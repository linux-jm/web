名前

du - ファイルのディスク使用量を推定する  

書式

du [,OPTION/]... [,FILE/]...
du [,OPTION/]... ,--files0-from=F/  

説明

各ファイルのデバイス使用量を集計します。ディレクトリは再帰的に処理されます。

長いオプションで必須となっている引数は短いオプションでも必須です。

-0, --null
出力行の区切りとして改行文字ではなく NUL を使用します。
-a, --all
ディレクトリだけでなく、全てのファイルについて表示します。
--apparent-size
デバイス使用量ではなく実際のサイズを表示します。実際の サイズは通常小さくなりますが、(スパース) ファイル内のホール、 内部フラグメンテーション、間接ブロックなどの理由で大きくなることもあります。
-B, --block-size=,SIZE/
SIZE の倍数として表示します。例: '-BM' は 1,048,576 バイト単位でサイズを表示します。 下記の SIZE フォーマットも参照してください。
-b, --bytes
'--apparent-size --block-size=,1/' と同じ
-c, --total
総合計を表示します。
-D, --dereference-args
コマンドラインで指定されたシンボリックのみをたどります。
-d, --max-depth=,N/
コマンド実行場所から N 階層以内のディレクトリの (--all 指定時はファイルも) 合計を表示します。 --max-depth=,0/ は --summarize と同じです。
--files0-from=,F/
ファイル F で指定された NUL で区切られた名前の ファイルからデバイス使用量を読み取ります。 F に - が指定された場合標準入力から読み込みます。
-H これは --dereference-args (-D) と同様です。
-h, --human-readable
人間が読みやすい形式でサイズを表示します。 (例: 1K 234M 2G)
--inodes
ブロック使用量ではなく inode 使用量を表示します。
-k これは --block-size=,1K/ と同様です。
-L, --dereference
全てのシンボリックリンクをたどります。
-l, --count-links
ハードリンクされた場合その個数分サイズを数えます。
-m これは --block-size=,1M/ と同様です。
-P, --no-dereference
シンボリックリンクをたどりません。 (デフォルト)
-S, --separate-dirs
子ディレクトリのサイズを含めません。
--si これは -h と同様ですが、1024 ではなく 1000 の累乗を表示します。
-s, --summarize
各引数の合計容量のみ表示します。
-t, --threshold=,SIZE/
SIZE が正の場合は SIZE より小さいエントリを無視します。 SIZE が負の場合は SIZE より大きなエントリを無視します。
--time
ディレクトリとその子ディレクトリに含まれる全てのファイルでの、最終更新時間を表示します。
--time=,WORD/
更新時間の代わりに WORD の時間を表示します。 WORD には次を指定でます: atime, access, use, ctime, status
--time-style=,STYLE/
時間を STYLE の形式で表示します。STYLE には次を指定できます: full-iso, long-iso, iso, +FORMAT FORMAT は 'date' と同様に解釈されます。
-X, --exclude-from=,FILE/
FILE 内のいずれかのパターンに一致するファイルを除外します。
--exclude=,PATTERN/
PATTERN に一致するファイルを除外します。
-x, --one-file-system
異なるファイルシステム上のディレクトリはスキップします。
--help
使い方を表示して終了します。
--version
バージョン情報を表示して終了します。

Display の値は、--block-size で指定した SIZE, DU_BLOCK_SIZE, BLOCK_SIZE および BLOCKSIZE 環境変数のうち、最初に指定されているサイズ単位で値が表示されます。 それ以外の場合、デフォルトの単位は 1024 バイトになります (POSIXLY_CORRECT が設定されている場合 512 バイト)。

SIZE 引数は整数で、追加で単位を指定できます。 (例えば 10M は 10*1024*1024 です)。 単位には K, M, G, T, P, E, Z, Y, R, Q (1024 の累乗) や KB, MB, ... (1000 の累乗) が使用できます。 二進接頭辞も使用することもできます: KiB=K, MiB=M など。  

パターン

PATTERN は (正規表現ではなく) シェルのパス名指定パターンです。 パターン ? は任意の 1 文字にマッチし、 * は (0 文字、1 文字、複数文字の) 任意の文字列にマッチします。 例えば、 *.o はファイル名が .o で終わる全てのファイルにマッチします。 したがって、コマンド
du --exclude='*.o'

では、名前が .o で終わるファイルとサブディレクトリが全てスキップされます (ファイル .o 自身もスキップされます)。
