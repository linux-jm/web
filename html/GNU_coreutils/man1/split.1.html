名前

split - ファイルを複数に分割する  

書式

split [,OPTION/]... [,FILE /[,PREFIX/]]  

説明

INPUT を PREFIXaa, PREFIXab, ... という固定サイズのファイルに分割します。 デフォルトのサイズは 1000 行です。デフォルトの PREFIX は 'x' です。

ファイルの指定がない場合や FILE が - の場合, 標準入力から読み込みを行います。

長いオプションで必須となっている引数は短いオプションでも必須です。

-a, --suffix-length=,N/
接尾辞の長さを N にします。 (デフォルト: 2)
--additional-suffix=,SUFFIX/
ファイル名に SUFFIX を追加で付加します。
-b, --bytes=,SIZE/
出力ファイル毎の大きさを SIZE バイトにします。
-C, --line-bytes=,SIZE/
出力ファイルに含まれる行の最大サイズを SIZE にします。
-d
接尾辞を英字ではなく 0 で始まる数字にします。
--numeric-suffixes[=,FROM/] -d と同様ですが、開始番号を設定できます。
-x
接頭辞を英字ではなく 0 で始まる 16 進数にします。
--hex-suffixes[=,FROM/] -x と同様ですが、開始番号を設定できます。
-e, --elide-empty-files
'-n' を使用した時に空ファイルを作成しません。
--filter=,COMMAND/
シェルコマンド COMMAND にファイル名を $FILE として出力します。
-l, --lines=,NUMBER/
出力ファイル毎の行数/レコード数を NUMBER 行/個にします。
-n, --number=,CHUNKS/
作成する出力ファイル数を CHUNKS 個にします。下記の説明を参照
-t, --separator=,SEP/
レコードの区切りとして改行ではなく SEP を使用します。 '\0' (zero) は NUL 文字を意味します。
-u, --unbuffered
'-n r/...' を使用した時に、すぐに入力を出力にコピーします。
--verbose
各出力ファイルを開く前に診断メッセージを表示します。
--help
使い方を表示して終了します。
--version
バージョン情報を表示して終了します。

SIZE 引数は整数で、追加で単位を指定できます(例えば 10M は 10*1024*1024 です)。 単位には K, M, G, T, P, E, Z, Y,R, Q (1024 の累乗) や KB, MB, ... (1000 の累乗) が使用できます。 二進接頭辞も使用することもできます: KiB=K, MiB=M など。  

塊 (CHUNKS) には以下を指定できます:

N
入力サイズに基づいて N 個のファイルに分割します。
K/N
N 個中 K 番目を標準出力に出力します。
l/N
N 個のファイルに分割しますが、行やレコード内の分割は行ないません。
l/K/N
N 個中 K 番目を標準出力に出力しますが、行やレコード内の分割は行ないません。
r/N
'l' と同様だがラウンドロビン分割をします。
r/K/N
上記と同様だが N 個中 K 番目を標準出力に出力します。
