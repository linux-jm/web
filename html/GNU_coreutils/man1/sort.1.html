名前

sort - テキストファイルの行の並び替えを行う  

書式

sort [,OPTION/]... [,FILE/]...
sort [,OPTION/]... ,--files0-from=F/  

説明

指定されたすべてのファイルの内容をソートして標準出力に書き込みます。

ファイルの指定がない場合や FILE が - の場合, 標準入力から読み込みを行います。

長いオプションで必須となっている引数は短いオプションでも必須です。 並び替えオプション:

-b, --ignore-leading-blanks
先頭の空白を無視します。
-d, --dictionary-order
空白および英数字のみ含まれていると仮定します。
-f, --ignore-case
大文字・小文字を区別しません。
-g, --general-numeric-sort
一般的な数値として比較を行います。
-i, --ignore-nonprinting
表示可能な文字のみ比較を行います。
-M, --month-sort
月名でソートします。(不明) < 'JAN' < ... < 'DEC' の順
-h, --human-numeric-sort
人間が読むことができる形式の数値を比較します。 (例: 2K 1G)
-n, --numeric-sort
文字列を数値とみなして比較します。 サポートされる文字列については完全なドキュメントを参照してください。
-R, --random-sort
シャッフルします。但し、同じキーはグルーピングされます。shuf(1) 参照。
--random-source=,FILE/
ランダムなバイトを FILE から取得します。
-r, --reverse
比較結果を逆順にします。
--sort=,WORD/
WORD に応じてソートします。WORD の候補は次の通り: general-numeric -g, human-numeric -h, month -M, numeric -n, random -R, version -V
-V, --version-sort
自然な (バージョン) 数字順でソートします。

そのほかのオプション:

--batch-size=,NMERGE/
一度に最大 NMERGE 行、併合を行います。 それ以上の場合は一時ファイルが使用されます。
-c, --check, --check=,diagnose-first/
入力がソートされているかを確認します。ソートは行いません。
-C, --check=,quiet/, --check=,silent/ -c
と同様ですが、正しくソートされていない最初の行を出力しません。
--compress-program=,PROG/
PROG を使用して一時ファイルを圧縮し、PROG -d を使用して展開します。
--debug
ソートに使用されている行の一部に注釈をつけて、 不確かな使用方法について標準エラー出力に警告を表示します。
--files0-from=,F/
ファイル F に含まれた NULL 文字で区切られた文字列をファイル名として扱い、 それらのファイルの中身を入力行して読み込みます。ファイル F に - を指定した時は、 ファイル名を標準入力から読み込みます。
-k, --key=,KEYDEF/
指定されたキーでソートします。KEYDEF では場所と並び替え種別を指定します。
-m, --merge
ソートされたファイルを併合します。ソート自体は行ないません。
-o, --output=,FILE/
結果を標準出力の代わりに FILE に書き込みます。
-s, --stable
前の比較結果に頼らない安定的な並び替えを行います。
-S, --buffer-size=,SIZE/
主記憶のバッファの大きさとして SIZE を使用します。
-t, --field-separator=,SEP/ フィールド区切り文字として、 空白の代わりに SEP を使用します。
-T, --temporary-directory=,DIR/
一時ディレクトリとして $TMPDIR または ,/tmp/ ではなく
DIR を使用します。オプションを複数指定すると、複数のディレクトリを指定できます。
--parallel=,N/
同時に実行するソートの数を N に変更します。
-u, --unique
同じキーを持つ行の最初の行だけを出力します。 -c と併せて使用した場合、厳密に順序を確認します。
-z, --zero-terminated
行の区切りとして改行文字ではなく NUL を使用します。
--help
使い方を表示して終了します。
--version
バージョン情報を表示して終了します。

KEYDEF は F[.C][OPTS][,F[.C][OPTS]] の書式で、開始位置と停止位置を指定します。 F はフィールド番号で、 C はフィールド内の文字位置です。両方とも開始番号は 1 です。 停止位置はデフォルトでは行末です。-t と -b の両方とも指定がない場合、 フィールド内の文字は、前にある空白の開始から数えられます。 OPTS には、1 文字の並び替えオプション [bdfgiMhnRrV] を一つ以上指定します。 OPTS で指定されたキーの並び替えオプションは、グローバルな並び替えオプション より優先されます。キーが指定されない場合、行全体がキーとして使用されます。 正しくないキーの使用を突き止めるには --debug を使ってください。

SIZE には以下の倍数などを指定する接尾辞を続けることが出来ます: % はメモリの何 % を使用するか。b は 1倍、K は 1024倍 (デフォルト)。 同様に M, G, T, P, E, Z, R, Q なども指定できます。

*** 警告 *** 環境変数によって指定されたロケールで並び替え順序が変わります。 本来のバイト単位の値を使用した伝統的な並び替え順にしたい場合、 LC_ALL=C を指定してください。
