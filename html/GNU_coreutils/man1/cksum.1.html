名前

cksum - ファイルのチェックサムとバイト数を表示する  

書式

cksum [,OPTION/]... [,FILE/]...  

説明

チェックサムを表示又は検査します。 デフォルトでは、 32 ビット CRC アルゴリズムを使用します。

ファイルの指定がない場合や FILE が - の場合, 標準入力から読み込みを行います。

長いオプションで必須となっている引数は短いオプションでも必須です。

-a, --algorithm=,TYPE/
使用するダイジェストタイプを選択します。ダイジェストについては以下を参照してください。
--base64
16進数ではなく、base64でエンコードされたダイジェストを出力します。
-c, --check
FILE からチェックサムを読み、それを検査します。
-l, --length=,BITS/
ビット単位のダイジェストの長さ; 最大値を超えてはならず、 blake2b では 8 の倍数でなければならず、sha2 または sha3 では 224、256、384 または 512 でなければなりません。
--raw
16進数ではなく、生のバイナリダイジェストを出力します。
--tag
BSD 形式のチェックサムを作成します。(デフォルト)
--untagged
反転スタイルのチェックサムを作成します(ダイジェストタイプなし)
-z, --zero
各出力行を改行ではなくNULで終わらせ、ファイル名のエスケープを無効にします。
 

次の5つのオプションは、チェックサムを確認する場合にのみ役立ちます:

--ignore-missing
見つからないファイルに対して失敗したりステータスを報告しません。
--quiet
正常に検証されたファイルに対してOKを出力しません。
--status
何も出力せず、ステータスコードは成功を示します。
--strict
不適切な形式のチェックサム行に対しては 0 以外の値を返します。
-w, --warn
不適切な形式のチェックサム行に関する警告を出します。
--debug
どの実装が使われたかを表示します。
--help
使い方を表示して終了します。
--version
バージョン情報を表示して終了します。
 

DIGESTは、ダイジェストアルゴリズムと既定の出力形式を決定します:

sysv
(sum -s と同じです)
bsd
(sum -r と同じです)
crc
(cksum と同じです)
crc32b
(cksum からのみ有効です)
md5
(md5sum と同じです)
sha1
(sha1sum と同じです)
sha2
(sha{224,256,384,512}sum と同じです)
sha3
(cksum からのみ有効です)
blake2b
(b2sum と同じです)
sm3
(cksum からのみ有効です)

チェックする場合、入力はこのプログラムの以前の出力、 または同等のスタンドアロンプログラムである必要があります。
