名前

nl - ファイルに行番号を付与する  

書式

nl [,オプション/]... [,ファイル/]...  

説明

指定した各ファイルに行番号を付け足して標準出力に書き込みます。

ファイルの指定がない場合や FILE が - の場合, 標準入力から読み込みを行います。

長いオプションで必須となっている引数は短いオプションでも必須です。

-b, --body-numbering=,STYLE/
本文の行番号を STYLE の形式にします。
-d, --section-delimiter=,CC/
セクションの区切り記号に CC を利用します。
-f, --footer-numbering=,STYLE/
フッタの行番号を STYLE の形式にします。
-h, --header-numbering=,STYLE/
ヘッダの行番号を STYLE の形式にします。
-i, --line-increment=,NUMBER/
行番号の増分を NUMBER にします。
-l, --join-blank-lines=,NUMBER/
NUMBER 個以下の空行を一つとして数えます。
-n, --number-format=,FORMAT/
行番号の出力形式を FORMAT にします。
-p, --no-renumber
セクション毎に行番号をリセットしません。
-s, --number-separator=,STRING/
行番号の後ろに STRING を加えます。 (可能な場合)
-v, --starting-line-number=,NUMBER/
各セクションの先頭行番号を NUMBER にします。
-w, --number-width=,NUMBER/
行番号を表示する列幅を NUMBER にします。
--help
使い方を表示して終了します。
--version
バージョン情報を表示して終了します。

デフォルトのオプションは -bt -d'\:' -fn -hn -i1 -l1 -n'rn' -s<TAB> -v1 -w6 です。

CC は 2 文字で、セクション区切りを指定するのみ使用されます。 2 番目の文字が指定されない場合には暗黙に ':' が指定されます。 GNU拡張として、2文字以上を指定することができ、 また空の文字列 (-d '') を指定することもできます。

STYLE には次のうちの一つを指定します。

a
すべての行番号
t
空行以外の行番号
n
空行の行番号
pBRE
基本正規表現 BRE に一致する行のみを数えたときの行番号

FORMAT には次のうちの一つを指定します。

ln
左揃え、 0 で埋めない
rn
右揃え、 0 で埋めない
rz
右揃え、 0 で埋める
