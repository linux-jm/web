名前

tail - ファイルの最後の部分を出力する  

書式

tail [,オプション/]... [,ファイル/]...  

説明

各 FILE の最後の 10 行を標準出力に書き出します。複数の FILE が指定され た場合、ファイル名がヘッダ情報として出力されます。

ファイルの指定がない場合や FILE が - の場合, 標準入力から読み込みを行います。

長いオプションで必須となっている引数は短いオプションでも必須です。

-c, --bytes=,[/+]NUM
最後の NUM バイトを出力します。 -c +NUM の場合は、 各ファイルの先頭から NUM 番目のバイト以降を出力します。
-f, --follow[={name|descriptor}]
ファイルが大きくなるのに合わせて追加されたデータを出力します。 オプションの引数が指定されなかった場合は 'descriptor' にります。
-F
これは --follow=,name/ --retry とです。
-n, --lines=,[/+]NUM
最後の 10 行ではなく NUM 行を出力します。 -n +NUM の場合は、先頭から NUM-1 行をスキップします。
--max-unchanged-stats=,N/
--follow=,name/ と併せて使用し、N 回 (デフォルトでは 5 回) stat を繰り返してもファイルサイズが変わっていない場合は、 ファイルの削除や名前の変更が行われていないかを確認するために FILE を再オープンします。 (ログファイルがローテートされた時には通常このような状態になります)。 inotify と併せて使う場合、このオプションが役に立つことはほとんどありません。
--pid=,PID/
-f と併せて使用し、 PID のプロセスがもはや存在しない場合終了します。 複数のプロセスを監視するために繰り返すことができます。
-q, --quiet, --silent
指定したファイル名を示すヘッダを出力しません。
--retry
ファイルがアクセスできない場合に、ファイルのオープンを継続して試みます。
-s, --sleep-interval=,N/
-f と併せて使用し、繰り返しの間隔を約 N 秒 (デフォルト: 1.0 秒) に設定します。 inotify および --pid=,P/ と併せて使用した場合、 最低 N 秒間に 1 回、プロセス P の確認を行います。
-v, --verbose
ファイル名を示すヘッダを常に出力します。
-z, --zero-terminated
行の区切りを改行でなく NUL にします。
--help
使い方を表示して終了します。
--version
バージョン情報を表示して終了します。

NUM には以下の倍数接尾子を続けることが出来ます: b 512, kB 1000, K 1024, MB 1000*1000, M 1024*1024, GB 1000*1000*1000, G =1024*1024*1024 で T、P、E、Z、Y、R、Q についても同様です。 二進接頭辞も使用することもできます: KiB=K, MiB=M など。

--follow (-f) を使用すると、tail はデフォルトでファイル記述子を追跡します。 このため tail で追跡しているファイルの名前が変更されたとしても、 tail は 元のファイルの終端を追跡し続けます。このデフォルトの動作はファイル記述子 ではなく、実際にある名前を持つファイルを追跡する場合には望ましくありませ ん (例: ログのローテーションなど)。そのような場合には --follow=,name/ を使 用してください。これにより名前の変更、削除、作成などにあわせて名前のついた ファイルの末尾を追跡するようになります。
