名前

ptx - ファイルの内容の整列した索引を生成する  

書式

ptx [,OPTION/]... [,INPUT/]... ,(-G なし)/
ptx ,-G /[,OPTION/]... [,INPUT /[,OUTPUT/]]  

説明

入力ファイルに含まれる単語の索引を並べ替え、前後を含めて出力します。

ファイルの指定がない場合や FILE が - の場合, 標準入力から読み込みを行います。

長いオプションで必須となっている引数は短いオプションでも必須です。

-A, --auto-reference
自動生成した参照文を出力します。
-G, --traditional
System V の 'ptx' に近い動作を行います。
-F, --flag-truncation=,STRING/
行の切り詰めの目印に STRING を使用します。 デフォルトは '/'
-M, --macro-name=,STRING/
'xx' の代わりに使うマクロ名を指定します。
-O, --format=,roff/
roff 命令で出力を生成します。
-R, --right-side-refs
参照文を右にします。ただし -w の勘定には入りません。
-S, --sentence-regexp=,REGEXP/
行末または文末を表現する正規表現を指定します。
-T, --format=,tex/
TeX 命令で出力を生成します。
-W, --word-regexp=,REGEXP/
キーワードに対して REGEXP で一致を調べます。
-b, --break-file=,FILE/
この FILE 中から単語を分割する文字を取得します。
-f, --ignore-case
小文字を大文字に変えて並び替えます。
-g, --gap-size=,NUMBER/
出力のフィールド間の列中の隙間の大きさを指定します。
-i, --ignore-file=,FILE/
FILE から無視する単語一覧を読み込みます。
-o, --only-file=,FILE/
この FILE から単語一覧のみを読み込みます。
-r, --references
各行の第1フィールドを参照文と見なします。
-t, --typeset-mode - 未実装 -
-w, --width=,NUMBER/
列の出力幅を指定. 参照文を除いて数えます。
--help
使い方を表示して終了します。
--version
バージョン情報を表示して終了します。
