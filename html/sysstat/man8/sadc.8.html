名前

sadc - システムアクティビティデータコレクタ。

 

書式

/usr/local/lib64/sa/sadc [ -C comment ] [ -D ] [ -F ] [ -f ] [ -L ] [ -V ] [ -S { keyword[,...] | ALL | XALL } ] [ interval [ count ] ] [ outfile ]

 

説明

sadc コマンドは、秒単位で、指定された間隔 (interval) で、指定された回数 (count) で、システムデータをサンプリングします。このコマンドは、指定された outfile または標準出力にバイナリ形式で書き込みます。outfile が - に設定されている場合、sadc は標準的なシステムアクティビティ日次データファイルを使用します (以下を参照)。この場合、ファイルがすでに存在する場合、sadc は前月のファイルであれば上書きします。既定では sadc はカーネルから利用可能なデータのほとんどを収集します。ただし、オプションのメトリックもあります。これらのメトリックでは、関連するオプションを明示的に sadc に渡して収集する必要があります (下記の -S オプションを参照)。

システムアクティビティの標準的な日次データファイルは、saDD という名前になります。ただし、オプション -D が使用されている場合、ファイルの名前は saYYYYMMDD になります。ここで、YYYY は現在の年を表し、MM は現在の月を表し、DD は現在の日を表します。既定では、/var/log/sa ディレクトリにあります。ただし、別の場所を指定することもできます。outfile が (プレーンファイルではなく) ディレクトリである場合、標準的なシステムアクティビティ日次データファイルが配置されているディレクトリと見なされます。

count パラメータが指定されていない場合、sadc は無限にデータを書き込みます。interval と count の両方が指定されておらず、オプション -C が使用されていない場合、システム起動時にカウンタが 0から再開する時間をマークするために使用されるダミーレコードが書き込まれます。たとえば、システム起動スクリプトの 1つは、次のコマンドエントリによって日次データファイルに再起動マークを書き込む場合があります。

/usr/local/lib64/sa/sadc -

sadc コマンドは、sar コマンドのバックエンドとして使用することを目的としています。

注意: sadcコマンドは、ローカルアクティビティのみをレポートします。

 

オプション

-C comment
interval パラメータも count パラメータも指定されていない場合、このオプションは sadc に、指定された comment 文字列を含むダミーレコードを書き込むように指示します。このコメントは、sar でオプション -C を使用して表示できます。
-D
標準のシステムアクティビティ日次データファイル名として、saDD の代わりに saYYYYMMDD を使用します。
-F
outfile の作成が強制されます。ファイルがすでに存在し、sadc にとって不明な形式である場合、ファイルは切り詰められます。これは、古いバージョンの sadc で作成された日次データファイルおよびその形式が現在の形式と互換性がなくなった場合に役立つ場合があります。
-f
fdatasync() は、データがディスクに確実に書き込まれるようにするために使用されます。これは、突然のシステムリセットによって saDD データファイルが破損する可能性が低くなるという点で、通常の動作とは異なります。ただし、データがキャッシュだけでなく基盤となるディスクに書き込まれる間、処理の進行がブロックされるため、sadc プロセス内のパフォーマンスが犠牲になります。
-L
sadcは、outfile に書き込む前、または切り詰める前に、排他ロックの取得を試みます。ロックの取得に失敗すると致命的です。ただし、通常の (つまり、ダミーでもヘッダーでもない) レコードを既存のファイルに書き込もうとする場合は除きます。この場合、sadc は次の間隔で再試行します。通常、ロックが失敗する唯一の理由は、別の sadc プロセスがファイルに書き込んでいた場合です。これは、cron が sadc を起動するために使用されるときに発生する可能性があります。システムに大きな負荷がかかっている場合は、cron が新しい sadc を起動したときに、古い sadc がまだ動作している可能性があります。ロックしないと、この状況によりシステムアクティビティファイルが破損する可能性があります。
-S { keyword[,...] | ALL | XALL }
取り得るキーワードは、 DISK, INT, IPV6, POWER, SNMP, XDISK, ALL と XALL です。
sadc によって収集されるオプションのアクティビティを指定します。一部のアクティビティは、データファイルが大きくなりすぎないようにするためのオプションです。DISK キーワードは、sadc がブロックデバイスのデータを収集することを示します。INT キーワードは、sadc がシステム割り込み用のデータを収集することを示します。IPV6 キーワードは、IPv6 統計情報が sadc によって収集されることを示します。POWER キーワードは、sadc が電源管理統計情報を収集することを示します。SNMP キーワードは、SNMP 統計情報が sadc によって収集されることを示します。ALL キーワードは、上記のすべてのキーワードを指定することと同等であるため、上記すべてのアクティビティが収集されます。
XDISK キーワードは DISK の拡張であり、パーティションとファイルシステムの統計がディスク統計に加えて sadc によって収集されることを示します。このオプションはカーネル 2.6.31 以降でのみ動作します。XALL キーワードは、上記のすべてのキーワード (キーワード拡張子を含む) を指定することと同等であるため、指定可能なすべてのアクティビティが収集されます。
重要な注意: 既存のデータファイルに保存されているアクティビティ (オプションのアクティビティを含む) は、オプション -S で選択したアクティビティよりも優先されます。その結果、既存のデータファイルにデータを追加すると、オプション -S 無視されます。
-V
バージョン番号を出力して終了します。

 

環境変数

sadc コマンドは、次の環境変数を参照します。
S_TIME_DEF_TIME
この変数が存在し、その値が UTC の場合、sadc はそのデータを UTC 時間で保存します。また、sadc は /var/log/sa ディレクトリにある当日のデータファイルを特定するために、現地時間の代わりに UTC 時間を使用します。

 

使用例

/usr/local/lib64/sa/sadc 1 10 /tmp/datafile
1秒間隔のレコードを 10個、/tmp/datafile バイナリファイルに書き込みます。
/usr/local/lib64/sa/sadc -C "Backup Start" /tmp/datafile
ファイル /tmp/datafile に「Backup Start」というコメントを挿入します。

 

バグ

sadc コマンドが作動するためには、/proc ファイルシステムがマウントされている必要があります。

使用しているカーネルのバージョンによっては、すべての統計情報が利用できるとは限りません。sadc は、少なくとも 2.6カーネルを使用していることを前提としています。

 

ファイル

/var/log/sa/saDD
/var/log/sa/saYYYYMMDD
標準的なシステムアクティビティの日次データファイルとその既定値の場所。YYYY は現在の年、MM は現在の月、DD は現在の日を表します。
/proc と/sys には、システム統計情報を含むさまざまなファイルが含まれています。
