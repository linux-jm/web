名前

sadf - sarによって収集されたデータを複数の形式で表示します。

 

書式

sadf [ -C ] [ -c | -d | -g | -j | -l | -p | -r | -x ] [ -H ] [ -h ] [ -T | -t | -U ] [ -V ] [ -O opts [,...] ] [ -P { cpu_list | ALL } ] [ -s [ start_time ] ] ] [ -e [ end_time ] ] ] [ --dev=dev_list ] [ --fs=fs_list ] [ --iface=iface_list] [ --int=int_list ] [ -- sar_options ] [ interval [ count ] ] [ datafile | -[0-9]+ ]

 

説明

sadfコマンドは、sar(1) コマンドによって作成されたデータファイルの内容を表示するために使用されます。sar とは異なり、sadf はデータをさまざまな形式 (CSV、XMLなど) で書き込むことができます。既定の形式は、awk (オプション -p を参照) のようなパターン処理コマンドで簡単に処理できる形式です。sadf コマンドを使用して、sar によって収集されたさまざまなアクティビティのグラフを描画し、それらをWebブラウザに SVG (Scalable Vector Graphics) グラフィックとして表示することもできます (オプション -g を参照)。

sadf コマンドは、datafile ファイルに保存されている標準出力レコードを抽出して書き込みます。このファイルは、sadf と互換性がある sar のバージョンで作成されている必要があります。datafile を省略すると、sadf は標準のシステムアクティビティ日次データファイルを使用します。sadf には引数として -1、-2 などを指定することもでき、その場合、過去のデータが表示できます。たとえば、-1 は昨日の標準システムアクティビティファイルを指します。

標準のシステムアクティビティの日次データファイルは、saDD または saYYYYMMDD です。ここで、YYYY は現在の年、MM は現在の月、DD は現在の日を表します。sadf は、saDD および saYYYYMMDD の最新のものを検索し、それを使用します。既定では、/var/log/sa ディレクトリにあります。ただし、別の場所を指定することもできます。datafile が (プレーンファイルではなく) ディレクトリである場合、標準のシステムアクティビティ日次データファイルが配置されているディレクトリと見なされます。

interval およびcount パラメータは、sadf に interval 秒間隔で count レコードを選択するよう指示するために使用されます。count パラメータが設定されていない場合、データファイルに保存されているすべてのレコードが表示されます。

sar のすべてのアクティビティフラグは、どのアクティビティが報告されるべきかを示すためにコマンド行に入力することができます。フラグを指定する前に、sadf のフラグと混同しないように、コマンド行にダッシュのペア (--) を付けます。フラグを指定しない場合は、CPUアクティビティのみが選択されます。

 

オプション

-C
sadf にファイルに存在するコメントを表示するように指示します。
-c
古いシステムアクティビティバイナリデータファイル (バージョン 9.1.6以降) を最新の形式に変換します。次の構文を使用します:

sadf -c old_datafile > new_datafile

変換は、オプション -O (下記参照) を使用して制御できます。

-d
リレーショナルデータベースシステムに簡単に取り込める形式で、データファイルの内容を出力します。出力は、セミコロンで区切られたフィールドで構成されます。各レコードには、ファイルが作成されたホストのホスト名、間隔の値 (得られない場合は -1)、ほとんどのデータベースで容易に受け入れられる形式のタイムスタンプ、および sar_options コマンド行オプションで指定されたセミコロンで区切られた追加のデータフィールドが含まれます。タイムスタンプ出力はオプション -T、-t および -U で制御できることに注意してください。
--dev=dev_list
そのデバイスの統計情報を sadf によって表示されるブロックデバイスを指定します。dev_list は、カンマで区切られたデバイス名のリストです。sar のオプション-d を使うのに便利です。.

-e [ hh:mm[:ss] ]
-e [ seconds_since_the_epoch ]

レポートの終了時間を設定します。終了時間の既定値は 18:00:00 です。時間は、24時間形式で指定するか、特定の時刻 (10桁の数字で指定) からの経過秒数で指定する必要があります。
--fs=fs_list
sadfで統計が表示されるファイルシステムを指定します。fs_list は、カンマで区切られたファイルシステムデバイス名やマウントポイントのリストです。どちらの形式もフィルタリングに受け入れられます。sar のオプション -F を使うのに便利です。
-g
データファイルの内容を SVG (Scalable Vector Graphics) 形式で出力します。このオプションを使用すると、Web ブラウザに高度なグラフを表示できます。次の構文を使用します:

sadf -g your_datafile [ -- sar_options ] > output.svg

生成された SVG ファイルを任意の Web ブラウザで開きます。出力は、オプション -O (下記参照) を使用して制御できます。

-H
レポートのヘッダーのみを表示します (該当する場合)。フォーマットが指定されていない場合は、データファイルのヘッダデータ (メタデータ) が表示されます。
-h
オプション -d と組み合わせて使用すると、すべてのアクティビティが 1行で水平に表示されます。
--iface=iface_list
sadfで統計情報が表示されるネットワークインタフェースを指定します。iface_list は、カンマで区切られたインターフェイス名のリストです。sar のオプション -n DEV および -n EDEV を使うのに便利です。
--int=int_list
sadf で統計情報を表示する割り込み名を指定します。int_list はカンマで区切られた値のリストまたは値の範囲です (例: 0-16,35,40-)。sar のオプション -I を使うのに便利です。
-j
データファイルの内容を JSON (JavaScript Object Notation) 形式で出力します。タイムスタンプは、オプション -T および -t で制御できます。
-l
データファイルの内容を PCP (Performance Co-Pilot) アーカイブに書き出します。アーカイブの名前は、キーワード pcparchive= と共にオプション -O を使って指定できます。
-O opts[,...]
指定されたオプションを使用して、sadf の出力を制御します。以下のオプションは、sadf -g によって表示される SVG 出力を制御するために使用されます:
autoscale
特定のビューのすべてのグラフを、現在のビューのスケールに基づいてできるだけ大きく描画します。これを行うには、係数 (10、100、1000...) を使用してグラフ図面を拡大します。このオプションは、同じビューに複数のグラフが描画されている場合に便利です。一部のグラフには非常に小さな値しか表示されず、他のグラフには大きな値が表示されます。後者の場合、前者はほとんど表示されません。
bwcol
白黒のパレットを使用してグラフを描画します。
customcol
グラフを描画する時、既定値のカラーパレットの代わりにカスタマイズ可能なカラーパレットを使用します。パレットをカスタマイズする方法については、以下の環境変数S_COLORS_PALETTE を参照してください。
debug
SVG 出力ファイルに有用なコメントを追加します。
height=value
SVGキャンバスの高さを value にします。
oneday
24 時間のグラフデータを表示します。時間は既定では UTC で表示されることに注意してください。現地時間で時間を表示し、真夜中から始まる時間枠を取得するためにはオプション -T を使用する必要があります。
packed
同じアクティビティ (および同じデバイス) からのすべてのビューを同じ行にグループ化します。
showidle
CPU 統計のグラフに %idle 状態を表示します。
showinfo
各ビューに追加情報 (日付やホスト名など) を表示します。
showtoc
SVG 出力の先頭に、各アクティビティの最初のグラフを指すリンクで構成される目次を追加します。
skipempty
すべてのグラフの値がゼロのビューを表示しません。
古いシステムアクティビティバイナリデータファイルを最新の形式に変換するには、次のオプションを使用します。
hz=value
古いデータファイルが作成されたマシンの 1秒当たりのティック数を指定します。
データを PCP アーカイブに書き出す場合、次のオプションが使用できます:
pcparchive=name
作成する PCP アーカイブの名前を指定します。
以下のオプションは、sadf -r によって表示される raw 出力を制御するために使用されます:
debug
主にデバッグに役立つ追加情報を表示します。
-P { cpu_list | ALL }
sadf に、指定された 1つまたは複数のプロセッサについてのみ、プロセッサ依存統計を報告するように通知します。cpu_list はカンマで区切られた値のリストまたは値の範囲です (例:0,2,4-7,12-)。プロセッサ 0が最初のプロセッサであり、プロセッサ all はすべてのプロセッサ間のグローバル平均であることに注意してください。ALL キーワードを指定すると、個々のプロセッサごとに統計情報を報告し、すべてのプロセッサに対してグローバルに報告します。
-p
データファイルの内容を、awk のようなパターン処理コマンドで簡単に処理できる形式で出力します。出力は、タブで区切られたフィールドで構成されます。各レコードには、ファイルが作成されたホストのホスト名、間隔の値 (得られない場合は -1)、タイムスタンプ、デバイス名 (得られない場合は -1)、フィールド名とその値が含まれます。タイムスタンプ出力はオプション -T、-t および -U で制御できることに注意してください。
-r
データファイルの内容をそのまま表示します。このフォーマットでは、すべてのカウンタの値がカーネルから読み込まれたとおりに表示されます。これは、たとえば、経過時間間隔にわたって平均値が計算されないことを意味します。出力は、オプション -O (上記参照)を使用して制御できます。

-s [ hh:mm[:ss] ]
-s [ seconds_since_the_epoch ]

レポートの開始時間を設定します。開始時刻の既定値は 08:00:00 です。時間は、24時間形式で指定するか、特定の時刻 (10桁の数字で指定) からの経過秒数で指定する必要があります。
-T
タイムスタンプを UTC (協定世界時) ではなく、現地時間で表示します。
-t
UTC (協定世界時) ではなく、データファイル作成者の元のローカル時間でタイムスタンプを表示します。
-U
エポックからのタイムスタンプ (UTC-Coordinated Universal Time) を秒単位で表示します。
-V
バージョン番号を出力して終了します。
-x
データファイルの内容を XML 形式で出力します。タイムスタンプは、オプション -T および -t で制御できます。対応する DTD (Document Type Definition) と XML スキーマは、sysstat ソースパッケージに含まれています。https://sysstat.github.io/ にもあります。

 

環境変数

sadf コマンドは、次の環境変数を参照します。
S_COLORS_PALETTE
sadf -g に、SVG 出力をレンダリングする時に使用する色を指定します。この環境変数は、オプション customcol でカスタムカラーパレットが選択されている場合にのみ考慮されます (オプション -O を参照)。値はコロンで区切られた機能のリストで、既定値先の色を表す 6桁 3バイトの 16進数 (16進トリプレット) に対応しています。

0=000000:1=1a1aff:2=1affb2:3=b21aff:
4=1ab2ff:5=ff1a1a:6=ffb31a:7=b2ff1a:
8=efefef:9=000000:A=1a1aff:B=1affb2:
C=b21aff:D=1ab2ff:E=ff1a1a:F=ffb31a:
G=bebebe:H=000000:I=000000:K=ffffff:
L=000000:T=000000:W=000000:X=000000

16進数字 0 ～F で構成される機能は、パレット内の最初の 16色を指定するために使用されます (これらの色はグラフの描画に使用されます)。たとえば、3=ffffff は、パレット内の 3番目の色が白 (0xffffff) であることを示します。
その他の機能は次のとおりです:

G=
グリッド線の描画に使用する色を指定します。
H=
レポートヘッダーの表示に使用する色を指定します。
I=
追加情報の表示に使用する色を指定します (日付、ホスト名など)。
K=
グラフの背景に使用する色を指定します。
L=
既定値の色を指定します (たとえば、目次の表示に使用します)。
T=
グラフタイトルの表示に使用する色を指定します。
W=
警告およびエラーメッセージの表示に使用する色を指定します。
X=
軸や目盛りの表示に使用する色を指定します。
S_TIME_DEF_TIME
この変数が存在し、その値が UTC である場合、sadf は、ディレクトリ /var/log/sa にある当日のデータファイルを特定するために、現地時間の代わりに UTC 時間を使用します。

 

使用例

sadf -d /var/log/sa/sa21 -- -r -n DEV
システムアクティビティファイル sa21 からメモリとネットワークの統計情報を抽出し、データベースが取り込むことができる形式で表示します。
sadf -p -P 1
現在の日次データファイルからプロセッサ 1(2番目のプロセッサ) の CPU 統計を抽出し、パターン処理コマンドで簡単に処理できる形式で表示します。

 

バグ

SVG 出力 (オプション -g で作成されたもの) は SVG 1.1 標準に完全に準拠します。グラフィックスは、Firefox、Chrome、Opera などのさまざまなウェブブラウザで正常に表示されています。しかし、Microsoft のブラウザ (Internet Explorer 11 および Edge 13.1 でテスト済み) では、SVG のレンダリングに問題がありますので、使用しないでください。

 

ファイル

/var/log/sa/saDD
/var/log/sa/saYYYYMMDD
標準的なシステムアクティビティの日次データファイルとその既定値の場所。YYYY は現在の年、MM は現在の月、DD は現在の日を表します。
