名前

sar - システムアクティビティ情報を収集、レポート、または保存します。

 

書式

sar [ -A ] [ -B ] [ -b ] [ -C ] [ -D ] [ -d ] [ -F [ MOUNT ] ] [ -H ] [ -h ] [ -p ] [ -r [ ALL ] ] [ -S ] [ -t ] [ -u [ ALL ] ] [ -V ] [ -v ] [ -W ] [ -w ] [ -x ] [ -y ] [ -z ] [ --dec={ 0 | 1 | 2 } ] [ --dev=dev_list ] [ --fs=fs_list ] [ --help ] [ --human ] [ --iface=iface_list ] [ --int=int_list ] [ --pretty ] [ --sadc ] [ -I [ SUM | ALL ] ] [ -P { cpu_list | ALL } ] [ -m { keyword[,...] | ALL } ] [ -n { keyword[,...] | ALL } ] [ -q [ keyword[,...] | ALL ] ] [ -j { SID | ID | LABEL | PATH | UUID | ... } ] [ -f [ filename ] | -o [ filename ] | -[0-9]+ ] [ -i interval ] [ -s [ start_time ] ] [ -e [ end_time ] ] ] [ interval [ count ] ]

 

説明

sar コマンドは、オペレーティングシステム内の、選択した累積アクティビティカウンタの内容を標準出力に書き込みます。アカウンティングシステムは、count およびinterval パラメータの値に基づいて、秒単位で、指定された間隔で、指定された回数だけ情報を書き込みます。interval パラメータがゼロに設定されている場合、sar コマンドは、システムが起動してからの時間の平均統計情報を表示します。interval パラメータを指定せずに count パラメータを指定した場合、レポートは連続的に生成されます。収集されたデータは、画面に表示されるだけでなく、-o filename フラグで指定されたファイルに保存することもできます。filename が省略された場合、sar は標準のシステムアクティビティ日次データファイルを使用します (以下を参照)。 既定では、カーネルから利用可能なすべてのデータがデータファイルに保存されます。

sar コマンドは、以前にファイルに保存されたレコードを抽出して標準出力に書き込みます。このファイルは、-f フラグで指定されたファイルか、既定では標準的なシステムアクティビティ日次データファイルのいずれかです。sar には引数として -1、-2 などを指定することもでき、その場合、過去のデータが表示されます。たとえば、-1 は昨日の標準システムアクティビティファイルを指します。

標準のシステムアクティビティの日次データファイルは、saDD または saYYYYMMDD です。ここで、YYYY は現在の年、MM は現在の月、DD は現在の日を表します。これらは、ファイル名が明示的に指定されていない場合のみ sar によって使用される既定のファイルです。ファイルにデータを書き込むために使用する場合 (オプション -o を使用する場合)、sar はオプション -D も一緒に指定されている場合 saYYYYMMDD を使用します。指定されていない場合は、saDD を使用します。以前にファイルに保存されたレコードを表示するために使用する場合、sar は saDD および saYYYYMMDD の最新のものを検索して使用します。

標準的なシステムアクティビティの日次データファイルは、既定では /var/log/sa ディレクトリに置かれています。ただし、別の場所を指定することもできます。(プレーンファイルではなく) ディレクトリをオプション -f または -o を付けて使用する場合、ディレクトリはデータファイルを含むディレクトリと見なされます。

-P フラグを指定しない場合、sar コマンドは、システム全体 (すべてのプロセッサ全体) の統計情報をレポートします。この統計情報は、割合で表された値の平均と、それ以外は合計として計算されます。-P フラグが指定されている場合、sar コマンドは、指定された 1つまたは複数のプロセッサに関するアクティビティをレポートします。-P ALL が指定されている場合、sar コマンドは個々のプロセッサごとの統計情報と、すべてのプロセッサ間の全体的な統計情報をレポートします。オフラインのプロセッサは表示されません。

フラグを使用して、特定のシステムアクティビティに関する情報を選択できます。フラグを指定しない場合は、CPU アクティビティのみが選択されます。-A フラグを指定すると、すべての可能なアクティビティが選択されます。

sar コマンドの既定値 (CPU 使用率レポート) は、主要なシステムリソースを監視するため、ユーザーがシステムアクティビティの調査を開始するために実行する最初の機能の 1つである可能性があります。CPU 使用率がほぼ 100% の場合 (user+nice+system)、サンプリングされるワークロードは CPU バウンドです。

複数のサンプルと複数のレポートが必要な場合は、sar コマンドの出力ファイルを指定すると便利です。sar コマンドをバックグラウンドプロセスとして実行します。この構文は次のとおりです:

sar -o datafile interval count >/dev/null 2>&1 &

すべてのデータはバイナリ形式でキャプチャされ、ファイル (datafile) に保存されます。その後、sar コマンドで -f オプションを使用すると、データを選択して表示できます。interval 秒間隔で count 分記録するために、interval および count パラメータを設定します。count パラメータが設定されていない場合、ファイルに保存されているすべてのレコードが選択されます。この方法でデータを収集すると、一定期間にわたるシステムの使用状況の特徴を見たり、使用時間のピークを判断するのに役立ちます。

注意: sar コマンドは、ローカルアクティビティのみをレポートします。

 

オプション

-A
これは、-bBdFHISvwWy -m ALL -n ALL -q ALL -r ALL -u ALL を指定したのと同じです。このオプションは、-I ALL -P ALL を指定することも仮定しますが、これらのオプションがコマンド行で明示的に設定されている場合を除きます。
-B
ページング統計情報をレポートします。次の値が表示されます:
pgpgin/s
1秒あたりの、システムがディスクからページインしたキビバイト単位の合計値。
pgpgout/s
1秒あたりの、システムがディスクにページアウトしたキビバイト単位の合計値。
fault/s
システムによる1秒あたりのページフォルト (メジャー + マイナー) 数。一部のページフォールトは I/O がなくても解決できるため、これは I/O を生成したページフォールトのカウントではありません。
majflt/s
システムが1秒あたりに発生した、ディスクからメモリページをロードする必要があったメジャーフォールト数。
pgfree/s
1秒あたりの、システムによって空きリストに置かれたページ数。
pgscank/s
1秒あたりの kswapd デーモンによってスキャンされるページ数 (正常なシステムのバックグラウンドで実行)。
pgscand/s
1秒あたりの、直接スキャンされたページ数 (プロセスは停止)。
pgsteal/s
1秒あたりの、メモリ要求を満たすために、システムがキャッシュ (ページキャッシュおよびスワップキャッシュ) から再利用したページ数。
pgprom/s
1秒あたりの、システムによってプロモートされた (つまり、低速のメモリタイプから高速のメモリタイプに移行された) ページ数。
pgdem/s
1秒あたりの、システムによって降格された (つまり、高速のメモリタイプから低速のメモリタイプに移行された) ページ数。
-b
I/O および転送レートの統計情報をレポートします。次の値が表示されます:
tps
1秒あたりの、物理デバイスに対して発行された転送数の合計。転送とは、物理デバイスへの I/O 要求のことです。複数の論理要求を、デバイスに対する 1つの I/O 要求にまとめることもあります。転送サイズは不定です。
rtps
1秒あたりの、物理デバイスに対して発行された読み取り要求の合計値。
wtps
1秒あたりの、物理デバイスに対して発行された書き込み要求の合計値。
dtps
1秒あたりの、物理デバイスに対して発行された破棄要求の合計値。
bread/s
1秒あたりの、デバイスから読み取られたブロック単位のデータの合計値 。ブロックはセクタと同等であるため、サイズは 512バイトです。
bwrtn/s
1秒あたりの、デバイスに書き込まれたブロック単位のデータの合計値。
bdscd/s
1秒あたりの、デバイスで破棄されたブロック単位のデータの合計値。
-C
ファイルからデータを読み取るときに、sar にsadc によって挿入されたコメントを表示するように指示します。
-D
標準のシステムアクティビティ日次データファイル名として、saDD の代わりに saYYYYMMDD を使用します。このオプションは、オプション -o と組み合わせてデータをファイルに保存するために使用した場合にのみ機能します。
-d
各ブロックデバイスのアクティビティをレポートします。データを表示する場合、/dev に表示されているとおりにデバイス名が表示されます。sar はメジャー番号とマイナー番号に基づいてデバイス名を決定するために /sys 中のデータを使用します。この名前解決が失敗した場合は、sar は /etc/sysconfig/sysstat.ioconf ファイルによって制御される名前マッピングを使用します。オプション -j が使用されている場合も(下記参照)、永続デバイス名を出力できます。オプション --dev= (対応するオプションエントリを参照) を使用した制限リストが指定されていない限り、すべてのデバイスの統計情報が表示されます。ディスクアクティビティは、収集を行った sadc のオプション -S DISK および -S XDISK に依存します。次の値が表示されます:
tps
1秒あたりの、物理デバイスに対して発行された転送数の合計。転送とは、物理デバイスへの I/O 要求のことです。複数の論理要求を、デバイスに対する 1つの I/O 要求にまとめることもあります。転送サイズは不定です。
rkB/s
1秒あたりの、デバイスから読み込んだキビバイト数。
wkB/s
1秒あたりの、デバイスに書き込んだキビバイト数。
dkB/s
1秒あたりの、デバイスが破棄したキビバイト数。
areq-sz
デバイスに対して発行された I/O リクエストの平均サイズ (キビバイト)
注:以前のバージョンでは、このフィールドは avgrq-sz と呼ばれ、セクタ単位で表されていました。
aqu-sz
デバイスに対して発行された要求の平均キュー長。
注: 以前のバージョンでは、このフィールドは avgqu-sz と呼ばれていました。
await
サービス対象のデバイスに対して発行された I/O 要求の平均時間 (ミリ秒単位)。これには、キュー内の要求に費やされた時間と、それらの要求の処理に費やされた時間が含まれます。
%util
I/O リクエストがデバイスに発行された経過時間の割合 (デバイスの帯域幅使用率)。デバイスが連続して要求を処理する場合、この値が 100%に近いと、デバイスが飽和状態になります。ただし、RAID アレイや最新の SSD など、リクエストを並行して処理するデバイスの場合、この数値はパフォーマンスの制限を反映していません。
--dec={ 0 | 1 | 2 }
小数点以下の桁数を指定します (0～2、既定値は2)。
--dev=dev_list
そのデバイスの統計情報を sar によって表示されるブロックデバイスを指定します。dev_list は、カンマで区切られたデバイス名のリストです。

-e [ hh:mm[:ss] ]
-e [ seconds_since_the_epoch ]

レポートの終了時間を設定します。終了時間の既定値は 18:00:00 です。時間は、24時間形式で指定するか、特定の時刻 (10桁の数字で指定) からの経過秒数で指定する必要があります。このオプションは、データがファイルから読み込まれるとき、またはファイルに書き込まれるときに使用できます (オプション -f または -o)。
-F [ MOUNT ]
現在マウントされているファイルシステムの統計情報を表示します。擬似ファイルシステムは無視されます。レポートの最後に、sar は、これらすべてのファイルシステムのサマリーを表示します。MOUNT パラメータキーワードを使用すると、ファイルシステムデバイスではなくマウントポイントがレポートされます。すべてのファイルシステムの統計が表示されます。ただし、オプション --fs= を使用して制限リストを指定した場合を除きます(該当するオプションエントリーを参照)。ファイルシステムの統計は、収集を行なった sadc のオプション -S XDISK に依存することに注意してください。

次の値が表示されます:

MBfsfree
メビバイト単位での、空きスペースの合計 (特権ユーザーのみが使用できるスペースを含みます)。
MBfsused
メビバイト単位での、使用されているスペースの総容量。
%fsused
特権ユーザーから見た、ファイルシステム使用率。
%ufsused
非特権ユーザーから見た、ファイルシステム使用率。
Ifree
ファイルシステム内の空きファイルノードの合計値。
Iused
ファイルシステム内で使用されているファイルノードの合計値。
%Iused
ファイルシステム内で使用されているファイルノードの割合。
-f [ filename ]
-o filename フラグによって作成された filename からレコードを抽出します。filename パラメータの既定値は、現在の標準のシステムアクティビティ日次データファイルです。filename が通常のファイルではなくディレクトリである場合、標準のシステムアクティビティの日次データファイルが配置されているディレクトリと見なされます。オプション -f は、オプション -o と排他です。
--fs=fs_list
sar で統計が表示されるファイルシステムを指定します。fs_list はカンマで区切られたファイルシステムデバイス名のリスト (例:/dev/sdb1) またはマウントポイント (例:/srv) です。オプション -F がデバイス名またはマウントポイントを表示しているかどうかに関係なく、どちらの形式もフィルタリングに受け入れられます。
-H
hugepages 使用率の統計をレポートします。次の値が表示されます:
kbhugfree
キビバイト単位での、でまだ割り当てられていない hugepages メモリーの量。
kbhugused
キビバイト単位での、割り当てられているhugepagesメモリーの量。
%hugused
割り当てられている hugepages メモリー合計の割合。
kbhugrsvd
キビバイト単位での、予約済みの hugepages メモリーの量。
kbhugsurp
キビバイト単位での、hugepages メモリの余剰量。
-h
このオプションは、--pretty --human と指定するのと同じです。
--help
短いヘルプメッセージを表示して終了します。
--human
人間が読める形式でサイズを印刷します (例:1.0k、1.2Mなど)。このオプションで表示される単位は、メトリクスに関連付けられている他の既定の単位 (例:キビバイト、セクタなど) よりも優先されます。
-I [ SUM | ALL ]
割り込みの統計情報をレポートします。表示される値は、特定のプロセッサまたはすべてのプロセッサにおける 1秒あたりの割り込み数です。割り込みのリストは、--int= を使用して指定できます (このオプションを参照)。SUM キーワードは、1秒間に受信した割り込みの合計値を表示します。ALL キーワードは、すべての割り込みからの統計情報をレポートすることを示します (これは既定値です)。割り込みの統計情報は、収集を行った sadc のオプション -S INT に依存することに注意してください。
-i interval
interval パラメータで指定された秒数にできるだけ近い秒数のデータレコードを選択します。
--iface=iface_list
sar で統計情報が表示されるネットワークインタフェースを指定します。iface_list は、カンマで区切られたインターフェイス名のリストです。
--int=int_list
sar で統計情報を表示する割り込み名を指定します。int_list はカンマで区切られた値のリストまたは値の範囲です (例: 0-16,35,40-)。
-j { SID | ID | LABEL | PATH | UUID | ... }
永続デバイス名を表示します。このオプションは、オプション -d と組み合わせて使用します。キーワードID、LABEL などは、永続的な名前のタイプを指定します。これらのキーワードに制限はありません。唯一の前提条件は、必要な永続的な名前を持つディレクトリが /dev/disk に存在することです。キーワードSID は、デバイス名として使用する固定識別子を取得しようとします。固定識別子は、同じ物理デバイスを再起動しても変更されません。デバイスが存在する場合、この識別子は通常、/dev/disk/by-id ディレクトリから読み込まれたデバイスの WWN (World Wide Name) です。
-m { keyword[,...] | ALL }
電力管理の統計情報をレポートします。これらの統計は、収集を行った sadc のオプション -S POWER に依存することに注意してください。

取り得るキーワードは、BAT,CPU,FAN,FREQ,IN,TEMP および USB です。

BAT キーワードを使用すると、バッテリ容量に関する統計情報がレポートされます。次の値が表示されます:

%cap
バッテリ容量。
cap/min
バッテリが 1分間に失った、または増えた容量。
status
電池の充電状態: ↑(フル)、←(充電中)、→(非充電中)、←(放電中)、?(不明)。

CPU キーワードを指定すると、CPU に関する統計情報がレポートされます。次の値が表示されます:
MHz
瞬時 CPU クロック周波数 (MHz)。

FAN キーワードを使用すると、ファンの速度に関する統計情報がレポートされます。次の値が表示されます:
rpm
1分あたりの回転数で表されるファン速度。
drpm
このフィールドは、現在のファン速度 (rpm) とその下限 (fan_min) の差として計算されます。
デバイス:
センサーデバイス名。

FREQ キーワードを指定すると、CPU クロック周波数に関する統計情報がレポートされます。次の値が表示されます:
wghMHz
CPU クロック周波数の加重平均 (MHz)。このオプションを有効にするには、cpufreq-stats ドライバをカーネルに組み込む必要があります。

IN キーワードを指定すると、電圧入力に関する統計情報がレポートされます。次の値が表示されます:
inV
電圧入力 (V)。
%in
相対入力値。100%という値は、電圧入力が上限 (in_max) に達したことを意味し、0% という値は、下限 (in_min) に達したことを意味します。
デバイス:
センサーデバイス名。

TEMP キーワードを使用すると、デバイスの温度に関する統計情報が報告されます。次の値が表示されます:
degC
デバイスの温度 (摂氏)。
%temp
デバイスの相対温度。100% という値は、温度が上限 (temp_max) に達したことを意味します。
デバイス:
センサーデバイス名。

USB キーワードを指定すると、sar コマンドは、現在システムに接続されているすべての USB デバイスのスナップショットを作成します。レポートの最後に、sar はすべての USB デバイスの概要を表示します。次の値が表示されます:
BUS
USB デバイスのルートハブ番号。
idvendor
(USB組織によって割り当てられる) ベンダー ID番号。
idprod
(製造元が割り当てる)製品 ID 番号。
maxpower
デバイスの最大消費電力 (mA単位)。
manufact
メーカー名。
product
製品名。

ALL キーワードは、上記のすべてのキーワードを指定することと同じなので、すべての電源管理統計情報がレポートされます。
-n { keyword[,...] | ALL }
ネットワーク統計情報をレポートします。

取り得るキーワードは DEV, EDEV, FC, ICMP, EICMP, ICMP6, EICMP6, IP, EIP, IP6, EIP6, NFS, NFSD, SOCK, SOCK6, SOFT, TCP, ETCP, UDP と UDP6 です。

DEV キーワードを使用すると、ネットワークデバイスからの統計情報がレポートされます。すべてのネットワークインタフェースの統計情報が表示されます。ただし、オプション--iface= を使用して制限リストが指定されている場合を除きます (対応するオプションエントリを参照)。次の値が表示されます:

IFACE
統計情報レポート対象となるネットワークインタフェースの名前。
rxpck/s
1秒あたりの受信パケット数
txpck/s
1秒あたりの送信パケット数。
rxkB/s
1秒あたりの受信キビバイト数。
txkB/s

1秒あたりの、出力された IPv6 データグラムのうち、宛先への転送を妨げるような問題は発生しなかったものの、破棄されたものの数 [ipv6IfStatsOutDiscards]。このカウンタは、パケットがこの (任意の) 破棄基準を満たした場合、fwddgm6/s でカウントされたデータグラムを含むことに注意してください。
inort6/s
1秒あたりの、宛先に転送するルートが見つからなかったために破棄された入力データグラムの数 [ipv 6 iFSattSiNNoRoutes]。
onort6/s
1秒あたりの、送信先への転送ルートが見つからなかったために破棄された、ローカルに生成された IP データグラムの数 [unknown formal SNMP name]。
asmf6/s
1秒あたりの、IPv6 再アセンブリアルゴリズムによって検出された失敗数 (タイムアウト、エラーなどの理由を問いません) [ipv6IfStatsReasmFails]。これは廃棄された IPv6 フラグメントの数である必要がないことに注意してください、なぜならいくつかのアルゴリズムが受信時にフラグメントを結合することでフラグメントの数を追跡できなくなるからです。
fragf6/s
1秒あたりの、この出力インターフェイスでフラグメント化する必要があったが、フラグメント化できなかったために廃棄された IPv6 データグラムの数 [ipv6IfStatsOutFragFails]。
itrpck6/s
1秒あたりの、データグラムフレームが十分なデータを伝送しなかったために廃棄された入力データグラムの数 [ipv6IfStatsInTruncatedPkts]。

ALL キーワードは、上記のすべてのキーワードを指定することと同じであるため、すべてのネットワークアクティビティがレポートされます。
-o [ filename ]
測定値をファイルにバイナリ形式で保存します。各測定値は別々のレコードにあります。filename パラメータの既定値は、現在の標準のシステムアクティビティ日次データファイルです。filename が通常のファイルではなくディレクトリである場合、標準のシステムアクティビティの日次データファイルが配置されているディレクトリと見なされます。オプション -o は、オプション -f と排他です。カーネルから取得可能なすべてのデータは、ファイルに保存されます (実際には、sar はデータコレクタ sadc をオプション -S ALL で呼び出します)。sadc(8) マニュアルページを参照してください。
-P { cpu_list | ALL }
指定された 1つまたは複数のプロセッサについて、プロセッサごとの統計情報をレポートします。cpu_list はカンマで区切られた値のリストまたは値の範囲です (例:0,2,4-7,12-)。プロセッサ 0が最初のプロセッサであり、プロセッサ all はすべてのプロセッサ間のグローバル平均であることに注意してください。ALL キーワードを指定すると、個々のプロセッサごとに統計情報を報告し、すべてのプロセッサに対してグローバルに報告します。オフラインのプロセッサは表示されません。
-p, --pretty
人間が読みやすいレポートを作成します。このオプションは、ネットワークインターフェイスやブロックデバイスの統計情報などを表示する場合に特に便利です。
-q [ keyword[,...] | ALL ]

ユーザレベル (アプリケーション) での実行中に発生した CPU 使用率の割合。このフィールドには、仮想プロセッサの実行に費やされた時間は含まれないことに注意してください。
%nice
nice プライオリティを使用してユーザレベルで実行しているときに発生した CPU 使用率の割合。
%system
システムレベル (カーネル) での実行中に発生した CPU 使用率の割合。このフィールドには、ハードウェアおよびソフトウェア割り込みのサービスに費やされた時間が含まれることに注意してください。
%sys
システムレベル (カーネル) での実行中に発生した CPU 使用率の割合。このフィールドには、ハードウェアまたはソフトウェア割り込みのサービスに費やされた時間は含まれないことに注意してください。
%iowait
CPU がアイドル状態で、その間システムに未処理のディスク I/O 要求があった時間の割合。
%steal
ハイパーバイザーが別の仮想プロセッサーにサービスを提供している間に、1つまたは複数の仮想 CPU が意図しない待機状態にあった時間の割合。
%irq
CPU がハードウェア割り込みを処理するために費やした時間の割合。
%soft
CPU がソフトウェア割り込みを処理するために費やした時間の割合。
%guest
CPU が仮想プロセッサを実行するために費やした時間の割合。
%gnice
nice したゲストを実行するために CPU が費やした時間の割合。
%idle
CPU がアイドル状態で、システムに未処理のディスク I/O 要求がなかった時間の割合。
-V
バージョン番号を出力して終了します。
-v
iノード、ファイル、その他のカーネルテーブルの状態をレポートします。次の値が表示されます:
dentunusd
ディレクトリキャッシュ内の未使用のキャッシュエントリ数。
file-nr
システムで使用されているファイルハンドルの数。
inode-nr
システムで使用されている inode ハンドラの数。
pty-nr
システムで使用されている擬似端末の数。
-W
スワップ の統計をレポートします。次の値が表示されます:
pswpin/s
1秒あたりにシステムが取り込んだスワップページの合計値。
pswpout/s
1秒あたりの、システムが排出したスワップページの合計値。
-w
タスクの作成とシステムスイッチングアクティビティをレポートします。次の値が表示されます:
proc/s
1秒あたりに作成されたタスクの合計値。
cswch/s
1秒あたりのコンテキスト切り替えの合計値。
-x
拡張レポート: 最後に、平均値に加えて最小値と最大値を表示します。
-y
TTYデバイスのアクティビティをレポートします。次の値が表示されます:
rcvin/s
1秒あたりの、現在のシリアル回線の受信割り込み数。シリアル回線番号は、TTY列に表示されます。
xmtin/s
1秒あたりの現在のシリアル回線の送信割り込み数。
framerr/s
1秒あたりの現在のシリアル回線のフレームエラー数。
prtyerr/s
1秒あたりの現在のシリアル回線のパリティエラー数。
brk/s
1秒あたりの現在のシリアル回線のブレーク数。
ovrun/s
1秒あたりの現在のシリアル回線のオーバーランエラー数。
-z
サンプル期間中にアクティビティがなかったデバイスの出力を sar に省略するように指示します。

 

環境変数

sarコマンドは、次の環境変数を参照します。
S_COLORS
出力がターミナルに接続されている場合、既定では、端末ごとに統計情報がカラーで表示されます。この変数を使用して、設定を変更します。取り得る値は、never、always またはauto (後者は既定の設定と同等ですです。
値の表示に使用されている色 (赤、黄、またはその他の色) は、単に色が原因で何らかの問題が発生していることを示すものではありません。異なる値の範囲を示しているだけです。
S_COLORS_SGR
端末に関する統計情報の表示に使用する色およびその他の属性を指定します。その値は、コロンで区切られたケイパビリティのリストで、既定値は C=33;22:I=32;22:N=34;1:R=31;22:W=35;1:X=31;1:Z=34;22+=32;1:-=31;1 です。
サポートされる機能は次のとおりです:
C=
バイナリ日次データファイルに挿入されたコメントの SGR (Select Graphic Rendition) 部分文字列。
I=
項目名または値の SGR 部分文字列 (例:ネットワークインターフェイス、CPU 番号など)
N=
ゼロ以外の統計値を表示する SGR 部分文字列。
R=
再起動メッセージ用の SGR 部分文字列。
W= (又は M=)
75%から 90% (またはメトリックの意味に応じて 10%から 25%) の範囲の割合に対する SGR 部分文字列。また、-10 から -5 の範囲の負の値にも使用されます。
X= (又は H=)
割合が 90%以上のSGR 部分文字列 (あるいはメトリックの意味に応じて10%以下)。また、-10 以下の負の値にも使用されます。
Z=
ゼロ値を表示する SGR 部分文字列。
+=
バッテリーの状態 (フルまたは充電中) を示す SGR 部分文字列。
-=
バッテリのステータス (充電中または放電中ではないこと) を示す SGR 部分文字列。
S_REPEAT_HEADER
出力が端末ではない場合、sar がヘッダを表示するまでの最大行数を指定します。
S_TIME_DEF_TIME
この変数が存在し、その値が UTC の場合、sar はデータを UTC 時間で保存します。(データは引き続きローカル時間で表示されます)。また、sar は /var/log/saディレクトリにある当日のデータファイルを特定するために、現地時間の代わりに UTC 時間を使用します。この変数は、ユーザーが複数の時間帯に分散しているサーバーで役立ちます。
S_TIME_FORMAT
この変数が存在し、その値が ISO の場合、レポートヘッダーに日付を印刷するときに、現在のロケールが無視されます。sar コマンドは、代わりに ISO 8601 形式 (YYYY-MM-DD) を使用します。タイムスタンプも ISO 8601 形式に準拠します。

 

使用例

sar -u 2 5
2秒ごとの CPU 使用率を報告します。5行表示されます。
sar -I --int=14 -o int14.file 2 10
2秒ごとに IRQ 14 の統計情報をレポートします。10行表示されます。データは、int14.file というファイルに保存されます。
sar -r -n DEV -f /var/log/sa/sa16
日次データファイル sa16 に保存されているメモリとネットワークの統計情報を表示します。
sar -A
現在の日次データファイルに保存されているすべての統計情報を表示します。

 

バグ

sar コマンドが作動するためには、/proc ファイルシステムがマウントされている必要があります。

使用しているカーネルのバージョンによっては、すべての統計情報が利用できるとは限りません。sar は、少なくとも 2.6カーネルを使用していることを前提としています。

sarは、キロバイト (kB)、メガバイト (MB) などに対応するユニットを表示しますが、実際にはキビバイト (kiB)、メビバイト (MiB) などを使用します。キビバイトは 1024バイト、メビバイトは 1024キビバイトに相当します。

 

ファイル

/var/log/sa/saDD
/var/log/sa/saYYYYMMDD
標準的なシステムアクティビティの日次データファイルとその既定値の場所。YYYY は現在の年、MM は現在の月、DD は現在の日を表します。

/proc と/sys には、システム統計情報を含むさまざまなファイルが含まれています。
