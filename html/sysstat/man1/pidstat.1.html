PIDSTAT

Updated: 2025年 1月
Index JM Home Page roff page
 

名前

pidstat - Linuxタスクの統計を報告します。

 

書式

pidstat [ -d ] [ -H ] [ -h ] [ -I ] [ -l ] [ -R ] [ -r ] [ -s ] [ -t ] [ -U [ username ] ] [ -u ] [ -V ] [ -v ] [ -w ] [ -C comm ] [ -G process_name ] [ --dec={ 0 | 1 | 2 } ] [ --human ] [ -o JSON ] [ -p { pid[,...] | SELF | ALL } ] [ -T { TASK | CHILD | ALL } ] [ interval [ count ] ] [ -e program args ]

 

説明

pidstat コマンドは、現在 Linux カーネルによって管理されている個々のタスクを監視するために使用されます。オプション -p で選択されたすべてのタスクか、オプション -p ALL が使用された場合は、Linuxカーネルによって管理されるすべてのタスクのアクティビティを標準出力に書き込みます。タスクを選択しない場合は、-p ALL を指定した場合と同じになります。ただし、レポートに表示されるのはアクティブタスク (統計情報の値が 0以外のタスク) のみです。

pidstat コマンドは、選択したタスクの子プロセスを監視するためにも使用できます。下記のオプション -T も参照してください。

interval パラメータは、各レポート間の時間間隔を秒単位で指定します。値がゼロの場合 (またはパラメータがまったくない場合)、システムの起動 (ブート) 以降のタスク統計情報がレポートされることを示します。count パラメータは、interval パラメータがゼロに設定されていない場合は、interval パラメータと組み合わせて指定できます。count の値は、interval 秒間隔で生成されるレポートの数を決定します。interval パラメータを指定せずにcount パラメータを指定した場合、pidstat コマンドはレポートを継続的に生成します。

フラグを使用して、特定のタスクアクティビティに関する情報を選択できます。フラグを指定しない場合は、CPU アクティビティのみが選択されます。

 

オプション

-C comm
コマンド名に文字列 comm が含まれるタスクのみを表示します。この文字列には正規表現を使用できます。
-d
I/O 統計情報をレポートします (カーネル2.6.20以降のみ)。以下の値が表示されます:
UID
監視されているタスクの実ユーザー識別番号。
USER
監視対象のタスクを所有する実際のユーザーの名前。
PID
監視対象のタスクの ID 番号。
kB_rd/s
タスクによってディスクから読み取られた 1秒あたりのキビバイト数。
kB_wr/s
タスクによってディスクに書き込まれた、または書き込まれることになる 1秒あたりのキビバイト数。
kB_ccwr/s
ディスクへの書き込みがタスクによってキャンセルされたキビバイト数。これは、タスクがダーティページキャッシュを切り捨てたときに発生する可能性があります。この場合、別のタスクが原因となっている一部の I/O は発生しません。
iodelay
監視対象タスクのブロック I/O 遅延です。クロックティック単位で測定されます。このメトリックには、同期ブロック I/O 補完およびスワップイン・ブロック I/O 補完の待機に費やされる遅延が含まれます。
Command
タスクのコマンド名。
--dec={ 0 | 1 | 2 }
小数点以下の桁数を指定します (0～2、既定値は2)。
-e program args
program を指定された引数 args で実行し、pidstat で監視します。pidstat は program が終了すると停止します。interval パラメーターには、ゼロ以外の値を指定する必要があります。
-G process_name
コマンド名に文字列 process_name が含まれるプロセスのみを表示します。この文字列には正規表現を使用できます。オプション -t をオプション -G とともに使用した場合、そのプロセスに属するスレッドも表示されます。これは、コマンド名に文字列 process_name が含まれない場合でも表示されます。
-H
時刻 (エポック) 以降のタイムスタンプを秒単位で表示します。
-h
すべてのアクティビティを 1行で水平に表示し、レポートの末尾に平均統計を表示しません。これは、他のプログラムによる解析を容易にすることを目的としています。
--human
人間が読める形式でサイズを印刷します (例:1.0k、1.2Mなど)。このオプションで表示される単位は、メトリクスに関連付けられている他の既定の単位 (例:キビバイト、セクタなど) よりも優先されます。
-I
SMP 環境では、タスクの CPU 使用量をオプション -u に表示されているようにプロセッサーの合計値で割るように指示します。
-l
プロセスのコマンド名とそのすべての引数を表示します。
-o JSON
統計情報を JSON (JavaScript Object Notation) 形式で表示します。JSON 出力フィールドの順序は未定義であり、将来新しいフィールドが追加される可能性があります。
-p { pid[,...] | SELF | ALL }
統計情報をレポートするタスク (プロセス) を選択します。pid はプロセスのID番号です。SELF キーワードは、pidstat プロセス自体について統計情報がレポートされることを示します。一方、ALL キーワードは、システムによって管理されるすべてのタスクについて統計情報がレポートされることを示します。
-R
リアルタイムの優先順位およびスケジューリングポリシー情報をレポートします。以下の値が表示されます:
UID
監視されているタスクの実ユーザー識別番号。
USER
監視対象のタスクを所有する実際のユーザーの名前。
PID
監視対象のタスクの ID 番号。
prio
監視されているタスクのリアルタイム優先度。
policy
監視対象のタスクのスケジューリングポリシー。
Command
タスクのコマンド名。
-r
ページフォルトとメモリ使用率をレポートします。

個々のタスクの統計をレポートする場合、次の値が表示されることがあります。

UID
監視されているタスクの実ユーザー識別番号。
USER
監視対象のタスクを所有する実際のユーザーの名前。
PID
監視対象のタスクの ID 番号。
minflt/s
タスクが 1秒間に発生させた、ディスクからメモリページをロードする必要がなかったマイナーフォールトの合計値。
majflt/s
タスクが 1秒あたりに発生した、ディスクからメモリページをロードする必要があったメジャーフォールトの合計値。
VSZ
仮想サイズ: タスク全体の仮想メモリー使用量 (キビバイト)。
RSS
常駐セットサイズ: タスクによって使用される、スワップされない物理メモリー (キビバイト)。
%MEM
タスクが現在使用している、利用可能な物理メモリのシェアです。
Command
タスクのコマンド名。
タスクとそのすべての子のグローバル統計をレポートする場合、次の値が表示されることがあります。
UID
子とともに監視されているタスクの実際のユーザー識別番号。
USER
子とともに監視されているタスクを所有する実際のユーザーの名前。
PID
子とともに監視されているタスクの識別番号。
minflt-nr
計測期間中に収集された、タスクおよびそのすべての子によって発生したマイナー・フォルトの合計値。
majflt-nr
計測期間中に収集された、タスクおよびそのすべての子によって発生したメジャー・フォルトの合計値。
Command
子とともに監視されているタスクのコマンド名。
-s
スタック使用率をレポートします。以下の値が表示されます:
UID
監視されているタスクの実ユーザー識別番号。
USER
監視対象のタスクを所有する実際のユーザーの名前。
PID
監視対象のタスクの ID 番号。
StkSize
タスク用にスタックとして予約されているが、必ずしも使用されていないメモリの量 (キビバイト単位)。
StkRef
スタックとして使用され、タスクによって参照されるキビバイト単位のメモリ量。
Command
タスクのコマンド名。
-T { TASK | CHILD | ALL }
このオプションは、pidstat コマンドで何をモニターするかを指定します。TASK キーワードは、統計情報が個々のタスクについてレポートされることを示します (これは既定のオプションです)。一方、CHILD キーワードは、統計情報が選択したタスクとそのすべての子についてグローバルにレポートされることを示します。ALL キーワードは、統計が個々のタスクに対してレポートされ、また、選択したタスクとその子に対してグローバルにレポートされることを示します。

注意:タスクとそのすべての子のグローバル統計は、pidstat のすべてのオプションで使用できるわけではありません。また、これらの統計は、現在の時間間隔に必ずしも関連しているわけではありません。子プロセスの統計は、子プロセスが終了するか強制終了された場合にのみ収集されます。

-t
選択したタスクに関連付けられているスレッドの統計も表示します。

このオプションによって、レポートに次の値が追加されます。

TGID
スレッド・グループ・リーダーの識別番号。
TID
モニタされているスレッドの ID 番号。
-U [ username ]
UID の代わりに、監視されているタスクの実際のユーザー名を表示します。username が指定されている場合は、指定されたユーザーに属するタスクのみが表示されます。
-u
CPU使用率をレポートします。

個々のタスクの統計をレポートする場合、次の値が表示されることがあります。

UID
監視されているタスクの実ユーザー識別番号。
USER
監視対象のタスクを所有する実際のユーザーの名前。
PID
監視対象のタスクの ID 番号。
%usr
nice 優先順位の有無にかかわらず、ユーザーレベル (アプリケーション) での実行中にタスクが使用した CPU の割合。このフィールドには、仮想プロセッサの実行に費やされた時間は含まれないことに注意してください。
%system
システムレベル (カーネル) での実行中にタスクが使用した CPU の割合。
%guest
仮想マシン内のタスクが消費した CPU の割合 (仮想プロセッサを実行)。
%wait
実行待機中にタスクが消費した CPU の割合。
%CPU
タスクで使用される CPU 時間の合計割合。SMP 環境では、コマンド行上でオプション -I が入力されている場合、タスクの CPU 使用率は CPU の合計値で除算されます。
CPU
タスクがアタッチされているプロセッサ番号。
Command
タスクのコマンド名。
タスクとそのすべての子のグローバル統計をレポートする場合、次の値が表示されることがあります。
UID
子とともに監視されているタスクの実際のユーザー識別番号。
USER
子とともに監視されているタスクを所有する実際のユーザーの名前。
PID
子とともに監視されているタスクの識別番号。
usr-ms
計測期間中に収集された、ユーザーレベル (アプリケーション) での実行中に、nice 優先順位の有無にかかわらず、タスクおよびそのすべての子によって費やされたミリ秒の合計値。このフィールドには、仮想プロセッサの実行に費やされた時間は含まれないことに注意してください。
system-ms
計測時間中に、タスクおよびそのすべての子タスクがシステムレベル (カーネル) での実行中に消費した時間の合計 (ミリ秒単位) です。
guest-ms
仮想マシン (仮想プロセッサを実行している) でタスクとそのすべての子が費やしたミリ秒の合計。
Command
子とともに監視されているタスクのコマンド名。
-V
バージョン番号を出力して終了します。
-v
いくつかのカーネルテーブルの値をレポートします。以下の値が表示されます:
UID
監視されているタスクの実ユーザー識別番号。
USER
監視対象のタスクを所有する実際のユーザーの名前。
PID
監視対象のタスクの ID 番号。
threads
現在のタスクに関連付けられているスレッドの数。
fd-nr
現在のタスクに関連づけられているファイルディスクリプタの数。
Command
タスクのコマンド名。
-w
タスクの切り替えアクティビティ (カーネル2.6.23以降のみ) をレポートします。以下の値が表示されます:
UID
監視されているタスクの実ユーザー識別番号。
USER
監視対象のタスクを所有する実際のユーザーの名前。
PID
監視対象のタスクの ID 番号。
cswch/s
1秒あたりに作成されたタスクを切り替える自発的なコンテキストの合計値。自発的なコンテキストスイッチは、使用できないリソースを必要とするためにタスクがブロックされたときに発生します。
nvcswch/s
1秒あたりに作成されたタスクを切り替える非自発的コンテキストの総数。非自発的なコンテキストスイッチは、タスクがそのタイムスライスの間実行され、その後、強制的にプロセッサを放棄させられたときに発生します。
Command
タスクのコマンド名。

 

環境変数

pidstat コマンドは、次の環境変数を参照します。
S_COLORS
出力がターミナルに接続されている場合、既定では、端末ごとに統計情報がカラーで表示されます。この変数を使用して、設定を変更します。取り得る値は、never、always またはauto (後者は既定の設定と同等ですです。
値の表示に使用されている色 (赤、黄、またはその他の色) は、単に色が原因で何らかの問題が発生していることを示すものではありません。異なる値の範囲を示しているだけです。
S_COLORS_SGR
端末に関する統計情報の表示に使用する色およびその他の属性を指定します。その値は、コロンで区切られたケイパビリティのリストで、既定値は I=32;22:N=34;1:W=35;1:X=31;1:Z=34;22 です。サポートされる機能は次のとおりです:
I=
アイテムの値 (PID、UID、CPU番号など) のための SGR (Select Graphic Rendition) 部分文字列。
N=
ゼロ以外の統計値およびタスク名の SGR 部分文字列。
W= (又は M=)
75%から 90% (またはメトリックの意味に応じて 10%から 25%) の範囲の割合に対する SGR 部分文字列。
X= (又は H=)
割合が 90%以上のSGR 部分文字列 (あるいはメトリックの意味に応じて10%以下)。
Z=
ゼロ値およびスレッド名の SGR 部分文字列。
S_TIME_FORMAT
この変数が存在し、その値が ISO の場合、レポートヘッダーに日付を印刷するときに、現在のロケールが無視されます。pidstatコマンドは、代わりに ISO 8601 形式 (YYYY-MM-DD) を使用します。タイムスタンプも ISO 8601 形式に準拠します。

 

使用例

pidstat 2 5
システムのアクティブタスクごとに、CPU 統計のレポートを 2秒間隔で 5つ表示します。
pidstat -r -p 1643 2 5
PID 1643 のページフォルトとメモリ統計のレポートを 2秒間隔で 5つ表示します。
pidstat -C "fox|bird" -r -p ALL
コマンド名に文字列「fox」または「bird」を含むすべてのプロセスについて、グローバルページフォルトとメモリー統計を表示します。
pidstat -T CHILD -r 2 5
システム内のすべてのタスクの子プロセスについて、ページフォルト統計のレポートを 2秒間隔で 5つ表示します。統計情報の値が 0以外の子プロセスだけが表示されます。

 

バグ

pidstat コマンドが作動するためには、/proc ファイルシステムがマウントされている必要があります。

pidstat は、キロバイト (kB)、メガバイト (MB)…に対応するユニットを表示しますが、実際にはキビバイト (kiB)、メビバイト (MiB)…を使用します。キビバイトは 1024バイト、メビバイトは 1024キビバイトに相当します。

 

ファイル

/proc には、システム統計を含むさまざまなファイルが含まれています。
