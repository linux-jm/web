名前

cifsiostat - CIFS 統計情報を報告します。

 

書式

cifsiostat [ -h ] [ -k | -m | -G ] [ -t ] [ -U ] [ -V ] [ -y ] [ --dec={ 0 | 1 | 2 } ] [ --human ] [ -o JSON ] [ --pretty ] [ interval [ count ] ]

 

説明

cifsiostat コマンドは、CIFS ファイルシステムのリード/ライト処理に関する統計情報を表示します。

interval パラメータは、各レポート間の時間間隔を秒単位で指定します。最初のレポートには、-y オプションが使用されている場合を除き、システムの起動 (ブート) 以降の時間の統計情報が含まれます (この場合、最初のレポートは省略されます)。以降の各レポートには、前回のレポート以降のインターバル中に収集された統計情報が含まれます。レポートは、CIFS ヘッダ行があり、マウントされている各 CIFS ファイルシステムの統計情報の行が後に続く形で構成されています。count パラメータは、interval パラメータと一緒に指定できます。count パラメータが指定されている場合、count の値は、interval 秒間隔で生成されるレポートの数を決定します。interval パラメータを指定せずにcount パラメータを指定した場合、cifsiostat コマンドはレポートを継続的に生成します。

 

レポート

CIFS レポートは、マウントされている CIFS ファイルシステムごとに統計情報を提供します。レポートには、次のフィールドが表示されます。

Filesystem:
この列には、CIFS ファイルシステムのマウントポイントが表示されます。
rB/s (rkB/s, rMB/s, rGB/s)
1秒当たりに読み取られた平均バイト数 (キビバイト、メビバイト、ギビバイト) を表示します。
wB/s (wkB/s, wMB/s, wGB/s)
1秒間に書き込まれる平均バイト数 (キビバイト、メビバイト、ギビバイト)を表示します。
rop/s
ファイルシステムに対して発行された1秒あたりの「読み取り」操作の数を表示します。
wop/s
ファイルシステムに対して発行された1秒あたりの「書き込み」操作の数を表示します。
fo/s
1秒あたりに開いたファイルの数を表示します。
fc/s
1秒当たりにクローズされたファイルの数を表示します。
fd/s
1秒あたりに削除されたファイルの数を表示します。

 

オプション

--dec={ 0 | 1 | 2 }
小数点以下の桁数を指定します (0～2、既定値は2)。
-G
統計情報を 1秒あたりのギビバイト数で表示します。
-h
このオプションは、--human --pretty と同じです。
--human
人間が読める形式でサイズを印刷します (例:1.0k、1.2Mなど)。このオプションで表示される単位は、メトリクスに関連付けられている他の既定の単位 (例:キビバイト、セクタなど) よりも優先されます。
-k
統計情報をキビバイト/秒単位で表示します。
-m
統計情報をメビバイト/秒単位で表示します。
-o JSON
統計情報を JSON (JavaScript Object Notation) 形式で表示します。JSON 出力フィールドの順序は未定義であり、将来新しいフィールドが追加される可能性があります。
--pretty
CIFS レポートを人間が読みやすくします。
-t
表示される各レポートに時間を印刷します。タイムスタンプのフォーマットは、S_TIME_FORMAT 環境変数 (下記参照) の値と、オプション -U が使用されたかどうかに依存します。
-U
エポックからのタイムスタンプ (UTC-Coordinated Universal Time) を秒単位で表示します。
-V
バージョン番号を出力して終了します。
-y
指定された間隔で複数のレコードを表示する場合は、システム起動後の統計情報を含む最初のレポートを省略します。

 

環境変数

cifsiostat コマンドは、次の環境変数を参照します。
S_COLORS
出力がターミナルに接続されている場合、既定では、端末ごとに統計情報がカラーで表示されます。この変数を使用して、設定を変更します。取り得る値は、never、always または auto (後者は既定の設定と同等)です。
値の表示に使用されている色 (赤、黄、またはその他の色) は、単に色が原因で何らかの問題が発生していることを示すものではありません。異なる値の範囲を示しているだけです。
S_COLORS_SGR
端末に関する統計情報の表示に使用する色およびその他の属性を指定します。その値は、コロンで区切られたケイパビリティのリストで、既定値はI=32;22:N=34;1:Z=34;22 です。サポートされる機能は次のとおりです:
I=
ファイルシステム名を表示する SGR 部分文字列。
N=
ゼロ以外の統計値を表示する SGR 部分文字列。
Z=
ゼロ値を表示する SGR 部分文字列。
S_TIME_FORMAT
この変数が存在し、その値が ISO の場合、レポートヘッダーに日付を印刷するときに、現在のロケールが無視されます。cifsiostat コマンドは、代わりに ISO 8601 形式 (YYYY-MM-DD) を使用します。オプション -t で表示されるタイムスタンプも ISO 8601 形式に準拠します。

 

バグ

/proc ファイルシステムは cifsiostat を作動させるために必ずマウントしなければなりません。

cifsiostatは、キロバイト (kB)、メガバイト (MB)、ギガバイト (GB)…に対応するユニットを表示しますが、実際にはキビバイト (kiB)、メビバイト (MiB)、ギビバイト (GiB)…を使用します。キビバイトは 1024バイト、メビバイトは 1024キビバイト、ギビバイトは 1024メビバイトです。

 

ファイル

/proc/fs/cifs/Stats には、CIFS統計情報が含まれます。
