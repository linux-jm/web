名前

tapestat - テープの統計情報をレポートします。

 

書式

tapestat [ -k | -m | -G ] [ -t ] [ -U ] [ -V ] [ -y ] [ -z ] [ --human ] [ -o JSON ] [ interval [ count ] ]

 

説明

tapestat コマンドは、システムに接続されているテープドライブのアクティビティを監視するために使用されます。

tapestat コマンドによって生成される最初のレポートは、システムがブートされてからの時間に関する統計情報を提供します。ただし、-y オプションが使用されると、この最初のレポートが省略されます。後続の各レポートには、前のレポート以降の時間が含まれます。

interval パラメータは、各レポート間の時間間隔を秒単位で指定します。count パラメータは、interval パラメータと一緒に指定できます。count パラメータが指定されている場合、count の値は、interval 秒間隔で生成されるレポートの数を決定します。count パラメータを指定せずに interval パラメータを指定した場合、tapestat コマンドはレポートを継続的に生成します。

 

レポート

tapestat レポートには、システムに接続されている各テープドライブの統計情報が表示されます。次のデータが表示されます:
r/s
この期間で発行された読み取り数の、1秒あたりの平均回数。
w/s
この期間で発行された書き込み数の、1秒あたりの平均回数。
kB_read/s | MB_read/s | GB_read/s
期間中に平均化された読み取りデータ量を、キビバイト単位 (既定値またはオプション -k 使用の場合、オプション -m 使用の場合はメビバイト、オプション -G 使用の場合はギビバイト)で表したもの。
kB_wrtn/s | MB_wrtn/s | GB_wrtn/s
期間中に平均化された書き込みデータ量を、キビバイト単位 (既定値またはオプション -k 使用の場合、オプション -m 使用の場合はメビバイト、またはオプション -G 使用の場合はギビバイト)で表したもの。
%Rd
読み込み待機率 - 読み取り要求が完了するまでの待機に費やされた期間中の時間の割合。この時間は、リクエストが SCSI 中間レイヤにディスパッチされてから、リクエストが完了したことを示す信号が送信されるまでの時間を測定します。
%Wr
書き込み待機率 - 書き込み要求が完了するまでの待機に費やされた期間中の時間の割合。この時間は、リクエストが SCSI 中間レイヤにディスパッチされてから、リクエストが完了したことを示す信号が送信されるまでの時間を測定します。
%Oa
全体の待機率 - I/O 要求 (読み取り、書き込み、およびその他)の完了を待つために費やされた、期間中の時間の割合。
Rs/s
0 以外の残余値が検出された場合の、 期間中の平均化された1秒あたりのI/O の数。
Ot/s
「その他」として含まれる、期間中に平均化された1秒あたりの I/O の数。その他の I/O には、テープドライバに対する ioctl 呼び出しや、テープドライバによって実行される暗黙的な操作 (「閉じるときに巻き戻す」を実装しているテープデバイスの場合) が含まれます。これには、テープドライバ以外の方法 (sg ioctlsなど) で実行された I/O は含まれません。

 

オプション

-G
1秒あたりに書き込まれた、または読み取られたギビバイト単位でのデータ量を示します。このオプションは、-k および -m と同時に指定できません。
--human
人間が読める形式でサイズを印刷します (例:1.0k、1.2Mなど)。このオプションで表示される単位は、メトリクスに関連付けられている他の既定の単位 (例:キビバイト、セクタなど) よりも優先されます。
-k
書き込みまたは読み取りされたデータ量を、メビバイトではなくキビバイト/秒で表示します。このオプションは、-G および -m と同時に指定できません。
-m
書き込みまたは読み取りされたデータ量を、キビバイトではなくメビバイト/秒で表示します。このオプションは、-G および -k と同時に指定できません。
-o JSON
統計情報を JSON (JavaScript Object Notation) 形式で表示します。JSON 出力フィールドの順序は未定義であり、将来新しいフィールドが追加される可能性があります。
-t
タイムスタンプを表示します。タイムスタンプの形式は、環境変数 S_TIME_FORMAT (以下を参照)の値と、オプション -U が使用されたかどうかによって異なります。
-U
エポックからのタイムスタンプ (UTC-Coordinated Universal Time) を秒単位で表示します。
-V
バージョンを出力して終了します。
-y
ブート以降の値を示す初期統計を省略します。
-z
tapestat に、サンプル期間中に活動がなかったテープの出力を省略するように指示します。

 

考慮事項

読み取り、書き込み、その他の割合の値が 100% を超える場合もあります(tapestat コマンドを実行しても、999を超える割合の値は表示されません)。インターバルが 5秒の場合に、テープの巻き戻しに 40秒かかるとすると、インターバル中、巻き戻しが完了するまでの %Oa 値は 0と表示され、巻き戻しが完了すると約 800% と表示されます。

テープドライブが読み取りまたは書き込みを停止し、その後再起動した場合 (つまり、ストリーミングを停止した場合)、%Rd と %Wr に同様の値が見られます。この場合、読み取りまたは書き込みが続行されると、r/s または w/s が 0に低下し、%Rd / %Wr 値が 100を超えることがあります (書き込みまたは読み取りの再開にかかる時間によって異なります)。これが問題になるのは、頻繁に発生する場合だけで、テープが摩耗し、バックアップ時間に影響が出る可能性があります。

高速テープドライブでは、待機時間の割合が低くなる場合があります。これは、テープドライブの問題を示すものではありません。低速のテープドライブ (旧世代の DDS ドライブなど) では、テープ (およびテープドライブ) の速度がファイルシステム入出力よりもはるかに遅いため、待機時間の割合が高くなる可能性があります。より高速なテープドライブ (LTO など) の場合、待機時間の割合は小さくなります。これは、テープに対して書き込みまたは読み取りを行うプログラムは、スループットが高いため、より多くのファイルシステム入出力を行うためです。

テープ統計は、アトミック変数を使用してカーネル内に実装されますが、グループとしてアトミックに読み取ることはできません。/sys ではすべての統計値が別々のファイルから読み取られるため、1つのテープドライブで別々のファイルを読み取っている間に入出力が完了することがあります。これにより、デバイスの一連の統計情報に、I/O が完了する前の値と完了した後の値が含まれる場合があります。

このコマンドは、秒単位の統計情報を計算するときに、丸め方式として切り捨てを使用します。たとえば、あるテープを別のテープにコピーするために dd を使用し、5秒の間隔で tapestat を実行し、3210回の書き込みと 3209回の読み取りが行われた場合、w/s は 642、r/s は 641 と表示されます (641.8 は641 に切り捨てられます)。この場合、tar アーカイブを (10kのブロックサイズで) コピーすると、kB_read/s と kB_wrtn/s の差 は 2 (サイズが 10k の 1つの I/O を 5秒のインターバルで割った値) になります。代わりに、3210回の書き込みと 3211回の読み取りがあった場合、w/s と r/s の両方が 642 と表示されますが、kB_read/s と kB_wrtn/s の値の違いは2 kB/sです。

このコマンドは、間隔を秒単位で指定されています。ただし、内部的には間隔はデバイスごとに追跡され、報告される 1秒あたりの統計情報に影響を与える可能性があります。統計情報の各セットがキャプチャされた時刻は、それらの統計情報とともに保持されます。現在の時刻と前回の時刻の差は、計算で使用するためにミリ秒に変換されます。たとえば、dd を使用して 2つのテープドライブ間で tar アーカイブをコピーする例を使用して、これがレポートされる統計にどのように影響するかを見ることができます。両方のデバイスが 28900キビバイトの転送を報告し、読み取りテープドライブの間隔が 5001ミリ秒、書き込みテープドライブの間隔が 5000ミリ秒の場合、計算される値は 5778 kB_read/s および 5780 kB_wrtn/s になります。

I/O 完了時の一部の統計情報の取得、切り捨て、および計算された統計情報の時間間隔内のわずかな違いの影響は、最小限である必要がありますが、ゼロ以外の場合もあります。

 

環境変数

tapestat コマンドは、次の環境変数を参照します。
S_COLORS
出力がターミナルに接続されている場合、既定では、端末ごとに統計情報がカラーで表示されます。この変数を使用して、設定を変更します。取り得る値は、never、always またはauto (後者は既定の設定と同等ですです。
値の表示に使用されている色 (赤、黄、またはその他の色) は、単に色が原因で何らかの問題が発生していることを示すものではありません。異なる値の範囲を示しているだけです。
S_COLORS_SGR
端末に関する統計情報の表示に使用する色およびその他の属性を指定します。その値は、コロンで区切られたケイパビリティのリストで、既定値は I=32;22:N=34;1:W=35;1:X=31;1:Z=34;22 です。サポートされる機能は次のとおりです:
I=
テープ名の SGR (Select Graphic Rendition) 部分文字列。
N=
ゼロ以外の統計値を表示する SGR 部分文字列。
W= (又は M=)
75%から 90% (またはメトリックの意味に応じて 10%から 25%) の範囲の割合に対する SGR 部分文字列。
X= (又は H=)
割合が 90%以上のSGR 部分文字列 (あるいはメトリックの意味に応じて10%以下)。
Z=
ゼロ値を表示する SGR 部分文字列。
S_TIME_FORMAT
この変数が存在し、その値が ISO の場合、レポートヘッダーに日付を印刷するときに、現在のロケールが無視されます。tapestat コマンドは、代わりに ISO 8601 形式 (YYYY-MM-DD) を使用します。オプション -t で表示されるタイムスタンプも ISO 8601 形式に準拠します。

 

バグ

/proc ファイルシステムは tapestat を作動させるために必ずマウントしなければなりません。sysfs をサポートしていないカーネルでは動作しません。

このコマンドを使用するには、カーネルバージョン 4.2以降が必要です (または、以前のバージョンのカーネルにバックポートされたテープ統計情報サポートが必要です)。

tapestat は、キロバイト (kB)、メガバイト (MB)、ギガバイト (GB)…に対応するユニットを表示しますが、実際にはキビバイト (kiB)、メビバイト (MiB)、ギビバイト (GiB)…を使用します。キビバイトは 1024バイト、メビバイトは 1024キビバイト、ギビバイトは 1024メビバイトです。

 

ファイル

/sys/class/scsi_tape/st<num>/stats/*
テープデバイスの統計情報ファイル。

/proc/uptime にはシステムの稼働時間が含まれます。
