IOSTAT

Updated: 2026年 8月
Index JM Home Page roff page
 

名前

CPU の統計と、 デバイスとパーティションの入出力の統計をレポートします。

 

書式

iostat [ -c ] [ -d ] [ -h ] [ -k | -m | -G ] [ -N ] [ -s ] [ -t ] [ -U ] [ -V ] [ -x ] [ -y ] [ -z ] [ --compact ] [ --dec={ 0 | 1 | 2 } ] [ { -f | +f } directory ] [ -j { ID | LABEL | PATH | UUID | ... } ] [ -o JSON ] [ [ -H ] -g group_name ] [ --human ] [ --pretty ] [ -p [ device[,...] | ALL ] ] [ device [...] | ALL ] [ interval [ count ] ]

 

説明

iostat コマンドは、システムの入出力デバイスの負荷を監視するために使用します。このコマンドは、デバイスの平均転送速度に対してデバイスがアクティブになっている時間を監視します。iostat コマンドは、システム構成を変更して物理ディスク間の入出力負荷のバランスを改善するために使用できるレポートを生成します。

iostat コマンドによって生成される最初のレポートは、システムがブートされてからの経過時間に関する統計情報を提供します。ただし、-y オプションが使用されている場合は、この最初のレポートは省略されます。後続の各レポートには、前のレポート以降の時間が含まれます。iostat コマンドを実行するたびに、すべての統計情報が報告されます。レポートは、CPU ヘッダー行と、それに続く CPU 統計情報の行で構成されます。マルチプロセッサシステムでは、CPU 統計はシステム全体で、すべてのプロセッサ間の平均として計算されます。デバイスヘッダ行が表示され、そのあとに、設定されている各デバイスの統計情報行が表示されます。

interval パラメータは、各レポート間の時間間隔を秒単位で指定します。count パラメータは、interval パラメータと一緒に指定できます。count パラメータが指定されている場合、count の値は、interval 秒間隔で生成されるレポートの数を決定します。interval パラメータを指定せずにcount パラメータを指定した場合、iostat コマンドはレポートを継続的に生成します。

 

レポート

iostat コマンドは、CPU 利用レポートとデバイス利用レポートの 2種類のレポートを生成します。

CPU 利用レポート
iostat コマンドによって生成される最初のレポートは、CPU 利用レポートです。マルチプロセッサシステムの場合、CPU の値はすべてのプロセッサの全体的な平均値です。レポートの形式は次のとおりです:
%user
ユーザーレベル (アプリケーション) での実行中に発生する CPU 使用率の割合を示します。
%nice
nice 優先度を使用してユーザレベルでの実行中に発生した CPU 使用率の割合を表示します。
%system
システムレベル (カーネル) での実行中に発生した CPU 使用率の割合を表示します。
%iowait
CPU がアイドル状態で、システムに未処理のディスク I/O 要求があった時間の割合を表示します。
%steal
ハイパーバイザーが別の仮想プロセッサーにサービスを提供している間に、1つまたは複数の仮想 CPU による強制待機に費やされた時間割合を表示します。
%idle
CPU がアイドル状態で、システムに未処理のディスク I/O 要求がなかった時間の割合を表示します。

デバイス利用レポート
iostat コマンドによって生成される2番目のレポートは、デバイス利用レポートです。デバイスレポートは、物理デバイスまたはパーティション単位で統計情報を提供します。統計情報を表示するブロックデバイスとパーティションは、コマンド行で指定できます。デバイスもパーティションも入力されていない場合は、システムで使用されているすべてのデバイスの統計情報が表示されます。ただし、カーネルがそのデバイスの統計情報を管理している場合に限ります。コマンド行で ALL キーワードを指定した場合は、一度も使用されていないデバイスも含め、システムで定義されているすべてのデバイスの統計情報が表示されます。転送速度は、既定値ごとに 1024バイトのブロック数で表示されます。ただし、環境変数 POSIXLY_CORRECT が設定されている場合は、 512バイトのブロック数が使用されます。レポートには、使用されているフラグに応じて、次のフィールドが表示されます(例: -x、-s および -k、-m または -G):
デバイス:
このカラムは、/dev ディレクトリにリストされているデバイス (またはパーティション) 名を示します。
tps
デバイスに対して発行された 1秒あたりの転送数を示します。転送とは、デバイスへの I/O 要求です。複数の論理要求を、デバイスに対する 1つの I/O 要求にまとめることもあります。転送サイズは不定です。
Blk_read/s (kB_read/s, MB_read/s, GB_read/s)
デバイスから読み取られたデータ量を、1秒あたりのブロック数 (キビバイト、メビバイト、ギビバイト) で示します。ブロックはセクタと同等であるため、サイズは 512バイトです。
Blk_wrtn/s (kB_wrtn/s, MB_wrtn/s, GB_wrtn/s)
デバイスに書き込まれたデータ量を、1秒あたりのブロック数 (キビバイト、メビバイト、ギビバイト) で示します。
Blk_dscd/s (kB_dscd/s, MB_dscd/s, GB_dscd/s)
デバイスで破棄されたデータの量を、1秒あたりのブロック数(キビバイト、メビバイト、ギビバイト)で示します。
Blk_w+d/s (kB_w+d/s, MB_w+d/s, GB_w+d/s)
デバイスに対して書き込まれた、または破棄されたデータの量を、1秒あたりのブロック数 (キビバイト、メビバイト、ギビバイト) で示します。
Blk_read (kB_read, MB_read, GB_read)
読み取られたブロックの合計値 (キビバイト、メビバイト、ギビバイト)。
Blk_wrtn (kB_wrtn, MB_wrtn, GB_wrtn)
書き込まれたブロックの合計値 (キビバイト、メビバイト、ギビバイト)。
Blk_dscd (kB_dscd, MB_dscd, GB_dscd)
破棄されたブロック (キビバイト、メビバイト、ギビバイト) の総数。
Blk_w+d (kB_w+d, MB_w+d, GB_w+d)
書き込まれたか、または破棄されたブロックの総数 (キビバイト、メビバイト、ギビバイト)。
r/s
デバイスで 1秒間に完了した読み込み要求数 (マージ後)。
w/s
デバイスで1秒間に完了した書き込み要求数 (マージ後)。
d/s
デバイスで 1秒間に完了した廃棄要求の数 (マージ後)。
f/s
デバイスで1秒間に完了したフラッシュ要求数 (マージ後)。これは、ディスクによって実行されたフラッシュ要求をカウントします。フラッシュ要求は、パーティションについては追跡されません。フラッシュ操作は、マージされる前は書き込みとしてカウントされます。
sec/s (kB/s, MB/s, GB/s)
デバイスでの 1秒あたりの読み取り、書き込み、または破棄されたセクター数 (キビバイト、メビバイト、ギビバイト)。
rsec/s (rkB/s, rMB/s, rGB/s)
デバイスから読み取られた 1秒あたりのセクタ数 (キビバイト、メビバイト、ギビバイト)。
wsec/s (wkB/s, wMB/s, wGB/s)
デバイスに書き込まれた 1秒あたりのセクタ数 (キビバイト、メビバイト、ギビバイト)。
dsec/s (dkB/s, dMB/s, dGB/s)
デバイスで破棄された 1秒あたりのセクタ数 (キビバイト、メビバイト、ギビバイト)。
rqm/s
1秒間にマージされ、デバイスのキューに入れられた I/O 要求の数。
rrqm/s
デバイスのキューに入れられた 1秒あたりのマージされた読み込み要求数。
wrqm/s
デバイスのキューに入れられた、1秒あたりのマージされた書き込み要求数。
drqm/s
マージされ、デバイスのキューに入れられた 1秒あたりの破棄要求の数。
%rrqm
デバイスに送信される前にマージされた読み取り要求の割合。
%wrqm
デバイスに送信される前にマージされた書き込み要求の割合。
%drqm
デバイスに送信される前にマージされた廃棄要求の割合。
areq-sz
デバイスに対して発行された I/O リクエストの平均サイズ (キビバイト)
注:以前のバージョンでは、このフィールドは avgrq-sz と呼ばれ、セクタ単位で表されていました。
rareq-sz
デバイスに対して発行された読み取り要求の平均サイズ (キビバイト)
wareq-sz
きびデバイスに対して発行された書き込み要求の平均サイズ (キビバイト)
dareq-sz
デバイスに対して発行された破棄要求の平均サイズ (キビバイト)。
await
サービス対象のデバイスに対して発行された I/O 要求の平均時間 (ミリ秒単位)。これには、キュー内の要求に費やされた時間と、それらの要求の処理に費やされた時間が含まれます。
r_await
サービス対象のデバイスに対して発行された読み取り要求の平均時間 (ミリ秒単位)。これには、キュー内の要求に費やされた時間と、それらの要求の処理に費やされた時間が含まれます。
w_await
サービス対象のデバイスに対して発行された書き込み要求の平均時間 (ミリ秒単位)。これには、キュー内の要求に費やされた時間と、それらの要求の処理に費やされた時間が含まれます。
d_await
サービス対象のデバイスに対して発行された廃棄要求の平均時間 (ミリ秒単位)。これには、キュー内の要求に費やされた時間と、それらの要求の処理に費やされた時間が含まれます。
f_await
サービス対象のデバイスに対して発行されたフラッシュ要求の平均時間 (ミリ秒単位)。ブロック層はフラッシュ要求を結合し、一度に多くても 1つしか実行しません。したがって、フラッシュ操作には 2倍の時間がかかる可能性があります。現在のフラッシュ要求を待ってから実行し、次のフラッシュ要求を待ちます。
aqu-sz
デバイスに対して発行された要求の平均キュー長。
注: 以前のバージョンでは、このフィールドは avgqu-sz と呼ばれていました。
%util
I/O リクエストがデバイスに発行された経過時間の割合 (デバイスの帯域幅使用率)。デバイスが連続して要求を処理する場合、この値が 100%に近いと、デバイスが飽和状態になります。ただし、RAID アレイや最新の SSD など、リクエストを並行して処理するデバイスの場合、この数値はパフォーマンスの制限を反映していません。

 

オプション

-c
CPU 使用率レポートを表示します。
--compact
すべてのメトリクスが 1行で表示されるように、デバイス使用率レポートをサブレポートに分割しません。
-d
デバイスの使用状況レポートを表示します。
--dec={ 0 | 1 | 2 }
小数点以下の桁数を指定します (0～2、既定値は2)。
-f directory
+f directory
デバイス統計を読み込むため、iostat に代替ディレクトリを指定します。オプション-f は、代替ディレクトリにあるファイルだけを使用するように iostat に指示します、オプション +f は、標準カーネルファイルと代替ディレクトリにあるファイルの両方を使用してデバイス統計を読み取るように指示します。

directory はユーザ空間で管理されているデバイスの統計情報を含むファイルを含むディレクトリです。以下を含めることができます:

- "diskstats" ファイル。このフォーマットは、"/proc" にあるフォーマットに準拠しています。
- "/sys" にあるファイルとフォーマットが一致するファイルに含まれている、個々のデバイスの統計情報。

特に、directory にある以下のファイルは、iostat によって使用され得ます:

directory/block/device/stat
directory/block/device/partition/stat

partition ファイルは、directory/dev/block/ ディレクトリにエントリが必要です。例:

directory/dev/block/major:minor --> ../../block/device/partition

-G
統計情報を 1秒あたりのギビバイト数で表示します。
-g group_name { device [...] | ALL }
デバイスグループの統計情報を表示します。iostat コマンドは、リスト内の個々のデバイスの統計情報を報告してから、リスト内のすべてのデバイスで構成される、group_name として表示される、グループのグローバル統計情報を 1行で報告します。ALL キーワードは、システムによって定義されたすべてのブロックデバイスがグループに含まれることを意味します。
-H
このオプションは、オプション -g と共に使用しなければなりません。このオプションを使用すると、グループのグローバル統計情報だけが表示され、グループ内の個々のデバイスの統計情報は表示されなくなります。
-h
このオプションは、--human --pretty と同じです。
--human
人間が読める形式でサイズを印刷します (例:1.0k、1.2Mなど)。このオプションで表示される単位は、メトリクスに関連付けられている他の既定の単位 (例:キビバイト、セクタなど) よりも優先されます。
-j { ID | LABEL | PATH | UUID | ... } [ device [...] | ALL ]
永続デバイス名を表示します。キーワードID、LABEL などは、永続的な名前のタイプを指定します。これらのキーワードに制限はありません。唯一の前提条件は、必要な永続的な名前を持つディレクトリが /dev/disk に存在することです。必要に応じて、選択した永続的な名前タイプに複数のデバイスを指定できます。これは、永続デバイス名は通常長いため、オプション --pretty では暗黙的にこのオプションが設定されます。
-k
統計情報をキビバイト/秒単位で表示します。
-m
統計情報をメビバイト/秒単位で表示します。
-N
すべてのデバイスマッパーデバイスの登録済みデバイスマッパー名を表示します。LVM2 の統計情報を表示する場合に便利です。
-o JSON
統計情報を JSON (JavaScript Object Notation) 形式で表示します。JSON 出力フィールドの順序は未定義であり、将来新しいフィールドが追加される可能性があります。
-p [ { device[,...] | ALL } ]
システムで使用されているブロックデバイスとそのすべてのパーティションの統計情報を表示します。コマンド行にデバイス名を入力すると、そのデバイスとそのすべてのパーティションの統計情報が表示されます。最後に、ALL キーワードは、一度も使用されていないものも含め、システムによって定義されたすべてのブロックデバイスおよびパーティションについて統計情報を表示する必要があることを示します。このオプションの前にオプション -j が定義されている場合は、選択した永続的な名前のタイプを使用して、コマンド行に登録されているデバイスを指定できます。
--pretty
デバイス使用レポートを人間が読みやすくします。デバイス名は右側に印刷されます。表示するメトリックが多い場合は、レポートを複数のサブレポートに分割することもできます (--compact オプションでこれを回避できます)。
-s
80文字幅の画面に収まる短い (幅の狭い) バージョンのレポートを表示します。
-t
表示される各レポートに時間を印刷します。タイムスタンプのフォーマットは、S_TIME_FORMAT 環境変数 (下記参照) の値と、オプション -U が使用されたかどうかに依存します。
-U
エポックからのタイムスタンプ (UTC-Coordinated Universal Time) を秒単位で表示します。
-V
バージョン番号を出力して終了します。
-x
拡張統計情報を表示します。
-y
指定された間隔で複数のレコードを表示する場合は、システム起動後の統計情報を含む最初のレポートを省略します。
-z
iostatに、サンプル期間中にアクティビティがなかったデバイスの出力を省略するように指示します。

 

環境変数

iostat コマンドは、次の環境変数を参照します。
POSIXLY_CORRECT
このパラメータを設定すると、転送速度が既定値の 1024バイトのブロックではなく、512バイトのブロックで表示されます。
S_COLORS
出力がターミナルに接続されている場合、既定では、端末ごとに統計情報がカラーで表示されます。この変数を使用して、設定を変更します。取り得る値は、never、always またはauto (後者は既定の設定と同等ですです。
値の表示に使用されている色 (赤、黄、またはその他の色) は、単に色が原因で何らかの問題が発生していることを示すものではありません。異なる値の範囲を示しているだけです。
S_COLORS_SGR
端末に関する統計情報の表示に使用する色およびその他の属性を指定します。その値は、コロンで区切られたケイパビリティのリストで、既定値は I=32;22:N=34;1:W=35;1:X=31;1:Z=34;22 です。サポートされる機能は次のとおりです:
I=
デバイス名の SGR (Select Graphic Rendition) 部分文字列。
N=
ゼロ以外の統計値を表示する SGR 部分文字列。
W= (又は M=)
75%から 90% (またはメトリックの意味に応じて 10%から 25%) の範囲の割合に対する SGR 部分文字列。
X= (又は H=)
割合が 90%以上のSGR 部分文字列 (あるいはメトリックの意味に応じて10%以下)。
Z=
ゼロ値を表示する SGR 部分文字列。
S_TIME_FORMAT
この変数が存在し、その値が ISO の場合、レポートヘッダーに日付を印刷するときに、現在のロケールが無視されます。iostat コマンドは、代わりに ISO 8601 形式 (YYYY-MM-DD) を使用します。オプション -t で表示されるタイムスタンプも ISO 8601 形式に準拠します。

 

使用例

iostat
すべての CPU およびデバイスについて、ブート以降の履歴レポートを 1つ表示します。
iostat -d 2
2秒間隔で継続的なデバイスレポートを表示します。
iostat -d 2 6
すべてのデバイスについて、2秒間隔で 6つのレポートを表示します。
iostat -x sda sdb 2 6
デバイス sda と sdb について、拡張統計情報の 6つのレポートを 2秒間隔で表示します。
iostat -p sda 2 6
デバイス sdaとそのすべてのパーティション (sda1 など)に関する 6つのレポートを 2秒間隔で表示します。

 

バグ

/proc ファイルシステムは iostat を作動させるために必ずマウントしなければなりません。

2.6.x より古いカーネルはサポートされなくなりました。

iostatは、キロバイト (kB)、メガバイト (MB)、ギガバイト (GB)…に対応するユニットを表示しますが、実際にはキビバイト (kiB)、メビバイト (MiB)、ギビバイト (GiB)…を使用します。キビバイトは 1024バイト、メビバイトは 1024キビバイト、ギビバイトは 1024メビバイトです。

 

ファイル

/proc/stat にはシステム統計が含まれます。
/proc/uptime にはシステムの稼働時間が含まれます。
/proc/diskstats にはディスクの統計が含まれます。
/sys にはブロックデバイスの統計情報が含まれます。
/proc/self/mountstats にはネットワークファイルシステムの統計情報が含まれます。
/dev/disk 永続的なデバイス名が含まれます。
