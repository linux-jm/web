名前

mpstat - プロセッサ関連の統計情報を報告します。

 

書式

mpstat [ -A ] [ --dec={ 0 | 1 | 2 } ] [ -H ] [ -n ] [ -U ] [ -u ] [ -T ] [ -V ] [ -I { keyword[,...] | ALL } ] [ -N { node_list | ALL } ] [ -o JSON ] [ -P { cpu_list | ALL } ] [ interval [ count ] ]

 

説明

mpstat コマンドは、使用可能な各プロセッサのアクティビティを標準出力に書き込みます。プロセッサ 0が最初のプロセッサです。すべてのプロセッサ間のグローバル平均アクティビティも報告されます。mpstat コマンドは、SMP マシンと UP マシンの両方で使用できますが、後者では、グローバル平均アクティビティのみが出力されます。アクティビティを選択していない場合は、既定のレポートは CPU 使用率レポートになります。

interval パラメータは、各レポート間の時間間隔を秒単位で指定します。値がゼロ (またはパラメータなし) は、システムの起動 (ブート) 以降のプロセッサ統計情報がレポートされることを示します。count パラメータは、interval パラメータがゼロに設定されていない場合は、interval パラメータと組み合わせて指定できます。count の値は、interval 秒間隔で生成されるレポートの数を決定します。count パラメータを指定せずに interval パラメータを指定した場合、mpstatコマンドはレポートを継続的に生成します。

 

オプション

-A
このオプションは、-n -u -I ALL と同じです。このオプションは、-N ALL -P ALL が指定されていることを仮定しますが、これらのオプションがコマンド行で明示的に設定されている場合を除きます。
--dec={ 0 | 1 | 2 }
小数点以下の桁数を指定します (0～2、既定値は2)。
-H
また、物理的にホットプラグされた vCPU の統計を検出して表示します。
-I { keyword[,...] | ALL }
割り込み情報の統計をレポートします。keyword が取り得る値は、CPU、SCPU、および SUM です。

CPU キーワードを指定すると、CPU が 1秒間に受信した個々の割り込みの数が表示されます。割り込みは、/proc/interrupts ファイルにリストされているものです。

SCPU キーワードを指定すると、1つまたは複数のソフトウェア割り込みが 1秒間に受信した各 CPU の数が表示されます。このオプションはカーネル 2.6.31 以降でのみ動作します。ソフトウェア割り込みは、/proc/softirqs ファイルにリストされているものです。

SUM キーワードを指定して mpstat コマンドを実行すると、プロセッサごとの割り込みの総数が表示されます。次の値が表示されます:

CPU
プロセッサ番号。キーワード all は、統計情報がすべてのプロセッサ間の平均として計算されることを示します。

intr/s
1つまたは複数の CPU が 1秒間に受信した割り込みの合計値を表示します。
ALL キーワードは、上記のすべてのキーワードを指定するのと同じであるため、すべての割り込み統計情報が表示されます。
-N { node_list | ALL }
統計情報を報告する NUMA ノードを指定します。node_list はカンマで区切られた値のリストまたは値の範囲です (例: 0,2,4-7,12-)。ノード all は、すべてのノードの全体平均ということに注意してください。ALL キーワードは、すべてのノードについて統計情報がレポートされることを示します。
-n
NUMA ノードの配置に基づいて、CPU 統計のサマリーをレポートします。次の値が表示されます:
NODE
論理 NUMA ノード番号。キーワード all は、統計情報がすべてのノード間の平均として計算されることを示します。
他のすべてのフィールドは、オプション -u で表示されるものと同じです (下記参照)。
-o JSON
統計情報を JSON (JavaScript Object Notation) 形式で表示します。JSON 出力フィールドの順序は未定義であり、将来新しいフィールドが追加される可能性があります。
-P { cpu_list | ALL }
統計情報を報告するプロセッサを指定します。cpu_list はカンマで区切られた値のリストまたは値の範囲です (例:0,2,4-7,12-)。プロセッサ 0が最初のプロセッサであり、プロセッサ all はすべてのプロセッサ間のグローバル平均であることに注意してください。ALL キーワードは、すべてのプロセッサについて統計情報がレポートされることを示します。オフラインのプロセッサは表示されません。
-T
CPU レポートにトポロジ要素を表示します (下記のオプション -u を参照)。次の要素が表示されます:
CORE
論理コア番号。
SOCK
論理ソケット番号。
NODE
論理 NUMA ノード番号。
-U
エポックからのタイムスタンプ (UTC-Coordinated Universal Time) を秒単位で表示します。
-u
CPU使用率をレポートします。次の値が表示されます:
CPU
プロセッサ番号。キーワードall は、統計情報がすべてのプロセッサ間の平均として計算されることを示します。
%usr
ユーザーレベル (アプリケーション) での実行中に発生する CPU 使用率の割合を示します。
%nice
nice 優先度を使用してユーザレベルでの実行中に発生した CPU 使用率の割合を表示します。
%sys
システムレベル (カーネル) での実行中に発生した CPU 使用率の割合を表示します。これには、ハードウェアのサービスおよびソフトウェア割り込みに費やされる時間は含まれないことに注意してください。
%iowait
CPU がアイドル状態で、システムに未処理のディスク I/O 要求があった時間の割合を表示します。
%irq
CPU がハードウェア割り込みを処理するために費やした時間の割合を表示します。
%soft
CPU がソフトウェア割り込みを処理するために費やした時間の割合を表示します。
%steal
ハイパーバイザーが別の仮想プロセッサーにサービスを提供している間に、1つまたは複数の仮想 CPU による強制待機に費やされた時間割合を表示します。
%guest
仮想プロセッサを実行するために 1つまたは複数の CPU によって消費された時間の割合を表示します。
%gnice
nice されたゲストを実行するために 1つまたは複数の CPU が費やした時間の割合を表示します。
%idle
CPU がアイドル状態で、システムに未処理のディスク I/O 要求がなかった時間の割合を表示します。
-V
バージョン番号を出力して終了します。

 

環境変数

mpstat コマンドは、次の環境変数を参照します。
S_COLORS
出力がターミナルに接続されている場合、既定では、端末ごとに統計情報がカラーで表示されます。この変数を使用して、設定を変更します。取り得る値は、never、always またはauto (後者は既定の設定と同等ですです。
値の表示に使用されている色 (赤、黄、またはその他の色) は、単に色が原因で何らかの問題が発生していることを示すものではありません。異なる値の範囲を示しているだけです。
S_COLORS_SGR
端末に関する統計情報の表示に使用する色およびその他の属性を指定します。その値は、コロンで区切られたケイパビリティのリストで、既定値は I=32;22:N=34;1:W=35;1:X=31;1:Z=34;22 です。サポートされる機能は次のとおりです:
I=
CPU番号用の SGR (Select Graphic Rendition) 部分文字列。
N=
ゼロ以外の統計値を表示する SGR 部分文字列。
W= (又は M=)
75%から 90% (またはメトリックの意味に応じて 10%から 25%) の範囲の割合に対する SGR 部分文字列。
X= (又は H=)
割合が 90%以上のSGR 部分文字列 (あるいはメトリックの意味に応じて10%以下)。
Z=
ゼロ値を表示する SGR 部分文字列。
S_TIME_FORMAT
この変数が存在し、その値が ISO の場合、レポートヘッダーに日付を印刷するときに、現在のロケールが無視されます。mpstat コマンドは、代わりに ISO 8601 形式 (YYYY-MM-DD) を使用します。タイムスタンプも ISO 8601 形式に準拠します。

 

使用例

mpstat 2 5
すべてのプロセッサのグローバル統計情報のレポートを 2秒間隔で 5つ表示します。
mpstat -P ALL 2 5
すべてのプロセッサに関する統計情報のレポートを 2秒間隔で 5つ表示します。

 

バグ

mpstat コマンドが作動するためには、/proc ファイルシステムがマウントされている必要があります。

 

ファイル

/proc には、システム統計を含むさまざまなファイルが含まれています。
