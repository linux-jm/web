名前

less - more の反対 (more のようなページャー)  

書式

less [-[+]aABcCdeEfFgGiIJKLmMnNqQrRsSuUVwWX~] [-b size] [-D color] [-h lines] [-j line] [-k key-file] [-{o|O} log-file] [-p pattern ] [-P prompt] [-t tag] [-T tags-file] [-x tab[{,tab}...]] [-y lines] [-z lines] [-lines] [-"cc] [-# shift] [+less-command] [--] [file ...]

less -?

less --help

less -V

less --version

(長いオプション名を持つ代替オプション構文については、オプション 節を参照してください)。  

説明

Less は more(1) に似たプログラムですが、もっと多くの機能があります。Less は起動前に入力ファイル全体を読み込む必要がないので、大きな入力ファイルでは vi(1) のようなテキストエディタよりも高速に起動します。Lessは termcap (またはいくつかのシステムでは
terminfo)を使用するので、さまざまな端末で実行できます。ハードコピー端末ではまだサポートが限られています。(ハードコピーの端末では、画面の上部に印刷される行の先頭にキャレット (^) が付きます。)  

コマンド

コマンドは、more と vi の両方に基づいています。コマンドの前には、以下の説明で N と呼ばれる 10進数を付けることができます。以下で示されるように、この番号は一部のコマンドで使用されます。

以下の説明では、^X は control-X を意味します。ESC は ESCAPE キーを表します。たとえば、ESC-v は "ESCAPE" と "v" の2文字のシーケンスを意味します。

h or H
ヘルプ:コマンドの概要を表示します。他のコマンドをすべて忘れた場合は、このコマンドを思い出してください。
SPACE または ^V または f または ^F
N 行前方にスクロールします。既定値はウィンドウ1つ分です。(以下の -z オプションも参照)。N が画面サイズより大きい場合は、最後の行から画面に入りきる分だけ表示されます。警告:いくつかのシステムでは ^V を特殊なリテラル文字として使用しています。
z
SPACE と似ていますが、N を指定すると N が新しいウィンドウサイズになります。
ENTER または RETURN または ^N または e または ^E または j または ^J
N 行分前方にスクロールします。既定値は 1 です。N が画面サイズより大きい場合でも、N 行全体が表示されます。
d or ^D
N 行前方にスクロールします。既定値は画面サイズの半分です。N を指定すると、それ以降の d および u コマンドの新しい既定値になります。
b または ^B または ESC-v
N 行後方にスクロールします。既定値は 1画面分です(以下の -z オプションを参照)。N が画面サイズより大きい場合は、最後の行から画面に入りきる分だけ表示されます。
w
ESC-v と似ていますが、N を指定すると、新しいウィンドウサイズになります。
y または ^Y または ^P または k または ^K
N 行後方にスクロールします。既定値 は 1 です。N が画面サイズより大きい場合でも、N 行全体が表示されます。警告:いくつかのシステムでは ^Y を特殊なジョブ制御文字として使用しています。
u または ^U
N 行後方にスクロールします。既定値は画面サイズの半分です。N を指定すると、それ以降の d および u コマンドの新しい既定値になります。
J
j と似ていますが、ファイルの末尾を超えてスクロールし続けます。
K または Y
k と同様ですが、ファイルの先頭を超えてスクロールし続けます。
ESC-SPACE
SPACE と同様ですが、ファイルの最後に達した場合でも、画面全体をスクロールします。
ESC-b
b と同様ですが、ファイルの先頭に達しても画面全体をスクロールします。
ESC-j
N行前方にスクロールします。既定値 は 1です。ファイル中の行は、ファイル内の完全な行であり、改行で終了します。
ESC-k
N行逆方向にスクロールします。既定値は 1 です。
ESC-) または RIGHTARROW
N文字分右方向にスクロールします。既定値は画面の半分です(-# オプションを参照)。数値 N を指定すると、それ以降の RIGHTARROW および LEFTARROW コマンドの既定値になります。テキストをスクロールしている間は、-S オプション(行の切り取り)が有効であるかのように動作します。
ESC-( または LEFTARROW
N 文字分左方向にスクロールします。既定値は画面の半分です(-# オプションを参照)。数値 N を指定すると、それ以降の RIGHTARROW および LEFTARROW コマンドの既定値になります。
ESC-} または ^RIGHTARROW または SHIFT-RIGHTARROW
水平方向に右にスクロールして、表示されている最も長い行の末尾を表示します。
ESC-{ または ^LEFTARROW または SHIFT-LEFTARROW
左方向にスクロールして最初の列に戻ります。
^END または SHIFT-END
ファイルのN 行目に移動します。既定値はファイルの末尾で、水平方向に右にスクロールして、表示されている最も長い行の末尾を表示します。
^HOME または SHIFT-HOME
ファイルの N行目に移動します。既定値は 1(ファイルの先頭)で、左にスクロールして最初のカラムに戻ります。
r または ^R または ^L
画面を再描画します。
R
バッファされている入力をすべて破棄して、画面を再描画します。つまり、現在のファイルを再ロードします。表示中にファイルが変更される場合に便利です。
F
前方にスクロールして、ファイルの終わりに達したらさらに読み続けようとします。通常、このコマンドはすでにファイルの終端に来ている場合に使用されます。これは、表示中に成長するファイルの末尾を監視する時に使われます。(動作は "tail-f" コマンドに似ています)。これ以上データを待たないようにするには、割り込み文字 (通常は ^C ) を入力します。poll(2) をサポートしているシステムでは、^X または --intr オプションで指定された文字も使用できます。入力がパイプで、--exit-follow-on-close オプションが有効な場合、パイプの入力側が閉じられると、less は自動的にデータの待機を停止します。
ESC-f
Fと同様ですが、最後の検索パターンに一致する行が見つかるたびに、端末ベルが鳴らされます。
ESC-F
F と同様ですが、最後の検索パターンに一致する行が見つかるとすぐに端末ベルが鳴らされ、順方向スクロールは停止します。
g または < または ESC-< または HOME
ファイルの N 行目に移動します(既定値 は 1 です)。(注意:N が大きいと遅くなることがあります。
G または > または ESC-> または END
ファイルの N 行目に移動します。既定値はファイルの最後です。(警告:N が大きい場合、または N が指定されておらず、ファイルではなく標準入力が読み込まれている場合、処理が遅くなる可能性があります。)
ESC-G
G と同じですが、数値 N が指定されておらず、入力が標準入力の場合は、現在バッファされている最後の行に移動します。
p または %
ファイルの N パーセントの位置に移動します。N は 0～100 の範囲で、小数点を含めることができます。
P
ファイル内のバイトオフセット N を含む行に移動します。
{
画面の一番上の行に左中括弧が表示されている場合、{ コマンドは対応する右中括弧の位置に移動します。対応する右中括弧は、画面の一番下の行に配置されます。一番上の行に複数の左中括弧がある場合は、番号 N を使用して、その行の N 番目の括弧を指定することができます。
}
画面の一番下の行に右中括弧が表示されている場合、} コマンドは対応する左中括弧に移動します。対応する左中括弧は、画面の一番上の行に配置されます。一番下の行に複数の右中括弧がある場合は、数字 N を使用して、その行の N 番目の括弧を指定することができます。
(
{ に似ていますが、中括弧ではなく小括弧に適用されます。
)
} に似ていますが、中括弧ではなく小括弧に適用されます。
[
{ と似ていますが、中括弧ではなく大括弧に適用されます。
]
} と似ていますが、中括弧ではなく大括弧に適用されます。
ESC-^F
このコマンドの後に2文字を指定すると、{ のように機能します。2文字はそれぞれ開き括弧と閉じ括弧として使用します。たとえば、"ESC^F <>" は、画面の一番上に表示されている行の<に対応する > に移動するために使用できます。
ESC-^B
このコマンドの後に2文字を指定すると、} のように機能します。2文字はそれぞれ開き括弧と閉じ括弧として使用します。たとえば、"ESC^B <>" は、画面の一番下に表示されている行の>に対応する < に移動するために使用できます。
m
その後に小文字または大文字を続けて入力することで、最初に表示される行をその文字でマークします。-J オプションを使用してステータス列を有効にした場合、マークの付いた行がステータス列に表示されます。
M
mと同じように動作しますが、最初に表示された行ではなく、最後に表示された行がマークされます。
'
(シングルクォート。)この後に小文字または大文字が続く場合、以前その文字でマークされていた位置に戻ります。シングルクォートをもう 1つ続けると、シングルクォートで"大きく"移動する前の位置に戻ります。^ または $ を指定すると、それぞれファイルの先頭または末尾にジャンプします。一回の less 処理中に新しいファイルが処理される場合でも、マークは保存されます。したがって、' コマンドを使用して入力ファイルを切り替えることができます。--save-marks オプションを指定すると、異なった less の処理においてもマークが保持されます。
^X^X
シングルクォートと同じです。
ESC-m
その後に小文字または大文字を続けて入力すると、その文字で識別されるマークがクリアされます。
/pattern
ファイル内を前方に検索して、パターンを含む N 行目を探します。N の既定値は 1 です。パターンは、システムが提供する正規表現ライブラリによって認識される正規表現です。既定では、検索時には大文字と小文字が区別されます(大文字と小文字は異なると見なされます)。-i オプションを使用してこれを変更できます。検索は、表示された最初の行から開始されます(ただし、これを変更する -a および -j オプションを参照してください)。
一部の文字は、パターンの先頭に入力すると特殊文字になります。これらの文字は、パターンの一部になるのではなく、検索のタイプを変更します。
^N or !
パターンに一致しない行を検索します。
^E or *
複数のファイルを検索します。つまり、一致するものが見つからずに検索が現在のファイルの最後に到達した場合、検索はコマンドラインリストの次のファイルで続行されます。
^F oまたは @
現在画面に表示されている内容や -a または -j オプションの設定に関係なく、コマンドラインリスト中にある最初のファイルの先頭行から検索を開始します。
^K
現在の画面上のパターンに一致するテキストをハイライト表示しますが、最初に一致した行には移動しません(現在の位置を保持)。
^R
正規表現のメタ文字を解釈しません。つまり、単純なテキスト比較を行います。
^S
1 から 5 までの数字 N が続きます。N 番目の括弧で囲まれた SUB-PATTERN に対して空でないマッチを持つテキストのみが、パターンにマッチすると見なされます。たとえば、^S1 で修飾された "(abc)(def)" を検索すると、"abc" のインスタンスは検索されますが、"abc" と "def" の両方のインスタンスがハイライト表示されます。(less が正規表現ライブラリposix,pcre,または pcre2 のいずれかで構築されている場合のみサポートされます。複数のサブパターンにマッチするように、複数の ^S 修飾子を指定することができます。
^W
現在のファイルをラップします。つまり、一致するものが見つからずに現在のファイルの末尾に達した場合、検索は現在のファイルの最初の行から開始した行まで続行されます。^W 修飾子が設定されている場合、^E 修飾子は無視されます。
^L
次の文字は文字通りに解釈されます。つまり、上記の検索修飾文字のいずれかであっても、パターンの一部になります。
?pattern
ファイル内を逆方向に検索して、パターンを含む N 行目を探します。検索は、表示されている最後の行から開始されます(ただし、これを変更する -a および -j オプションを参照してください)。
/ コマンドのように特殊な文字もあります。
^N or !
パターンに一致しない行を検索します。
^E or *
複数のファイルを検索します。つまり、検索で一致するものが見つからずに現在のファイルの先頭に到達した場合、検索はコマンドラインリストの前のファイルで続行されます。
^F oまたは @
現在画面に表示されている内容や -a または -j オプションの設定に関係なく、コマンドラインリストの最後のファイルの最後の行から検索を開始します。
^K
順方向検索と同様です。
^R
順方向検索と同様です。
^S
順方向検索と同様です。
^W
現在のファイルをラップします。つまり、一致するものが見つからずに現在のファイルの先頭に達した場合、検索は現在のファイルの最後の行から開始した行まで続行されます。
^L
順方向検索と同様です。
ESC-/pattern
"/*"と同じです。
ESC-?pattern
"?*" と同じです。
n
最後のパターンを含む N 番目の行に対して、前の検索を繰り返します。前の検索が ^N で変更されていた場合、そのパターンを含まない N 行目が検索されます。前の検索が ^E によって変更された場合、現在のファイルで検索条件が満たされなければ、次の(または前の)ファイルで検索が続行されます。以前の検索が ^R によって変更された場合、検索は正規表現を使わずに行われます。前の検索が ^W で変更されている場合、検索はファイルの最後(または最初)で折り返されます。以前の検索 が ^F または ^K で変更されていても効果はありません。
N
前の検索を逆方向に繰り返します。
ESC-n
ファイルの境界を越えて、前の検索を繰り返します。その結果、前の検索が * で変更されたかのようになります。
ESC-N
前の検索を逆方向に、ファイルの境界を越えて繰り返します。
ESC-u
検索のハイライト表示を元に戻します。現在の検索パターンに一致する文字列の強調表示をオフにします。前に ESC-u を押したためにハイライト表示が既にオフになっている場合は、ハイライト表示をオンに戻します。検索コマンドを使用した場合も、ハイライト表示がオンに戻ります。(ハイライト表示は、-G で切り替えることによって無効にすることもできますこの場合、検索コマンドはハイライト表示をオンに戻しません。
ESC-U
ESC-u と同様ですが、保存された検索パターンをクリアします。-J オプションを使用してステータス列を有効にすると、ステータス列にマークされている検索結果がすべてクリアされます。
&pattern
パターンに一致する行のみを表示します。パターンに一致しない行は表示されません。パターンが空の場合(& と入力した直後に [ENTER]を押すと)、すべてのフィルタがオフになり、すべての行が表示されます。フィルタが有効な間は、ファイル内の一部の行が非表示になっている可能性があることを示すアンパサンドがプロンプトの先頭に表示されます。複数の & コマンドを入力できます。この場合、すべてのパターンに一致する行のみが表示されます。
/ コマンドのように特殊な文字もあります。
^N or !
パターンに一致しない行のみを表示します。
^R
正規表現のメタ文字を解釈しません。つまり、単純なテキスト比較を行います。
:e [filename]
新しいファイルを読み込みます。ファイル名が見つからない場合は、コマンドラインのファイルリストから"現在の"ファイル(以下の :n および :p コマンドを参照)を再度読み込みます。ファイル名の中のパーセント記号 (%) は、現在のファイルの名前に置き換えられます。シャープ記号 (#) は、前に読み込んだファイルの名前に置き換えられます。ただし、2つの連続するパーセント記号は、1つのパーセント記号に置き換えられます。これにより、名前にパーセント記号を含むファイル名を入力できます。同様に、2つの連続したシャープ記号は1つのシャープ記号に置き換えられます。ファイル名は、後続の :n および :p コマンドで表示できるように、コマンドラインのファイルリストに挿入されます。ファイル名が複数のファイルで構成されている場合、それらはすべてファイルのリストに挿入され、最初のファイルを閲覧します。ファイル名に1つ以上のスペースが含まれている場合は、ファイル名全体を二重引用符で囲む必要があります(-" オプションも参照)。
^X^V or E
これは :eと同じです。警告:いくつかのシステムでは ^V を特殊なリテラル文字として使用しています。そのようなシステムでは ^V を使うことはできないかもしれません。
:n
コマンドラインで指定されたファイルのリストから次のファイルを読み込みます。N を指定すると、次の N 番目のファイルを読み込みます。
:p
コマンドラインリストで一つ前のファイルを読み込みます。N を指定すると、N 番目の前のファイル読み込みます。
:x
コマンドラインリストの最初のファイルを読み込みます。番号 N を指定すると、リスト内の N 番目のファイルを読み込みます。
:d
ファイルのリストから現在のファイルを削除します。
t
現在のタグに複数一致するものがある場合は、次のタグに移動します。タグの詳細については、-t オプションを参照してください。
T
現在のタグに複数一致するものがあった場合は、前のタグに移動します。
^O^N または ^On
ファイル内を前方に検索して、次の N 番目のOSC 8 ハイパーリンクを探します。
^O^P または ^Op
ファイル内を逆方向に検索して、前からN 番目の OSC 8 ハイパーリンクを探します。
^O^L または ^Ol
現在選択されているOSC 8 ハイパーリンクにジャンプします。
= または ^G または :f
表示されているファイルの名前、行番号、表示されている一番下の行のバイトオフセットなど、表示されているファイルに関する情報を出力します。可能であれば、ファイルの長さ、ファイル内の行数、および最後に表示された行より上のファイルの割合も出力します。
-
コマンドラインオプション文字(後述のオプションを参照)の1つを指定すると、そのオプションの設定が変更され、新しい設定を説明するメッセージが出力されます。ダッシュの直後に ^P (CONTROL-P) を入力すると、オプションの設定は変更されますが、メッセージは出力されません。オプション文字が数値の場合(たとえば -b または -h など)、または文字列値の場合(-P または -t など)、新しい値をオプション文字の後に入力できます。新しい値を入力しないと、現在の設定を説明するメッセージが出力され、何も変更されません。
--
これは - コマンドに似ていますが、単一のオプション文字ではなく、長いオプション名(後述のオプションを参照)を取ります。変更するには、オプション名を入力してから ENTER キーまたは RETURN キーを押します。オプション名の先頭だけを入力して [TAB] を押すと、その文字列で始まるすべてのオプション名を検索できます。2番目のダッシュの直後に ^P を指定すると、- コマンドのように、新しい設定を説明するメッセージが表示されなくなります。
-+
コマンドラインオプション文字のうちの 1 つを続けて入力することで、オプションを既定値の設定にリセットし、新しい設定を説明するメッセージを出力します。("-+X" コマンドはコマンドラインで "-+X" と同じことを行います。これは文字列値オプションでは動作しません。
--+
これは -+ コマンドと似ていますが、単一のオプション文字ではなく長いオプション名を使用します。
-!
この後にコマンドラインオプション文字の1つを指定すると、オプションが既定値設定の"反対"にリセットされ、新しい設定を説明するメッセージが出力されます。これは、数値または文字列値のオプションでは機能しません。
--!
これは -! コマンドと似ていますが、単一のオプション文字ではなく、長いオプション名をとります。
_
(アンダースコア。)この後にコマンドラインオプション文字の 1つが続き、そのオプションの現在の設定を説明するメッセージが出力されます。オプションの設定は変更されません。
__
(二重アンダースコア)これは _ (アンダースコア)コマンドと似ていますが、単一のオプション文字ではなく、長いオプション名をとります。オプション名を入力したら、ENTER キーまたは RETURN キーを押す必要があります。
+cmd
新しいファイルを読み込むたびに、指定された cmd を実行します。たとえば、+G を指定すると、less は最初に各ファイルの先頭ではなく末尾から表示します。
V
実行中の less バージョン番号を表示します。
q または Q または :q または :Q または ZZ
less を終了します。

次の 7 つのコマンドは、インストール環境によって有効な場合と無効な場合があります。

v
エディタを起動して、表示されている現在のファイルを編集します。エディタは、定義されている場合は環境変数 VISUAL から取得され、VISUAL が定義されていない場合はEDITOR から取得され、VISUAL も EDITOR も定義されていない場合は既定値から "vi" になります。 以下の "プロンプト" のセクションにある LESSEDIT の説明も参照してください。
!シェルコマンド
シェルを起動して、指定されたシェルコマンドを実行します。コマンド内のパーセント記号 (%) は、現在のファイル名に置き換えられます。シャープ記号 (#) は、前に読み込んだファイルの名前に置き換えられます。"!!" は、最後のシェルコマンドを繰り返します。シェルコマンドのない "!" は、対話的なシェルを起動します。"!" の直後に ^P(CONTROL-P) が入力された場合、シェルコマンドの実行後に "done" メッセージは出力されません。Unix システムでは、シェルは環境変数 SHELL から取得されるか、既定値として "sh" になります。MS-DOS、Windows、および OS/2 システムでは、シェルは通常のコマンドプロセッサです。
# シェルコマンド
"!" コマンドに似ていますが、プロンプト文字列と同じように展開されます。たとえば、現在のファイルの名前は "%f" となります。
| <m> シェルコマンド
<m> は任意のマーク文字を表します。入力ファイルのセクションを指定されたシェルコマンドにパイプします。パイプされるファイルのセクションは、文字でマークされた位置と現在の画面の間にあります。マークされた位置が現在の画面の前か後かに関係なく、現在の画面全体が含まれます。<m> はファイルの開始または終了を示すためにそれぞれ ^ または $ とすることもできます。もしも <m> が . または改行の場合、現在の画面がパイプされます。もしも ^P (CONTROL-P) がマーク文字の直後に入力された場合、シェルコマンドの実行後に "done" メッセージは出力されません。
s ファイル名
入力をファイルに保存します。これは、入力が通常のファイルではなくパイプである場合にのみ機能します。
^O^O
シェルコマンドを実行して、以前の ^O^N または ^O^P コマンドで選択された現在の OSC 8 ハイパーリンクの URI を開きます。シェルコマンドを見つけるために、"LESS_OSC8_xxx" という名前の環境変数が読み込まれます。"xxx" は URI からのスキーム(最初のコロンの前の部分)です。URI にコロンがない場合は空です。環境変数の値はプロンプト文字列と同じ方法で展開され(特に、"%o" のインスタンスは URI に置き換えられます)、OSC 8 "handler" シェルコマンドを生成します。ハンドラからの標準出力は、URI を開くために実行される "opener" シェルコマンドです。

次の2つの特殊なケースがあります:

1.
URIが "#" で始まる場合、URI の残りの部分は同じファイル内の別の OSC 8 リンクの id パラメータの値として扱われ、^O^O は単純にそのリンクにジャンプします。
2.
オープナが文字 ":e" で始まり、その後に空白とファイル名が続く場合、オープナをシェルコマンドとして実行する代わりに、指定されたファイル名が現在の less インスタンスでオープンされます。

オープナが完全な URI をコマンドラインパラメータとして受け入れる単純なケースでは、ハンドラは次のように単純にできます: 

echo mybrowser '%o'

その他の場合、URI を変更する必要がある場合もあるため、ハンドラーは %o 値を操作する必要があります。

LESS_OSC8_xxx 変数が設定されていない場合、変数 LESS_OSC8_ANY が試されます。LESS_OSC8_xxx も LESS_OSC8_ANY も設定されていない場合、"xxx" スキームを使用するリンクは開くことができません。しかし、"man" (LESS_OSC8_man が設定されていない場合に使用される)と "file" (LESS_OSC8_fileが設定されていない場合に使用される) のスキームには既定値ハンドラがあり、sed(1) コマンドとBourneシェル sh(1) と互換性のある構文を持つシェルを提供するシステムで動作します。LESS_OSC8_ANY を使用して LESS_OSC8_file を上書きする場合は、既定値を使用しないことを示すために LESS_OSC8_file を "-" に設定する必要があります。LESS_OSC8_man についても同様です。

%o 経由で OSC8 ハンドラに渡される URI は、単一引用符や二重引用符を含まないことが保証されていますが、セミコロン、ドル記号、アンパサンドなどの他のシェルメタキャラクタを含むことができます。ハンドラは、シェルメタキャラクタを含む URI を開く場合、意図しないシェルコマンドの実行を防ぐために、オープナコマンド内のパラメータを適切に引用するように注意すべきです。同様に、ハンドラコマンドはコマンドプロンプトのように展開されるため、プロンプト展開によって解釈されるメタ文字(パーセント、ドット、コロン、バックスラッシュなど)は、バックスラッシュでエスケープする必要があります(詳細については "プロンプト" セクションを参照)。

^X
F コマンドの実行中などに "データを待っています(Waiting for data)" というメッセージが表示されたときに ^X を押すと、less の待機を停止し、プロンプトに戻ります。これにより、less はファイルが現在の位置で終了していると認識するため、より多くのデータを表示するには R または F コマンドを使用する必要がある場合があります。--intr オプションを使用すると、^X の代わりに別の文字を指定できます。このコマンドは、poll(2) 関数をサポートするシステム上でのみ動作します。poll(2) がないシステムでは、代わりに割り込み文字(通常 ^C ) を使うことができます。
 

オプション

コマンドラインオプションについて説明します。ほとんどのオプションは、less の実行中に "-" コマンドを使用して変更できます。

一部のオプションは、2つの形式のいずれかで指定できます。ダッシュの後に1つの文字が続くか、2つのダッシュの後に長いオプション名が続く形です。長いオプション名は、その省略形が明確である限り、短縮することができます。たとえば、--mouse は --mou と省略できますが、--mo ではありません。--mouse と --modelines は両方とも --mo で始まるためです。

長いオプション名の中には、--quit-at-eof とは異なり、--QUIT-AT-EOF など、大文字のものもあります。このようなオプション名は、最初の文字だけを大文字にする必要があります。名前の残りの部分はどちらの場合でもかまいません。たとえば、--Quit-at-eof は --Quit-at-eof と同じです。

オプションは環境変数 "LESS" からも取得されます。例えば、less を起動するたびに "less-options..." とタイプするのを避けるためには、csh では:

setenv LESS "-options"

とし、sh を使っている時には:

LESS="-options"; export LESS とします。

MS-DOS と Windows では引用符は必要ありませんが、オプション文字列内のパーセント記号が環境変数の展開と解釈されないことに注意してください。

環境変数はコマンドラインの前に解析されるため、コマンドラインオプションは LESS 環境変数よりも優先されます。LESS 変数に指定されたオプションは、"-+" で始まるコマンドラインオプションによって、既定値にリセットすることができます。

-k または -D のような一部のオプションでは、オプション文字の後に文字列が必要です。そのオプションの文字列は、ドル記号 ($) が見つかったときに終了すると見なされます。たとえば、次のような2つの-D のようなオプションを設定できます:

LESS="Dnwb$Dsbw"

--use-backslash オプションがオプションの前にある場合、ドル記号やバックスラッシュは、その前にバックスラッシュを置くことで、オプション文字列に文字どおり含めることができます。--use-backslash オプションが有効でない場合、バックスラッシュは特別扱いされず、オプション文字列にドル記号を含めることはできません。

-? または --help
このオプションは、less によって受け入れられたコマンドの要約を表示します(h コマンドと同じです)。(シェルが疑問符を解釈する方法によっては、"-\?" のように疑問符を引用符で囲む必要がある場合があります。)
-a または --search-skip-screen
既定では、順方向検索は表示画面の上部から開始され、逆方向検索は表示画面の下部から開始されます(ただし、n コマンドまたは N コマンドによって呼び出される繰り返し検索は例外で、それぞれ "ターゲット" 行の後または前から開始されます。ターゲット行の詳細については、-j オプションを参照してください)。-a オプションを指定すると、画面の一番下から順方向検索が開始され、画面の一番上から逆方向検索が開始されるため、画面に表示されているすべての行がスキップされます。
-A または --SEARCH-SKIP-SCREEN
すべての前方検索(繰り返さない検索だけでなく)をターゲット行の直後で開始し、すべての後方検索をターゲット行の直前で開始します。したがって、順方向検索では、表示された画面の一部(最初の行からターゲット行まで)がスキップされます。同様に、逆方向の検索では、表示された画面を最後の行からターゲット行までスキップします。これは、441 より前のバージョンでの既定の動作です。
-bn または --buffers=n
less が各ファイルに使用するバッファ領域の大きさをキロバイト (1024 バイト) 単位で指定します。既定では、ファイルごとに 64KB のバッファ領域が使用されます(ファイルがパイプでない場合。-B オプションを参照してください)。-b オプションは、各ファイルに対して n キロバイトのバッファ領域を使用するように指定します。n が -1 の場合、バッファ領域は無制限です。つまり、ファイル全体をメモリに読み込むことができます。
-B または --auto-buffers
既定では、データがパイプから読み取られるときに、バッファが必要に応じて自動的に割り当てられます。大量のデータがパイプから読み取られると、大量のメモリが割り当てられる可能性があります。-B オプションを指定すると、このパイプ用バッファの自動割り当てが無効になり、64KB (または -b オプションで指定された容量)だけがパイプに使用されます。警告:-B を使用すると、パイプされたデータの最後に表示された部分のみがメモリに保持されるため、誤った表示が発生する可能性があります。それ以前のデータは失われます。失われた文字は、疑問符として表示されます。
-c または --clear-screen
フルスクリーンの再描画を上から下に行います。既定では、全画面の再描画は画面の下からスクロールして行われます。
-C または --CLEAR-SCREEN
-cと同じですが、less の古いバージョンとの互換性用です。
-d または --dumb
-d オプションは、端末がダムである場合に通常表示されるエラーメッセージを抑制します。つまり、画面をクリアしたり、逆方向にスクロールしたりする機能など、いくつかの重要な機能が欠けています。-d オプションは、それらの機能がある場合、ダム端末上でもlessの動作を変更しません。

非標準ファイルを強制的に開きます。(非標準ファイルは、ディレクトリまたはデバイススペシャルファイルです)。また、バイナリファイルを開いたときの警告メッセージも表示されません。既定では、less は非標準ファイルを開くことを拒否します。オペレーティングシステムによっては、-f が設定されていてもディレクトリを読み込めないことに注意してください。
-F または --quit-if-one-screen
ファイル全体を最初の画面に表示できる場合、less は自動的に終了します。後述の LESS_SHELL_LINES 環境変数の説明も参照してください。
-g または --hilite-search
通常、less は最後の検索コマンドにマッチする全ての文字列をハイライトします。-g オプションは、この動作を変更して、最後の検索コマンドで見つかった特定の文字列のみをハイライト表示します。これにより、less は既定状態よりもいくらか速く動作できます。
-G または --HILITE-SEARCH
-G オプションを指定すると、検索コマンドで見つかった文字列がすべてハイライト表示されなくなります。
-hn または --max-back-scroll=n
逆方向にスクロールする行の最大数を指定します。n 行よりも後ろにスクロールする必要がある場合は、代わりに前方向に画面が再描画されます。端末に逆方向スクロール機能がない場合は、-h0 が仮定されます。
-i または --ignore-case
大文字と小文字を区別せずに検索します。つまり、大文字と小文字は同一とみなされます。検索パターンに大文字が含まれる場合、このオプションは無視されます。つまり、パターンに大文字が含まれる場合、大文字と小文字の区別をして検索します。
-I または --IGNORE-CASE
-i と似ていますが、検索では、パターンに大文字が含まれていても大文字と小文字は区別されません。
-jn または --jump-target=n
"ターゲット" 行を配置する画面上の行を指定します。ターゲット行とは、パターンの検索、行番号へのジャンプ、ファイルのパーセンテージへのジャンプ、またはタグへのジャンプを行うコマンドによって指定された行です。画面行は番号で指定できます。画面上の一番上の行は 1、次の行は 2、以下同様です。負の値を指定すると、画面の一番下を基準にした線になります。画面の一番下の行は -1、一番下から 2番目の行は -2 のようになります。代わりに、スクリーン行はスクリーンの高さに対する割合として指定することもでき、その場合は小数点から始まります:.5 はスクリーンの中央、.3 は最初の行から 3/10 の位置、以下同様です。行が分数として指定されている場合、端末ウィンドウのサイズが変更されると、実際の行番号が再計算されます。--header オプションが使用され、-j によって指定されたターゲット行がヘッダーによって隠される場合、ターゲット行はヘッダーの後の最初の行に移動されます。

-j オプションのいずれかの形式が使用されている場合、繰り返される前方検索("n" または "N" で呼び出される)は、ターゲット行の直後の行から始まり、繰り返される後方検索は、-a または -A によって変更されない限り、ターゲット行から始まります。例えば、"-j4" を使うと、検索対象行は画面の 4 行目になるので、画面の 5 行目から順方向検索が始まります。ただし、繰り返さない検索 ("/" または "?" で呼び出す)は、常にそれぞれ画面の最初または最後の行から開始されます。

-J または --status-column
画面の左端にステータス列を表示します。ステータスカラムに表示される文字は、次のいずれかです。
>
行は -S オプションで分割され、画面の右端を超えて切り取られたテキストには、現在の検索の一致が含まれます。
<
行は水平方向にシフトされ、画面の左側を超えてシフトされたテキストには、現在の検索にマッチしたものが含まれます。
=
行は切り取られて移動され、画面の両側を越えてマッチするものがあります。
*
行の目に見える部分にはマッチするものがありますが、その右または左にはマッチするものがありません。
a-z, A-Z
行は、m または M コマンドによって、対応する文字でマークされています。
#
--mouse オプションが有効な場合、行はマウスで左クリックしてマークされています。
-kfilename または --lesskey-file=filename
less を開いて、指定されたファイルを lesskey(1) バイナリファイルとして解釈します。複数の -k オプションを指定できます。LESSKEY または LESSKEY_SYSTEM 環境変数が設定されている場合、またはlesskey ファイルが標準の場所にある場合(KEY BINDINGSを参照)、そのファイルはlesskey ファイルとして使われます。下記の --lesskey-content による警告に注意してください。
--lesskey-src=filename
less を開いて、指定されたファイルを lesskey(1) ソースファイルとして解釈します。LESSKEYIN または LESSKEYIN_SYSTEM 環境変数が設定されている場合、または lesskeyソ ースファイルが標準の場所にある場合(KEY BINDINGSを参照)、そのファイルは lesskey ソースファイルとしても使用されます。バージョン 582 より前では、lesskeyプログラムは、less で使用するために、lesskey sourceファイルをlesskey binaryファイルに変換するために動かす必要がありました。less の新しいバージョンは、lesskeyソースファイルを直接読み込み、ソースファイルが存在する場合はバイナリファイルを無視します。下記の --lesskey-content による警告に注意してください。
--lesskey-content=text
less に、指定したテキストを lesskey(1) ソースファイルの内容として解釈させます。テキスト中では、lesskey 行は通常の改行またはセミコロンで区切ることができます。リテラルセミコロンは、バックスラッシュとそれに続くセミコロンで表すことができます。
警告:起動時に使用されるLESS、LESSSECURE、LESSCHARSET などの特定の環境変数は、コマンドラインオプション (--lesskey、--lesskey-src または--lesskey-content)で指定されたファイルでは設定できません。lesskey ファイルを使用して環境変数を設定する場合は、既定値 lesskey ファイルを使用するか、コマンド行オプションを使用するよりも LESSKEYIN またはLESSKEY_CONTENT 環境変数を使用してファイルを指定する方が安全です。
-K または --quit-on-intr
割り込み文字 (通常は ^C) が入力されたときに、less をステータス 2 で直ちに終了させます。通常、割り込み文字があると、less は何をしていても停止し、コマンドプロンプトに戻ります。
-L または --no-lessopen
LESSOPEN 環境変数を無視します(後述の "入力プリプロセッサ" の項を参照)。このオプションはless 内から設定できますが、現在開いているファイルではなく、その後に開いたファイルにのみ適用されます。
-m または --long-prompt
less に more(1) のような冗長なファイルのパーセント表示を伴うプロンプトを表示します。既定では、less はコロンでプロンプトを表示します。
-M または --LONG-PROMPT
lessに、more(1) よりもさらに冗長なプロンプトを表示させます。
-n または --line-numbers
行番号を表示しません。既定では(行番号を使用する)、less は、特に非常に大きな入力ファイルでは、場合によっては実行速度が遅くなるを引き起こす可能性があります。行番号の使用は、次のことを意味します。行番号は冗長プロンプトと = コマンドで表示され、v コマンドは現在の行番号をエディタに渡します(後述のプロンプトの LESSEDIT の説明も参照)。
-N または --LINE-NUMBERS
ディスプレイの各行の先頭に行番号を表示します。
-ofilename または --log-file=filename
less の入力を、表示されている指定された名前のファイルにコピーし閲覧します。これは、入力ファイルが通常のファイルではなくパイプである場合にのみ適用されます。ファイルがすでに存在する場合、less は上書きする前に確認を求めます。
-Ofilename または --LOG-FILE=filename
-O オプションは -o, と似ていますが、確認を求めずに既存のファイルを上書きします。
ログファイルが指定されていない場合は、ログファイルを指定するために -o および -O オプションをless 内から使用できます。ファイル名を指定しない場合は、単にログファイルの名前が表示されます。"s" コマンドは、less 内から -o を指定するのと同じです。
-ppattern または --pattern=pattern
コマンドラインで -p オプションを指定するのは、+/pattern を指定するのと同じです。つまり、less に対して、ファイル内で最初に pattern が出現したところから開始するように指示します。
-Pprompt または --prompt=prompt
3つのプロンプトスタイルを好みに合わせて調整できます。このオプションは通常、less コマンドごとに入力するのではなく、LESS 環境変数に設定します。このようなオプションは、LESS 変数の最後のオプションであるか、ドル記号で終了する必要があります。

-Ps
の後に文字列を指定すると、既定の(短い)プロンプトがその文字列に変わります。
-Pm
は、中間の (-m)プロンプトを変更します。
-PM
は、長い (-M) プロンプトを変更します。
-Ph
はヘルプ画面のプロンプトを変更します。
-P=
は = コマンドで出力されるメッセージを変更します。
-Pw
はデータ待ちの間に出力されるメッセージを変更します("F" コマンドで)。
すべてのプロンプト文字列は、一連の文字と特殊なエスケープシーケンスで構成されます。詳細については、"プロンプト" のセクションを参照してください。
-q または --quiet または --silent
適度に "静かな" 動作にします。ファイルの末尾を超えて、またはファイルの先頭の前にスクロールしようとしても、端末ベルは鳴らされません。端末に "ビジュアルベル" がある場合は、それが代わりに使用されます。無効な文字の入力など、他の特定のエラーが発生した場合にはベルが鳴ります。このような場合、既定では端末のベルを鳴らすことになっています。
-Q または --QUIET または --SILENT
完全に "静かな" 動作を引き起こします。端末のベルは決して鳴りません。端末に "ビジュアルベル" がある場合、それは端末でベルが鳴らされたであろうすべての場合に使用されます。
-r または --raw-control-chars
"そのままの" 制御文字を表示します。既定では、キャレット記法を使用して制御文字を表示します。たとえば、コントロール-A(8進001) は "^A" と表示されます(-U オプションで説明するように、いくつかの例外があります)。警告:-r オプションを使用すると、less は画面の実際の外観を追跡できません。これは、画面が各タイプの制御文字にどのように応答するかによって異なるためです。したがって、長い行が間違った場所で分割されるなど、さまざまな表示上の問題が発生する可能性があります。
-r オプションは危険であり、推奨されません。
-r オプションは、コマンドラインまたは - コマンドで設定できますが、誤って使用しないように、LESS 環境変数では設定できません。-r が LESS 環境変数に表示されている場合は、-Rとして扱われます。
-R または --RAW-CONTROL-CHARS
-r と同様ですが、限られた数のエスケープシーケンスだけが "そのままの" 形式で出力されます。-r とは異なり、画面の外観は正しく維持されます。そのままの文字として出力されるシーケンスは次のとおりです。
1. ANSI SGR("color") シーケンス
2. OSC 8 ハイパーリンク
3. その他の OSC シーケンス(OSC タイプ番号が LESSANSIOSCALLOW 環境変数にリストされている場合)
4. 文字が LESSANSIOSCCHARS 環境変数にリストされ、その後にアスタリスクが付いている場合、非標準の導入文字(つまり、"]" 以外の文字) で始まる OSC シーケンス
ANSI カラーエスケープシーケンスは、次の形式のシーケンスです。
      ESC [ ... m
ここで "..." は 0 個以上の色指定文字です。色のエスケープシーケンスは、色が複数行ではなく 1 行内で変更された場合にのみサポートされます。つまり、各行の先頭は、前の行のエスケープシーケンスに関係なく、通常(色なし)であると見なされます。
環境変数 LESSANSIENDCHARS を、カラーエスケープシーケンスを終了できる文字のリストに設定することで、less が"m"以外の文字が ANSI カラーエスケープシーケンスを終了できるとみなすようにできます。また、環境変数 LESSANSIMIDCHARS に表示可能な文字のリストを設定することで、less に ESC と m の間に標準以外の文字が現れるとみなすようにできます。
OSC シーケンスの形式は次のとおりです。
      ESC ] N ; ... \7
ここで OSC タイプ番号 N は 10進数です。終了シーケンスは上記のように BEL 文字 (\7) か、2 文字のシーケンス "ESC\" のどちらかです。
-s または --squeeze-blank-lines
連続する空白行を単一の空白行にまとめます。これは、nroff(1) の出力を表示するときに便利です。
-S または --chop-long-lines
画面の幅よりも長い行は折り返されずに切り捨てます。つまり、画面の幅に収まらない長い行の部分は、→キーを押すまで表示されません。既定では、長い行を折り返します。つまり、残りを次の行に表示します。--wordwrap オプションも参照してください。--header オプションがアクティブな間は、-S オプションは無視され、画面の幅よりも長い行は切り捨てられます。
-ttag または --tag=tag

-U または --UNDERLINE-SPECIAL

-V または --version

-w または --hilite-unread
ページ全体が順方向に移動した後の最初の "新しい" 行を一時的にハイライト表示します。最初の "新しい" 行は、前に画面の下部にあった行の直後の行です。また、g または p コマンドの後にターゲット行をハイライト表示します。ハイライト表示は、移動を伴う次のコマンドで削除されます。--status-line オプションが有効な場合は、行全体(画面の幅)がハイライト表示されます。それ以外の場合は、行のテキストのみがハイライト表示されます。ただし、-J オプションが有効な場合は、ステータス列のみがハイライト表示されます。
-W または --HILITE-UNREAD
-w と似ていますが、2 行以上前進移動コマンドを実行すると、最初の新しい行が一時的にハイライト表示されます。
-xn,... または --tabs=n,...
タブ位置を設定します。n を 1 つだけ指定した場合、タブ位置は n の倍数に設定されます。カンマで区切られた複数の値を指定すると、それらの位置にタブストップが設定され、その後、最後の2つの値と同じ間隔で続きます。例えば、"-x9,17" は位置9, 17、25、33等にタブを設定します。n の既定値は 8 です。
-X または --no-init
端末への termcap 初期設定文字列と初期設定解除文字列の送信を無効にします。これは、初期化または初期化解除によって画面のクリアなどの不必要な処理が行われる場合に望ましい場合があります。端末の中には、適切な動作のために初期化文字列を必要とするものがあることに注意してください。そのため、-X が使用されている場合は、完全に正しく動作しないことがあります。
-yn または --max-forw-scroll=n
前方にスクロールする行の最大数を指定します。n 行よりも前にスクロールする必要がある場合は、代わりに画面が再描画されます。必要に応じて、-c または -C オプションを使用して、画面の上部から再描画できます。既定では、前方に移動するとスクロールします。
-zn または --window=n または -n
スクロールウィンドウの既定値のサイズを n 行に変更します。既定値は一画面分です。z および w コマンドを使用して、ウィンドウのサイズを変更することもできます。"z" は more(1) のいくつかのバージョンとの互換性のために省略することができます。数値 n が負の場合、これは 現在の画面サイズより少ない n 行を指定することになります。たとえば、画面が 24 行の場合、-z-4 はスクロールウィンドウを 20 行に設定します。後で画面のサイズを 40 行に変更すると、スクロールウィンドウは自動的に 36 行に変更されます。
-"cc または \fB--quotes=cc
ファイル名の引用符文字を変更します。これは、スペースと引用符の両方を含むファイルに名前を付けようとする場合に必要になることがあります。この後に1文字が続くと、引用文字がその文字に変更されます。スペースを含むファイル名は、二重引用符ではなくその文字で囲む必要があります。その後に 2文字が続き、開始引用符を最初の文字に、終了引用符を 2番目の文字に変更します。スペースを含むファイル名の前には開き引用符を付け、その後に閉じ引用符を付ける必要があります。引用符文字を変更した後でも、このオプションは - " (ダッシュの後に二重引用符)のままであることに注意してください。
-~ または --tilde
通常、ファイルの終わりより後の行は単一のチルダ (~) として表示されます。このオプションを使用すると、ファイルの終わりの後の行が空白行として表示されます。
-# または --shift
RIGHTARROW コマンドおよび LEFTARROW コマンドで水平にスクロールする位置の既定値を指定します。指定した数値が 0 の場合、位置の既定値数はスクリーン幅の半分に設定されます。あるいは、値は小数点で始まる画面幅の分数として指定することもできます:.5 は画面幅の半分、.3 は画面幅の 10 分の 3、以下同様です。数値が分数として指定されている場合、端末ウィンドウのサイズが変更されると、実際のスクロール位置の数が再計算されます。
--autosave=actions
通常、履歴ファイルが保存されるのは、less が終了したときだけです。このオプションは、履歴ファイルを保存するその他のアクションを指定します。各アクションは、actions 文字列中の単一の文字で定義されます:
m
--save-marks が有効な間にマークを設定またはクリアします。
/
検索中。
!
シェル・コマンドの実行中。
*
任意のアクション。"m/!" と同じです。
"-" を設定すると既定値になります。less を終了するだけで履歴ファイルが保存されます。シェルによっては、コマンドラインでこのオプションを指定する時、"!" と "*" の文字をエスケープまたは引用符で囲む必要があります。
--cmd=commands
指定された文字列は、less への最初のコマンドと見なされます。これは、"+commands" を指定するのと似ています。ただし、-E または -F オプションを使用したためにless が即時終了した場合、--cmd で指定されたコマンドは実行されません。一方、+ オプションで指定されたコマンドは、less が即時終了した場合でも実行されます。
--exit-follow-on-close
パイプに対して "F" コマンドを使用すると、パイプの入力側が閉じられると、less はそれ以上データを待機することを自動的に停止します。
--file-size
--file-size が指定されている場合、less はファイルを開いた直後にファイルのサイズを決定します。次に、"=" コマンドによってファイル内の行数が表示されます。入力ファイルがシーク不可能(パイプなど)でサイズが大きい場合、処理が遅くなる可能性があるため、通常はこれは行われません。
--follow-name
通常、F コマンドの実行中に入力ファイルの名前が変更された場合、less は名前が変更されても元のファイルの内容を表示し続けます。--follow-name が指定されている場合、F コマンドの実行中、less は定期的に名前を指定してファイルを再び開こうとします。再オープンが成功し、ファイルが元のファイルとは異なる場合(つまり、元のファイルと同じ名前で新しいファイルが作成された場合)、less はその新しいファイルの内容を表示します。
--form-feed
ファイル内を前方または後方にスクロールするときに、改ページ文字 (^L) で始まる行に達すると停止します。これは、ページ間でフォームフィードを使用するファイルを表示する場合に便利です。
--header=L,C,N
画面に表示されるヘッダーの行数と列数を設定します。ヘッダ行の数は L に設定されます。L が 0 の場合、ヘッダー行は無効になります。L が空または存在しない場合、ヘッダー行の数は変更されません。ヘッダ列の数は C に設定されます。C が 0 の場合、ヘッダー列は無効になります。C が空または存在しない場合、ヘッダー列の数は変更されません。最初のヘッダー行は、ファイル中の行番号 N に設定されます。N が空または存在しない場合、--header コマンドが less 内から発行された場合は画面の最初の行に現在表示されている行の番号になり、--header オプションがコマンド行で指定された場合は 1 になります。特別な形式 "--header=-" はヘッダ行とヘッダ列を無効にし、"--header=0,0" と等価です。

L がゼロ以外の場合、画面上部の最初の L 行は、ファイルのどの部分が表示されているかに関係なく、行N で始まるファイルの行に置き換えられます。ヘッダー行を表示すると、ヘッダー行より前のファイルの内容は表示されません。C がゼロ以外の場合、各行の先頭に表示される最初の C 文字は、行の残りの部分が水平方向にスクロールされる場合でも、行の最初の C 文字に置き換えられます。

--header オプションがアクティブな場合、画面の幅よりも長い行は切り捨てられ、-S オプションは無視されます。

--incsearch
以降の検索コマンドは"インクリメンタル"です。つまり、less は、パターンの各文字が入力されるたびに、検索パターンを含む次の行に進みます。
--intr=c
"Waiting for data"メッセージが表示されたときに読み込みを中断するには、^X の代わりに文字cを使用します。cは ASCII 文字で、1～127 の値でなければなりません。キャレットとそれに続く 1 文字を使用して、制御文字を指定できます。
--line-num-width=n
-N オプションが有効な場合の行番号フィールドの最小幅を n 文字数に設定します。既定値は 7 です。
--match-shift=n
-S が有効な場合、検索にマッチしたものが、現在表示されている画面の左または右に移動したために表示されなくなった場合、テキストは水平に移動して検索に一致したものが表示されるようになります。このオプションは、シフト後に検索にマッチした最初の文字が配置される列を選択します。つまり、検索にマッチしたものの左側に表示されるn 文字が存在します。
あるいは、値は小数点で始まる画面幅の分数として指定することもできます:.5 は画面幅の半分、.3 は画面幅の 10 分の 3、以下同様です。数値が分数として指定されている場合、端末ウィンドウのサイズが変更されると、実際のスクロール位置の数が再計算されます。
--modelines=n
ファイルを表示する前に、less は最初の n 行を読み取って、vim 互換のmodeline を探します。n が 0 の場合、less はモードラインを見つけようとしません。モードラインを使用することで、ファイル自体が、それを表示するときに使用されるタブストップを指定できます。

モード行には、行のどこかにプログラム名("vi"、"vim"、"ex"、または"less")が含まれ、その後にコロンが続き、場合によっては単語"set"が続き、最後に0個以上のオプション設定が続きます。"set" という語を使用する場合、オプション設定はスペースで区切り、最初のコロンで終了します。"set" という語を使用しない場合、オプション設定はスペースまたはコロンで区切ることができます。プログラム名が "less" の場合は "set" という単語が必要ですが、他の3つの名前のいずれかが使用されている場合はオプションです。いずれかのオプション設定が "tabstop=n" または "ts=n" 形式である場合、--tabs=n が指定された場合と同様にタブストップが自動的に設定されます。n が取り得る値については、--tabs の説明を参照してください。

--mouse
マウス入力を有効にします。マウスホイールを下にスクロールするとファイル内を順方向に移動し、上にスクロールするとファイル内を逆方向に移動し、左クリックすると "#" マークがマウスがクリックされた行に設定され、右クリック(またはその他)すると "#" マークの位置に戻ります。左ボタンを押しながらドラッグしても、ファイル内を移動できます。OSC 8 ハイパーリンク上でマウスカーソルを左クリックすると、^O^N コマンドのようにハイパーリンクが選択されます。既に選択されている OSC 8 ハイパーリンクをマウスカーソルで左クリックすると、^O^O コマンドのようにハイパーリンクが開きます。ホイールを動かしたときにスクロールする行数は、--wheel-lines オプションで設定できます。マウス入力は、X11 マウスレポートをサポートする端末と Windows でのみ機能します。
--MOUSE
--mouse と同様ですが、マウスホイールの動きでスクロールされる方向が逆になります。
--no-edit-warn
LESSOPEN プリプロセッサ (後述の "INPUT PREPROCESSOR" セクションを参照)を使用して開かれたファイルに対して v コマンドを使用しても、警告メッセージが出力されません。
--no-keypad
キーパッド初期設定文字列および非初期設定文字列の端末への送信を無効にします。これは、キーパッドの文字列によってテンキーが望ましくない動作をする場合に便利です。
--no-histdups
このオプションは、検索文字列またはファイル名が入力され、同じ文字列がすでに履歴リストにある場合、新しい文字列が追加される前に既存のコピーが履歴リストから削除されるように動作を変更します。したがって、指定された文字列は履歴リストに 1 回だけ表示されます。通常、文字列は複数回現れることがあります。
--no-number-headers
ヘッダー行(--header オプションで定義)には、行番号は割り当てられません。行番号 1 は、ヘッダー行の後の最初の行に割り当てられます。
--no-paste
端末が xterm-compatible"brackets paste" をサポートしている場合、less にペーストされたテキストは無視されます。ただし、画面下部のコマンドラインに 1 行のテキスト検索文字列、ファイル名などがペーストされる場合は例外です。つまり、コマンドラインに貼り付けられたテキストの最初の改行と、それに続くテキストは無視されます。
--no-search-header-lines
検索にはヘッダー行は含まれませんが、ヘッダー列は含まれます。
--no-search-header-columns
検索にはヘッダー列は含まれませんが、ヘッダー行は含まれます。
--no-search-headers
検索には、ヘッダー行またはヘッダー列は含まれません。
--no-vbell
端末のビジュアルベルを無効にします。
--proc-backspace
設定されている場合、バックスペースは、-u オプションも -U オプションも設定されていないものとして処理されます。すなわち、下線に隣接するバックスペースは、テキストを下線モードで表示させ、同一の文字間のバックスペースは、テキストを太字モードで表示させます。このオプションは、-u および -U オプションよりも優先されるため、バックスペースの表示をタブやキャリッジリターンとは別に制御できます。設定されていない場合、バックスペースの表示は -u および -U オプションで制御されます。
--PROC-BACKSPACE
設定されている場合、バックスペースは -U オプションが設定されているかのように扱われます。つまり、バックスペースは制御文字として扱われます。
--proc-return
設定されている場合、キャリッジリターンは、-u オプションも -U オプションも設定されていないものとして処理されます。つまり、改行の直前のキャリッジリターンが削除されます。このオプションは、-u および -U オプションを上書きするため、キャリッジリターンの表示はバックスペースやタブの表示とは別に制御できます。設定されていない場合、キャリッジリターンの表示は -u および -U オプションによって制御されます。
--PROC-RETURN
設定されている場合、キャリッジリターンは -U オプションが設定されているかのように扱われます。つまり、キャリッジリターンは制御文字として扱われます。
--proc-tab
設定されている場合、-U オプションが設定されていない場合と同様にタブが処理されます。つまり、タブはスペースに展開されます。このオプションは -U オプションを上書きするため、タブの表示はバックスペースやキャリッジリターンの表示とは別に制御できます。設定されていない場合、タブの表示は -U オプションによって制御されます。
--PROC-TAB
設定されている場合、タブは -U オプションが設定されているかのように扱われます。つまり、タブは制御文字として扱われます。
--redraw-on-quit
終了時に、端末の初期化解除文字列を送信した後、最後の画面全体を再描画します。端末の端末非初期化文字列によって端末が別の画面から切り替わる場合、less が終了した後も現在のファイルの最後の画面が表示されたままになります。
--rscroll=c
このオプションは、切り捨てられた行のマークに使用する文字を変更します。これは、LESSBINFMT のように 2文字の属性インジケータで始まる場合があります。属性インジケータがない場合は、スタンドアウト(目立つ文字)が使用されます。"-" に 設定すると、切り詰められた行はマークされません。
--save-marks
履歴ファイルにマークを保存して、異なる less の呼び出し間でマークが保持されるようにします。
--search-options=...
既定値の検索修飾子を設定します。値は、1つ以上の文字E、F、K、N、R、またはW の文字列です。これらのいずれかを設定すると、すべての検索パターンの先頭に制御文字を入力した場合と同じ結果になります。例えば、--search-options=W は全てのパターンの先頭に ^W とタイプすることと同じです。この値には 1 から 5 までの数字を含めることもできます。これは、すべての検索パターンの先頭で ^S と入力した後にその数字を続けた場合と同じ結果になります。"-" を指定すると、すべての既定値の検索修飾子が無効になります。
--show-preproc-errors
LESSOPEN プリプロセッサがデータを生成した後にゼロ以外の終了コードで終了した場合、less は警告を表示します。
--status-col-width=n
-J オプションが有効な場合、ステータス列の幅を設定します。既定値は 2文字です。
--status-line
行をマークすると、(ステータス列だけでなく)行全体が強調表示されます。また、-w オプションによってハイライト表示された行は、行全体がハイライト表示されます。--use-color が設定されている場合、ラインは強調表示されるのではなく、色付きになります。
--use-backslash
このオプションは、これに続くオプションの解釈を変更します。--use-backslash オプションの後、オプション文字列内のバックスラッシュは削除され、次の文字は文字通りに解釈されます。これにより、オプション文字列にドル記号を含めることができます。
--use-color

--wordwrap
-S オプションを使用しない場合は、可能であればスペースまたはタブで各行を折り返して、単語が 2行に分割されないようにします。既定値は任意の文字でラップします。

行編集

画面の下部にコマンドライン(たとえば、:e コマンドのファイル名や検索コマンドのパターン)を入力する場合、特定のキーを使用してコマンドラインを操作できます。ほとんどのコマンドには [大括弧] で囲まれた代替形式があり、特定のキーボードにキーが存在しない場合に使用できます。(ESC で始まるフォームは、一部の MS-DOS および Windows システムでは機能しないことに注意してください。これは、ESC が行消去文字であるためです。)これらの特殊キーは、 ^V または ^A のいずれかの"リテラル"文字を前に付けることによって、文字通りに入力できます。バックスラッシュ自体は、2つのバックスラッシュを入力することによって文字通りに入力することもできます。
LEFTARROW [ ESC-h ]
カーソルを左に1スペース分移動します。
RIGHTARROW [ ESC-l ]
カーソルを右に1スペース分移動します。
^LEFTARROW [ ESC-b または ESC-LEFTARROW ]
(つまり、CTRL キーと LEFTARROW キーを同時に押します)。カーソルを 1単語分左に移動します。
^RIGHTARROW [ ESC-w または ESC-RIGHTARROW ]
(つまり、CTRL キーとRIGHTARROW を同時に押します)。カーソルを 1単語分右に移動します。
HOME [ ESC-0 ]
カーソルを行頭に移動します。
END [ ESC-$ ]
カーソルを行末に移動します。
BACKSPACE
カーソルの左側にある文字を削除するか、コマンドラインが空の場合はコマンドをキャンセルします。
DELETE または [ ESC-x ]
カーソルの下の文字を削除します。
^BACKSPACE [ ESC-BACKSPACE ]
(つまり、CONTROL キーと BACKSPACE キーを同時に押します)。カーソルの左側の単語を削除します。
^DELETE [ ESC-X or ESC-DELETE ]
(つまり、CONTROL キーと DELETE を同時に押します)。カーソルの下の単語を削除します。
UPARROW [ ESC-k ]
直前のコマンドラインを呼出します。最初にテキストを入力して上矢印キーを押すと、そのテキストで始まる前のコマンドが呼出されます。
DOWNARROW [ ESC-j ]
次のコマンドラインを呼出します。最初にテキストを入力して↓キーを押すと、そのテキストで始まる次のコマンドが呼出されます。
TAB
カーソルの左側にある部分的なファイル名を補完します。複数のファイル名とマッチする場合は、最初に一致したものがコマンドラインに入力されます。タブを繰り返すと、他の一致するファイル名が順に表示されます。補完したファイル名がディレクトリの場合は、ファイル名に "/" が追加されます。(MS-DOS および Windows システムでは、"\" が追加されます)。環境変数LESSSEPARATOR を使用すると、ディレクトリ名に追加する別の文字を指定できます。
BACKTAB (SHIFT-TAB) [ ESC-TAB ]
TAB と似ていますが、一致するファイル名を逆方向に循環します。
^L
カーソルの左側にある部分的なファイル名を補完します。複数のファイル名と一致する場合は、すべてのマッチしたもの(訳注 複数)がコマンドラインに入力されます。
^U (Unix and OS/2) または ESC (MS-DOS and Windows)
コマンドライン全体を削除するか、カーソルがコマンドラインの先頭にある場合はコマンドをキャンセルします。Unix でラインキル文字を ^U 以外の文字に変更すると、^U の代わりにその文字が使われます。
^G
コマンドライン全体を削除し、メインプロンプトに戻ります。
 

キー割り当て

lesskey ソースファイルを作成して、独自の less コマンドを定義することもできます。このファイルは、コマンドキーのセットと、各キーに関連付けられたアクションを指定します。また、行編集キーを変更したり(行編集 を参照)、less で使用する環境変数を設定できます。ファイルフォーマットの詳細については、lesskey(1) マニュアルページを参照してください。

環境変数 LESSKEYIN が設定されている場合、less はそれを lesskey ソースファイルの名前として使用します。それ以外の場合、less は lesskey ソースファイルの標準的な場所を探します。Unix システムでは、less は "$XDG_CONFIG_HOME/lesskey"、"$HOME/.config/lesskey"、または "$HOME/.lesskey" という lesskey ファイルを探します。MS-DOS および Windows システムでは、less "$HOME/_lesskey" という名前の lesskey ファイルを検索し、見つからない場合は、PATH 環境変数で指定されたディレクトリで "_lesskey" という名前の lesskey ファイルを検索します。OS/2 システムでは、less は "$HOME/lesskey.ini" という名前のlesskeyファイルを検索し、見つからない場合は、INIT環境変数で指定されたディレクトリで "lesskey.ini" という名前の lesskey ファイルを検索し、見つからない場合は、PATH 環境変数で指定されたディレクトリで "lesskey.ini" という名前の lesskeyファイルを検索します。

システム全体の lesskey ソースファイルを設定して、キーの割り当てを行うこともできます。ローカルの lesskey ファイルとシステム全体のファイルの両方でキーが定義されている場合は、ローカルファイルのキー割り当てがシステム全体のファイルのキー割り当てよりも優先されます。環境変数 LESSKEYIN_SYSTEM が設定されている場合、less はそれをシステム全体の lesskey ファイルの名前として使用します。それ以外の場合は、less は、システム全体の lesskey ファイルの標準的な場所を検索します。Unix システムでは、システム全体の lesskey ファイルは/usr/local/etc/syslesskeyです。(ただし、less が /usr/local/etc とは異なる sysconf ディレクトリで構築されている場合は、そのディレクトリに sysless ファイルがあります。MS-DOS および Windows システムでは、システム全体の lesskey ファイルは c:\_syslesskey です。OS/2 システムでは、システム全体の lesskey ファイルは c:\syslesskey.ini です。

古いバージョンの less (v582以前) では、lesskey プログラムによって生成されたバイナリ形式の lesskey ファイルを使用していました。いまでは lesskeyプログラムを使用する必要はなくなりました。  

入力プリプロセッサ

less に対して"入力プリプロセッサ"を定義することができます。less はファイルを開く前に、まず入力プリプロセッサに対して、ファイルの内容の表示方法を変更することができます。入力プリプロセッサは単なる実行可能プログラム (またはシェルスクリプト) であり、ファイルの内容を置換ファイルと呼ばれる別のファイルに書き込みます。元のファイルの内容の代わりに、置換ファイルの内容が表示されます。ただし、ユーザには元のファイルが開いているように見えます。つまり、less は現在のファイルの名前として元のファイル名を表示します。

入力プリプロセッサは、ユーザが入力した元のファイル名であるコマンドライン引数を1つ受け取ります。置換ファイルが作成され、完了すると、置換ファイルの名前が標準出力に出力されます。入力プリプロセッサが置換ファイル名を出力しない場合、less は通常どおり元のファイルを使用します。標準入力を表示する場合、入力プリプロセッサは呼び出されません。入力プリプロセッサを設定するには、LESSOPEN 環境変数を、入力プリプロセッサを呼び出すコマンド行に設定します。このコマンドラインには、文字列 "%s" を1つ含める必要があります。この文字列は、入力プリプロセッサコマンドが呼び出されたときにファイル名に置き換えられます。

less がこのような方法で開かれたファイルを閉じるとき、入力ポストプロセッサと呼ばれる別のプログラムを呼び出します。このプログラムは、必要なクリーンアップ動作(LESSOPEN によって作成された置換ファイルの削除など)を実行します。このプログラムは、ユーザが入力した元のファイル名と置換ファイルの名前の 2つのコマンドライン引数を受け取ります。入力ポストプロセッサを設定するには、LESSCLOSE 環境変数を入力ポストプロセッサを起動するコマンドラインに設定します。2つの文字列 "%s" が含まれる場合があります。1つ目は元のファイル名に置き換えられ、2つ目は LESSOPEN によって出力された置換ファイルの名前に置き換えられます。

例えば、多くのUnix システムでは、これらの 2 つのスクリプトはファイルを圧縮形式で保持することを可能にしますが、less はそれらを直接表示します:

lessopen.sh:

  #! /bin/sh

  case "$1" in

  *.Z)  TEMPFILE=$(mktemp)


  uncompress -c $1 >$TEMPFILE 2>/dev/null

  if [ -s $TEMPFILE ]; then

  echo $TEMPFILE

  else

  rm -f $TEMPFILE

  fi

  ;;

  esac

lessclose.sh:

  #! /bin/sh

  rm $2

これらのスクリプトを使用するには、両方を実行可能な場所に配置し、LESSOPEN="lessopen.shs" と LESSCLOSE="lessclose.shss" を設定します。他のタイプの圧縮ファイルを受け入れるために、より複雑な LESSOPEN および LESSCLOSE スクリプトを作成することもできます。

入力プリプロセッサを設定して、データを置換ファイルに入れるのではなくファイルデータを直接 less にパイプすることもできます。これにより、ファイルの表示を開始する前にファイル全体を解凍する必要がなくなります。このように動作する入力プリプロセッサは、入力パイプと呼ばれます。入力パイプは、置換ファイルの名前を標準出力に書き込むのではなく、置換ファイルの内容全体を標準出力に書き込みます。入力パイプが標準出力に文字を書き込まない場合、置換ファイルはなく、less は通常どおり元のファイルを使用します。入力パイプを使用するには、LESSOPEN 環境変数の最初の文字を縦棒 (|) にして、入力プリプロセッサが入力パイプであることを示します。パイプ以外の入力プリプロセッサと同様に、コマンド文字列には %s を 1つ含める必要があり、これは入力ファイルのファイル名に置き換えられます。

たとえば、多くのUnix システムでは、このスクリプトは前のサンプルスクリプトのように動作します。

lesspipe.sh:

  #! /bin/sh

  case "$1" in

  *.Z)  uncompress -c $1 2>/dev/null


  ;;

  *)    exit 1


  ;;

  esac

  exit $?

このスクリプトを使用するには、スクリプトを実行可能な場所に置き、LESSOPEN="lesspipe.sh%s" を設定します。

プリプロセッサは空のファイルを出力できないことに注意してください。空のファイルは置換がないことを意味すると解釈され、元のファイルが使用されます。これを回避するために、LESSOPEN が 2つの垂直バーで始まる場合、出力が空のときの動作はスクリプトの終了ステータスによって決まります。出力が空で、終了ステータスが 0 の場合、空の出力は置換テキストとみなされます。出力が空で終了ステータスがゼロ以外の場合、元のファイルが使用されます。以前のバージョンの less との互換性のために、LESSOPEN が 1つの縦棒だけで始まる場合、プリプロセッサの終了ステータスは無視されます。

入力パイプを使用する場合、LESSCLOSE ポストプロセッサを使用できますが、クリーンアップする置換ファイルがないため、通常は必要ありません。この場合、LESSCLOSE ポストプロセッサに渡される置換ファイル名は "-" です。

以前のバージョンの less との互換性のため、less が標準入力を参照している場合、入力プリプロセッサやパイプは使用されません。ただし、LESSOPEN の最初の文字がダッシュ (-) の場合、入力プリプロセッサは標準入力およびその他のファイルで使用されます。この場合、ダッシュはプリプロセッサコマンドの一部とは見なされません。標準入力が表示されている場合、入力プリプロセッサには、シングルダッシュで構成されるファイル名が渡されます。同様に、LESSOPEN の最初の 2文字が縦棒とダッシュ (|-)、または 2つの縦棒とダッシュ (||-) の場合、入力パイプは標準入力およびその他のファイルで使用されます。この場合も、ダッシュは入力パイプコマンドの一部とは見なされません。  

国際化文字セット

入力ファイルには次の5種類の文字があります。
通常の文字
これは画面に直接表示できます。
制御文字
これは直接表示されるべきではないが、通常のテキストファイル(バックスペースやタブなど)にあるものです。
バイナリ文字
は直接表示されるべきではなく、テキストファイル内で見つかることも期待されていません。
結合文字(あるいは合成文字)
これは個別に表示されませんが、直前の文字の表示を変更します。(LESSCHARSET が "utf8 " の場合のみ)
削除された文字
これは入力から削除され、表示されません。(LESSCHARSET が "utf8 " の場合のみ)

"文字セット"とは、各文字がこれらのカテゴリのどれに属するかを記述したものです。LESSCHARSET 環境変数を使用して、文字セットを選択できます。LESSCHARSET の取り得る値は以下の通りです:

ascii
BS、TAB、NL、CR、およびフォームフィードは制御文字であり、32～126 の値を持つすべての文字は通常であり、その他はすべてバイナリです。
iso8859
ISO 8859 文字セットを選択します。これは ASCII と同じですが、160 から 255 までの文字は通常の文字として扱われます。
latin1
iso8859 と同じです。
latin9
iso8859 と同じです。
dos
MS-DOS に適した文字セットを選択します。
ebcdic
EBCDIC 文字セットを選択します。
IBM-1047
OS/390 Unix サービスが使用する EBCDIC 文字セットを選択します。latin1の EBCDIC 版です。お使いの環境で LESSCHARSET=IBM-1047 または LC_CTYPE=en_US を設定しても同様の結果が得られます。
koi8-r
ロシア語の文字セットを選択します。
next
NeXT コンピュータに適した文字セットを選択します。
utf-8
ISO 10646 文字セットの UTF-8 エンコーディングを選択します。UTF-8 は、入力ファイルでマルチバイト文字をサポートするという点で特殊です。マルチバイト文字をサポートする唯一の文字セットです。
windows
Microsoft Windows に適した文字セット (cp 1252) を選択します。

まれに、LESSCHARSET で定義可能な文字セット以外の文字セットを使用するために less を調整することが望ましい場合があります。この場合、環境変数 LESSCHARDEF を使用して文字セットを定義できます。文字列内の各文字が、文字セット内の 1文字を表す文字列に設定する必要があります。"." は通常の文字、"c" はコントロール、"b" はバイナリを表します。繰り返しには十進数を使用することも可能です。例えば、"bccc4b." は文字 0 がバイナリ、1、2、3 がコントロール、4、5、6、7がバイナリ、8 が通常であることを意味します。最後の文字以降のすべての文字は最後の文字と同じと見なされるため、9～255の文字は通常どおりになります。(これは例であり、実際の文字セットを表しているとは限りません)。

LESSCHARSET も LESSCHARDEF も設定されていないが、文字列 "UTF-8"、"utf8"、"UTF-8" または "utf8" のいずれかが LC_ALL、LC_CTYPE または LANG 環境変数で見つかった場合、既定の文字集合は UTF-8 です。

この文字列が見つからず、しかもシステムが setlocale(3) インタフェースをサポートしている場合、less は setlocale を使用して文字セットを決定します。setlocale は LANG もしくは LC_CTYPE 環境変数を設定することで制御されます。

最後に、setlocale インターフェイスも使用できない場合、既定の文字集合はutf-8 です。

制御文字とバイナリ文字は目立つように表示されます(たとえば反転表示)。このような文字は、可能であればキャレット記法で表示されます(^A は control-A を表します)。キャレット記法は、0100 ビットを反転した結果が通常の印刷可能な文字になる場合にのみ使用されます。それ以外の場合、文字は角形括弧で囲まれた 16進数として表示されます。この形式は、LESSBINFMT 環境変数を設定することで変更できます。LESSBINFMT は、"*" と表示属性を選択するための1文字で始めることができます。"*k" は点滅、"*d" は太字、"*u" は下線付き、"*s" は目立つように(たとえば反転)、"*n" は通常です。LESSBINFMTが "*" で始まらない場合は、通常属性であると見なされます。LESSBINFMT の残りの部分は、1つの printf 形式のエスケープシーケンス(%の後に x、X、o、d などが続く)を含む文字列です。たとえば、LESSBINFMT が "*u[%x]" の場合、バイナリ文字は括弧で囲まれ、下線付きの 16進数で表示されます。LESSBINFMT が指定されていない場合の既定値は "*s<%02 X>" です。警告:LESSBINFMT を使用して文字を拡張した結果は、31文字未満である必要があります。

文字セットが utf-8の 場合、LESSUTFBINFMT 環境変数の動作は LESSBINFMT と似ていますが、デコードは成功したものの表示に適さない Unicode コードポイント(未割り当てのコードポイントなど)に適用されます。この既定値は "<U+%04 lX>" です。LESSUTFBINFMT と LESSBINFMT は表示属性の設定("*x")を共有しているため、どちらかを指定すると両方に影響します。LESSUTFBINFMT は LESSBINFMT の後に読み取られるため、その設定がある場合は優先されます。UTF-8 ファイル内の問題のあるオクテット(切り捨てられたシーケンスのオクテット、完全であるが最短ではないフォーム・シーケンスのオクテット、無効なオクテット、およびストレイ・トレーリング・オクテット)は、UTF-8 ファイルが不正な形式であることの診断を容易にするために、LESSBINFMT を使用して個別に表示されます。

文字セットが utf-8 の場合、まれに、特定の文字のタイプのユニコード定義をオーバーライドすることが望ましい場合があります。たとえば、Private Use Area内 の文字は通常バイナリ文字として扱われますが、その範囲内の印刷可能な文字を持つカスタムフォントを使用している場合は、less に、そのような文字を印刷可能として扱うに指示することが望ましい場合があります。これは、LESSUTFCHARDEF 環境変数を character type 定義のコンマ区切りリストに設定することで実行できます。各文字タイプ定義は、1つの 16 進コードポイントまたはダッシュで区切られたコードポイントのペアで構成され、その後にコロンとタイプ文字が続きます。各 16進コードポイントの前には、オプションで "U" または "U+" を付けることができます。コードポイントのペアが指定された場合、タイプは 2つの値を含むすべての文字に対して設定されます。コンマで区切られたコードポイント値が複数ある場合、それらは数の昇順でなければなりません。タイプ文字は、次のいずれかです。

p
通常の印字可能な文字。
w
ワイド(2スペース)印刷可能文字。
b
バイナリ(印刷不可能)文字。
c
結合文字(幅 0)。
d
削除された文字(入力から削除され、表示されない)。

たとえば、LESSUTFCHARDEFを 

        E000-F8FF:p,F0000-FFFFD:p,100000-10FFFD:p

に設定すると、すべての Private Use Area 文字が印刷可能として扱われます。

既定では、絵文字修飾子、コンポーネント、バリエーションセレクタは、多くの端末で正しく表示されないため削除されています。それらの一部またはすべてを正しく表示する端末を使用している場合は、LESSUTFCHARDEF を設定してそれらを結合文字として処理することで、それらを表示できます。たとえば、次のように設定すると、すべての文字が合成されます。 

        FE00-FE0F:c,1F3FB-1F3FF:c,1F9B0-1F9B3:c,E0100-E01EF:c
 

プロンプト

-P オプションを使用すると、プロンプトを好みに合わせて調整できます。-P オプションに指定した文字列は、指定したプロンプト文字列に置き換わります。文字列内の特定の文字は特別に解釈されます。プロンプトメカニズムは柔軟性を提供するためにかなり複雑ですが、一般ユーザはパーソナライズされたプロンプト文字列を構築する詳細を理解する必要はありません。

パーセント記号とそれに続く 1文字は、次の文字が何であるかに応じて展開されます。(入力プリプロセッサが使用されている場合、以下の入力ファイルサイズへの参照は、前処理されたサイズを指します)。

%bX
現在の入力ファイルへのバイトオフセットに置き換えられます。b の後には、バイトオフセットが使用される行を指定する 1文字(上記の X が続きます。文字が "t" の場合は、ディスプレイの一番上の行のバイトオフセットが使用され、"m" は中央の行を使用することを意味し、"b" は最下行を使用することを意味し、"B" は最下行の直後の行を使用することを意味し、"j" は -j オプションで指定された"ターゲット"行を使用することを意味します。
%B
現在の入力ファイルのサイズに置き換えられます。
%c
画面の最初の列に表示されるテキストの列番号に置き換えられます。
%C
画面の最後のカラムに表示される(または表示される)テキストのカラム番号に置き換えられます。
%dX
入力ファイル内の行のページ番号に置き換えられます。使用する行は、%b オプションと同様に、X によって決定されます。
%D
入力ファイルのページ数、つまり入力ファイルの最後の行のページ番号に置き換えられます。
%E
エディタの名前に置き換えられます(VISUAL 環境変数から、または VISUAL が定義されていない場合は EDITOR 環境変数から)。以下のLESSEDIT 機能の説明を参照してください。
%f
現在の入力ファイルの名前に置き換えられます。
%F
現在の入力ファイル名の最後のコンポーネントに置き換えられます。
%g
現在の入力ファイルのシェルエスケープされた名前に置き換えられます。これは、展開された文字列が LESSEDIT などのシェルコマンドで使用される場合に便利です。
%i
入力ファイルのリスト内の現在のファイルのインデックスに置き換えられます。
%lX
入力ファイルの行番号に置換されます。使用する行は、%b オプションと同様に、X によって決定されます。
%L
入力ファイルの最終行の行番号に置き換えられます。
%m
入力ファイルの合計数に置き換えられます。
%o
現在選択されている OSC 8 ハイパーリンクのURIに置き換えられるか、ハイパーリンクが選択されていない場合は疑問符に置き換えられます。これは、^O^O コマンドの説明で説明されているように、OSC 8 ハンドラによって使用されます。
%pX
バイトオフセットに基づいて、現在の入力ファイルのパーセント位置で置き換えられます。使用される行は、%b オプションと同様に X によって決定されます。
%PX
行番号に基づいて、現在の入力ファイルのパーセント位置で置き換えられます。使用される行は、%b オプションと同様に X によって決定されます。
%Q
現在表示されている最も長い行の長さに対する、画面に表示されているテキストの最後の列の割合 (%C/%W) に置き換えられます。このシーケンスを使用すると、プロンプトの表示が通常より遅くなる可能性があることに注意してください。
%s
%Bと同じです。
%t
末尾のスペースを削除します。通常は文字列の末尾に使用されますが、どこにでも使用できます。
%T
通常は"file"という単語に展開されます。ただし、-t オプションを使用してタグリストを介してファイルを表示する場合は、"tag" という単語に展開されます。
%W
現在画面に表示されている最も長い行の幅に置き換えられます。このシーケンスを使用すると、プロンプトの表示が通常より遅くなる可能性があることに注意してください。
%x
リスト内の次の入力ファイルの名前に置き換えられます。

不明な項目がある場合(たとえば、入力がパイプの場合のファイルサイズ)は、代わりに疑問符が出力されます。

プロンプト文字列の形式は、特定の条件に応じて変更できます。疑問符とそれに続く1文字は、"IF" のように機能します。次の文字に応じて、条件が評価されます。条件が 真 の場合、疑問符および条件文字の後に続く文字(ピリオドまで)がプロンプトに含まれます。条件が偽の場合、そのような文字は含まれません。疑問符とピリオドの間にあるコロンは、"ELSE" として働きます。コロンとピリオドの間にある任意の文字は、IF 条件が 偽 の場合にのみ文字列に含まれます。条件文字(疑問符の後)には、次の文字を使用できます。

?a
すでにプロンプトに文字が含まれている場合は真。
?bX
指定した行のバイトオフセットが既知の場合は真。
?B
現在の入力ファイルのサイズが既知の場合は真。
?c
文字列が横方向にシフトしている場合(%c は 0 ではない)に真。
?dX
指定した行のページ番号が既知の場合は真。
?e
ファイルの終りのときに真。
?f
入力ファイル名があるとき (入力がパイプでないとき) に真。
?lX
指定した行の行番号が既知の場合に真。
?L
ファイルの最終行の行番号が既知の場合に真。
?m
2 つ以上の入力ファイルがある場合に真。
?n
新しい入力ファイルの最初のプロンプトのとき真。
?pX
バイトオフセットに基づいて、指定された行の現在の入力ファイルへのパーセントが既知である場合は真。
?PX
行番号に基づいて、指定された行の現在の入力ファイルへの割合が既知である場合は真。
?Q
%Q が 100未満の場合は真。このシーケンスを使用すると、プロンプトの表示が通常より遅くなる可能性があることに注意してください。
?s
"?B"と同じです。
?x
次の入力ファイルがある場合(つまり、現在の入力ファイルが最後のファイルでない場合)に真。

特殊文字(疑問符、コロン、ピリオド、パーセント、およびバックスラッシュ)以外の文字は、文字通りプロンプトの一部になります。特殊文字は、その前にバックスラッシュを付けることで、文字通りプロンプトに含めることができます。

次に例を示します:

?f%f:Standard input.

このプロンプトは、ファイル名が既知の場合はそれを表示し、わからなければ "Standard input" という文字列を表示します。

?f%f .?ltLine %lt:?pt%pt\%:?btByte %bt:-...

ファイル名が既知の場合は、このプロンプトによってファイル名が出力されます。ファイル名の後には、行番号が既知の場合はそれが続き、それ以外の場合はパーセントが、わかっていない場合はバイトオフセットが続きます。それ以外の場合は、ダッシュが出力されます。各疑問符には対応するピリオドがあり、%pt の後の % はバックスラッシュでエスケープすることによって文字通り含まれていることに注意してください。

?n?f%f .?m(%T %i of %m) ..?e(END) ?x- Next\: %x..%t

これにより、ファイル内の最初のプロンプトの場合はファイル名が表示され、複数の入力ファイルがある場合は "file N of N" メッセージが表示されます。次に、ファイルの終わりにいる場合は、文字列 "(END)" が出力され、その後に次のファイルがあればその名前が出力されます。最後に、後続のスペースは切り捨てられます。これは既定のプロンプトです。参考までに、他の2つのプロンプト -m および -M それぞれの既定値を示します。ここでは、読みやすさのためだけに、それぞれが2行に分かれています。 

?n?f%f .?m(%T %i of %m) ..?e(END) ?x- Next\: %x.:
        ?pB%pB\%:byte %bB?s/%s...%t

?f%f .?n?m(%T %i of %m) ..?ltlines %lt-%lb?L/%L. :
        byte %bB?s/%s. .?e(END) ?x- Next\: %x.:?pB%pB\%..?c (column %c).%t

次に、= コマンドによって生成される既定のメッセージを示します。 

?f%f .?m(%T %i of %m) .?ltlines %lt-%lb?L/%L. .
        byte %bB?s/%s. ?e(END) :?pB%pB\%..?c (column %c).%t

プロンプト拡張機能は別の目的にも使用されます。環境変数 LESSEDIT が定義されている場合は、v コマンドが呼び出されたときに実行されるコマンドとして使用されます。LESSEDIT 文字列は、プロンプト文字列と同じ方法で展開されます。LESSEDITの既定値は次のとおりです: 

        %E ?lm+%lm. %g

これにより、エディタ名、+、行番号、シェルでエスケープされたファイル名の順に展開されることに注意してください。使用しているエディタが "+linenumber" 構文を受け入れない場合、または起動構文にその他の違いがある場合は、LESSEDIT を変更してこの既定値を修正できます。  

セキュリティ:

環境変数 LESSSECURE が 1 に設定されている場合、less は "セキュア" モードで実行されます。このモードでは、次の機能は無効です。
edit
編集コマンド (v)
examine
検査コマンド (:e)
glob
ファイル名の * などのメタ文字
ファイル名の補完(TAB, ^L)
history
履歴ファイル
lesskey
lesskey ファイル -k と --lesskey-src の使用
lessopen
入力プリプロセッサ(LESSOPEN 環境変数)
logfile
ログファイル(s と -o
osc8
OSC 8 リンクのオープン (^O^O)
pipe
パイプコマンド(|)
shell
シェルと pshell コマンド(!および #)
stop
SIGTSTPシグナルで less を停止。
tags
タグファイル(-t) の使用。

LESSSECURE_ALLOW 環境変数には、LESSSECURE が設定されているときに選択的に有効になる機能の名前のコンマ区切りリストを設定できます。各機能名は、上記のリストの各行の最初の単語です。フィーチャ名は、あいまいでない限り省略することができます。たとえば、次のようになります。 LESSSECURE=1 と LESSSECURE_ALLOW=hist,edit が設定されている場合、履歴ファイルと編集コマンドを除いて、上記のすべての機能が無効になります。

Lessは、"セキュア" モードで永続的にコンパイルすることもできます。その場合、LESSSECURE 変数と LESSSECURE_ALLOW 変数は無視されます。  

MORE との互換性

環境変数 LESS_IS_MORE が 1 に設定されている場合、またはプログラムが "more" という名前のファイルリンクを介して呼び出され、環境変数 LESS_IS_MORE が 0 に設定されていない場合、less は ほとんどの場合 POSIX more(1) コマンド仕様に従って動作します。このモードでは、less は次のように異なる動作をします。

-e オプションの動作は異なります。-e オプションが設定されていない場合、less は -e オプションが設定されているかのように動作します。-e オプションが設定されている場合、less は -E オプションが設定されているかのように動作します。

-m オプションの動作は異なります。-m オプションが設定されていない場合は、mediumプロンプトが使用され、文字列 "--More--" が先頭に付加されます。-m オプションが設定されている場合、短いプロンプトが使用されます。

-n オプションは、-z オプションと同様に動作します。-n オプションの通常の動作は、このモードでは使用できません。

-p オプションへのパラメータは、検索パターンではなく less コマンドとして解釈されます。

LESS 環境変数は無視され、代わりに MORE 環境変数が使用されます。  

環境変数

環境変数は、通常どおりシステム環境で指定することも、lesskey(1) ファイルで指定することもできます。環境変数が複数の場所で定義されている場合、ローカルの lesskey ファイルで定義された変数は、システム環境で定義された変数よりも優先されます。システム環境で定義された変数は、システム全体の lesskey ファイルで定義された変数よりも優先されます。
COLUMNS
画面の列数を設定します。TERM 変数で指定されたカラム数よりも優先されます。(しかし、TIOCGWINSZ や WIOCGETD をサポートするウィンドウシステムを使っているなら、ウィンドウシステムの画面サイズの考え方は環境変数 LINES と COLUMNS よりも優先されます。
EDITOR
エディタの名前(v コマンドで使用)。
HOME
ユーザーのホームディレクトリの名前(UNIX および OS/2 システムで lesskey ファイルを検索するために使用されます)。
HOMEDRIVE, HOMEPATH
環境変数 HOMEDRIVE と HOMEPATH の連結は、HOME 変数が設定されていない場合、ユーザーのホームディレクトリー名前になります(Windows バージョンのみ)。
INIT
ユーザーの init ディレクトリーの名前(OS/2 システムで lesskey ファイルを検索するために使用されます)。
LANG
文字セットを決定する言語。
LC_CTYPE
文字セットを決定する言語。
LESS
自動的に less に渡されるオプション。
LESSANSIENDCHARS
ANSI カラーエスケープシーケンス(既定値 "m")を終了する文字。
LESSANSIMIDCHARS
ANSI カラーエスケープシーケンス(既定値 "0123456789:;[!"'#%()*+
LESSANSIOSCALLOW
-R が有効なときに、端末に直接出力されるOSC タイプのコンマ区切りリスト(既定値は "8" で、これは OSC 8 シーケンスのみが直接出力される)。
LESSANSIOSCCHARS
"OSコマンド" シーケンスの開始をマークするために ESC 文字に続く文字。この文字に続く文字列終端文字(ESC-バックスラッシュまたは BEL)までのすべての文字は、OSC シーケンス(既定値 "]")の一部と見なされます。LESSANSIOSCCHARS の文字の後にアスタリスクが付いている場合は、ファイル内容の中でその文字で始まるシーケンスが端末に渡されます。アスタリスクが付いていない場合は、プロンプト文字列に表示されるシーケンスだけが渡されます。
LESSBINFMT
印刷不可能な非制御文字を表示するための形式。
LESSCHARDEF
文字セットを定義します。
LESSCHARSET
定義済みの文字セットを選択します。
LESSCLOSE
(オプションの)入力ポストプロセッサを起動するコマンド行。
LESSECHO
lessechoプログラムの名前(既定値では "lessecho")。lessecho プログラムは、Unix システムでファイル名に含まれる * や ? などのメタ文字を展開するために必要です。
LESSEDIT
エディタプロトタイプ文字列(v コマンドに使用)。"プロンプト" の説明を参照してください。
LESSGLOBALTAGS
グローバルタグを検索するために -t オプションで使用されるコマンドの名前。システムに global(1) コマンドがある場合は、通常は "global" に設定する必要があります。設定されていない場合、グローバルタグは使用されません。
LESSHISTFILE
less の呼び出しの間に検索コマンドとシェルコマンドを記憶するために使用される履歴ファイルの名前。"-" または "/dev/null" に設定すると、履歴ファイルは使用されません。既定値はオペレーティングシステムによって異なりますが、通常は次のとおりです。
Linux および Unix
"$XDG_STATE_HOME/lesshst" or "$HOME/.local/state/lesshst" または "$XDG_DATA_HOME/lesshst" or "$HOME/.lesshst".
Windows および MS-DOS
"$HOME/_lesshst".
OS/2
"$HOME/lesshst.ini" or "$INIT/lesshst.ini".
LESSHISTSIZE
履歴ファイルに保存するコマンドの最大数。既定値は 100 です。
LESSKEYIN
lesskey sourceファイル名の既定値。
LESSKEY
lesskey binaryファイル名の既定値。("$LESSKEYIN" が存在する場合は使用されません。)
LESSKEY_CONTENT
この値は、--lesskey-content オプションのパラメータであるかのように解析されます。
LESSKEYIN_SYSTEM
システム全体のlesskey sourceファイル名の既定値。
LESSKEY_SYSTEM
システム全体のlesskey binaryファイル名の既定値。("$LESSKEYIN_SYSTEM" が存在する場合は使用されません。)
LESSMETACHARS
シェルによって "メタ文字" と見なされる文字のリスト。
LESSMETAESCAPE
シェルに送るコマンドの各メタ文字の前に less が付ける接頭辞(既定値 "\")。
LESSNOCONFIG
"-" に設定すると、TERM 以外のすべての環境変数は無視されます(設定されていないものとして扱われます)。環境変数名をコンマで区切ったリストに設定すると、TERM 以外のすべての環境変数とリスト内の環境変数は無視されます。いずれの場合も(空でない値が設定されている場合)、すべての lesskey ファイルも無視されます。
LESSOPEN
(オプションの)入力プリプロセッサを起動するコマンドライン。
LESSSECURE
"セキュア" モードで less を実行。"セキュリティ" の項の説明を参照してください。
LESSSECURE_ALLOW
通常は LESSSECURE によって無効にされる個々の機能を有効にします。"セキュリティ" の項の説明を参照してください。
LESSSEPARATOR
ファイル名補完時のディレクトリ名に付加される文字列(MS-DOS, Windows, OS/2では既定値 "\"、それ以外は "/")。
LESSUTFBINFMT
印刷不可能な Unicode コードポイントを表示するためのフォーマット。
LESSUTFCHARDEF
指定した Unicode 文字のタイプを上書きします。
LESS_COLUMNS
画面の列数を設定します。COLUMNSとは異なり、システムの画面サイズの概念よりも優先されるため、less が全画面幅未満を使用にするために使用できます。負の値に設定すると、実際の画面幅よりも少ない列数が使用されるように設定します。
LESS_LINES
画面の行数を設定します。LINES とは異なり、システムの画面サイズの考え方よりも優先されるので、less が画面の高さ全体よりも小さいものを使用にするために使用できます。負の値に設定すると、実際の画面の高さよりもはるかに少ない行数が使用されるように設定されます。設定すると、less 移動コマンドごとに画面全体を再描画するため、スクロールが遅くなる場合があります。
LESS_DATA_DELAY
入力からのデータの読み取りを開始してからの時間(ミリ秒単位)。その後、"Waiting for data" メッセージが表示されます。既定値は 4000(4秒)です。
LESS_IS_MORE
more(1) コマンドをエミュレートします。
LESS_OSC8_xxx
"xxx" が "http" や "file" などの URI スキームである場合、そのスキームを持つ URI を含む OSC 8 リンクを開くための OSC 8 ハンドラを設定します。
LESS_OSC8_ANY
"xxx" スキームに特定の LESS_OSC8_xxx ハンドラが設定されていない OSC 8 リンクをオープンするための OSC 8 ハンドラを設定します。
LESS_SHELL_LINES
-F オプションが設定されている場合、ファイルの表示に使用される画面行数が、画面の高さから LESS_SHELL_LINES 変数の値を引いた値以下になると、less は自動的に終了します。したがって、画面に1行以上表示されるシェルプロンプトを使用する場合は、この変数をプロンプトの行数に設定して、-F を使用したときにファイル全体が表示されるようにすることができます。設定されていない場合、LESS_SHELL_LINES は 1 とみなされます。
LESS_SIGUSR1
1つまたは複数の less コマンド文字の文字列に設定すると、less がSIGUSR1 シグナルを受信したときに、これらのコマンドが実行されます。
LESS_TERMCAP_xx
"xx" は任意の2文字で、端末の termcap"xx" 機能の定義を上書きします。文字列内のエスケープシーケンスは処理されないため、 ESC などの印刷不可能な文字は、文字列内に文字通りに存在する必要があります。
LESS_TERMINFO_xxxx
"xxxx" は任意の文字列で、端末の terminfo"xxxx" 機能の定義を上書きします。LESS_TERMCAP_xx または LESS_TERMINFO_xxxx のいずれかを使用して、端末機能を上書きできます。これは、less が termcap または terminfo ライブラリのどちらで構築されたかによりません。
LESS_TERMCAP_BRACKETED_PASTE_START
標準の ANSI エスケープシーケンスを上書きして、ブラケットによる貼り付けを有効にします。これは、--no-paste オプションが有効な場合に使用されます。
LESS_TERMCAP_BRACKETED_PASTE_END
標準の ANSI エスケープシーケンスを上書きして、ブラケットによる貼り付けを無効にします。
LESS_TERMCAP_MOUSE_START
標準の ANSI エスケープシーケンスを上書きして、マウスレポートを有効にします。これは、--mouse オプションが有効な場合に使用されます。
LESS_TERMCAP_MOUSE_END
標準の ANSI エスケープシーケンスを上書きして、マウスレポートを無効にします。
LESS_TERMCAP_SUSPEND
画面の更新を一時的に停止するエスケープシーケンスを定義します。これは、画面をクリアする前に端末に送信されます。これは、特定の端末で画面が再描画される際のティアリングを避けるために使用できます。
LESS_TERMCAP_RESUME
画面の更新を再開するエスケープシーケンスを定義します。これは、プロンプトを表示した後に端末に送られます。
LESS_UNSUPPORT
スペースで区切られたコマンド行オプションのリスト。これらのオプションがコマンドラインや LESS 環境変数に指定されていても無視されます(エラーメッセージは表示されません)。LESS_UNSUPPORT にリストされているオプションは、- および -- コマンドで変更できます。LESS_UNSUPPORT 内の各オプションは、ダッシュの後に 1 文字のオプション文字が続くか、2 つのダッシュの後に長いオプション名が続きます。
LINES
画面の行数を設定します。TERM 変数で指定された行数よりも優先されます。(しかし、TIOCGWINSZ や WIOCGETD をサポートするウィンドウシステムを使っているなら、ウィンドウシステムの画面サイズの考え方は環境変数 LINES と COLUMNS よりも優先されます。
MORE
more互換モードでの実行時に自動的に less に渡されるオプション。
PATH
ユーザーの検索パス(MS-DOS、Windows、および OS/2 システムで lesskey ファイルを検索するために使用されます)。
POSIXLY_CORRECT
任意の値に設定すると、コマンドラインのすべてのオプション引数がファイル名引数の前に置かれることになります。これは、lesskey ファイル内ではなく、実際の環境変数として設定する必要があります。
SHELL
command を実行し、ファイル名を展開するために使用されるシェル。
TERM
less が走行している端末のタイプ。
VISUAL
エディタの名前(v コマンドで使用)。
XDG_CONFIG_HOME
lesskey ファイルを置ける場所。KEY BINDINGS セクションを参照。
XDG_DATA_HOME
履歴ファイルの場所。環境変数LESSHISTFILE の説明を参照してください。
XDG_STATE_HOME
履歴ファイルの場所。環境変数LESSHISTFILE の説明を参照してください。
