名前

libtool - 一般化されたライブラリビルドのためのサポートサービスを 提供します。  

書式

libtool [,OPTION/]... [,MODE-ARG/]...  

説明

一般化されたライブラリビルドのためのサポートサービスを提供します。  

オプション

--config
設定変数をすべて表示します。
--debug
詳細なシェルトレース出力を有効にします。
-n, --dry-run
ファイルへの修正は何も行わずに、コマンドだけ表示します。
--features
基本的な設定情報を表示します。
--finish

 '--mode=finish' 操作を利用します。
--mode=,MODE/
操作モードの中から MODE を利用します。
--no-finish
共有ライブラリキャッシュを更新しません。
--no-quiet, --no-silent
既定の情報メッセージを表示します。
--no-warnings
'-Wnone' と同様。
--preserve-dup-deps
重複した依存ライブラリを削除しません。
--quiet, --silent
通常のメッセージを表示しません。
--reorder-cache=,DIRS/
優先 DIRS 用の共有ライブラリキャッシュの並べ替え
--tag=,TAG/
設定変数を TAG で示されるタグから利用します。
-v, --verbose
デフォルトよりも多くのメッセージを表示します。
--version
バージョン情報を表示します。
-W, --warnings=,CATEGORY/
CATEGORY に該当する警告メッセージを表示します。 [デフォルト: all]
-h, --help, --help-all
ヘルプメッセージをそれぞれ、短く、長く、詳細に表示します。
 

警告のカテゴリーは以下のとおりです。

'all'
警告メッセージをすべて表示します。
'none'
警告メッセージをすべて非表示にします。
'error'
警告を致命的エラーとして扱います。

MODE は以下のいずれかです。

clean
ビルドディレクトリ内のファイルを削除します。
compile
ソースファイルをコンパイルして libtool オブジェクトを 生成します。
execute
ライブラリのパスを自動設定した上でプログラムを実行します。
finish
libtool ライブラリのインストールをすべて行います。
install
ライブラリと実行ファイルをインストールします。
link
ライブラリまたは実行ファイルを生成します。
uninstall
インストールディレクトリからライブラリを削除します。

MODE-ARGS は MODE に応じて変わります。 一つめのオプションとして受け渡される場合は、 '--mode=MODE' は 'MODE' として省略できます。 あるいはその短縮形とすることもできます。

GNU libtool ホームページ: <https://www.gnu.org/software/libtool/>.

バグを報告する際には、 バグが再現できるテストケースを示した上で、 以下の情報を含めてください。

ホストのトリプレット (triplet):
x86_64-pc-linux-gnu
シェル:
,/bin/bash/
コンパイラー:
gcc
コンパイラーフラグ: -g -O2 リンカー: ,/usr/bin/ld/ -m elf_x86_64 (gnu かどうか? yes) version: libtool (GNU libtool) 2.5.4 automake: automake (GNU automake) 1.17 autoconf: autoconf (GNU Autoconf) 2.72e
 

バグ報告

関連項目

libtool の完全なドキュメントは Texinfo マニュアルとしてメンテナンスされています。info と libtool の両プログラムが適切にインストールされていれば、以下のコマンド
info libtool

を実行して完全なマニュアルを参照できます。
