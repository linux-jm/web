名前

unlockpt - 擬似端末マスタ/スレーブのペアのロックを解除する  

ライブラリ

標準 C ライブラリ (libc,~-lc)  

書式

#define _XOPEN_SOURCE
#include <stdlib.h>

int unlockpt(int fd);

glibc 向けの機能検査マクロの要件 (feature_test_macros(7) 参照):

unlockpt(): 


    Since glibc 2.24:
        _XOPEN_SOURCE >= 500
    glibc 2.23 and earlier:
        _XOPEN_SOURCE
 

説明

unlockpt() 関数はファイルディスクリプター fd で参照されるマスタ擬似端末に対応するスレーブ擬似端末のロックを解除する。

擬似端末のスレーブ側をオープンする前に、 unlockpt() を呼び出す必要がある。  

返り値

When successful, unlockpt() returns 0. Otherwise, it returns -1 and sets errno to indicate the error.  

エラー

EBADF
引数 fd が書き込み用にオープンされたファイルディスクリプターでない。
EINVAL
引数 fd がマスタ擬似端末に対応するものではない。
