名前

timegm, timelocal - gmtime と localtime の逆関数  

ライブラリ

標準 C ライブラリ (libc, -lc)  

書式

#include <time.h>

[[deprecated]] time_t timelocal(struct tm *tm);
time_t timegm(struct tm *tm);
glibc 向けの機能検査マクロの要件 (feature_test_macros(7) 参照):

timelocal(), timegm(): 

    glibc 2.19 から:
        _DEFAULT_SOURCE
    glibc 2.19 とそれ以前:
        _BSD_SOURCE || _SVID_SOURCE
 

説明

関数 timelocal() と timegm() は、localtime(3) と gmtime(3) の逆関数です。どちらの関数も要素別の時刻を取得し、カレンダ時刻(1970-01-01 00:00:00 +0000, UTCの紀元からの秒数)に変換します。2つの関数の違いは、timelocal() では変換時にローカル・タイムゾーンが考慮されるのに対して、timegm() では協定世界時 (UTC) の入力値が考慮されることです。  

返り値

成功した場合、これらの関数はカレンダー時刻(紀元からの秒数)を time_t 型の値として返します。エラーの場合は (time_t)\ -1 を返し、エラーを示すために errno を設定します。  

エラー

EOVERFLOW
結果を表示できません。

標準

BSD.  

履歴

GNU, BSD.

timelocal() 関数は POSIX の標準関数 mktime(3) と同じものです。そのため、これを使う理由はないはずです。  

関連項目

gmtime(3), localtime(3), mktime(3), tzset(3)
