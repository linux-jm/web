bcopy

Section: C Library Functions (3)
Updated: 2026-02-08
Index JM Home Page roff page
 

名前

bcopy - バイト列をコピーする  

ライブラリ

標準 C ライブラリ (libc,~-lc)  

書式

#include <strings.h>

[[deprecated]] void bcopy(size_t n;
                          const void src[n], void dest[n], size_t n);
 

説明

bcopy() は src から先頭 n バイトを dest にコピーする。 領域が重なっていても、結果は正しいものである。  

返り値

なし。  

属性

この節で使用されている用語の説明については、 attributes(7) を参照。
インターフェース属性値
bcopy() Thread safetyMT-Safe
 

標準規格

なし。  

歴史

4.3BSD.

Marked as LEGACY in POSIX.1-2001: use memcpy(3) or memmove(3) in new programs. Note that the first two arguments are interchanged for memcpy(3) and memmove(3). POSIX.1-2008 removes the specification of bcopy().  

関連項目

bstring(3), memccpy(3), memcpy(3), memmove(3), strcpy(3), strncpy(3)
