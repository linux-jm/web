getdtablesize

名前

getdtablesize - ファイルディスクリプターテーブルのサイズを取得する  

ライブラリ

標準 C ライブラリ (libc,~-lc)  

書式

#include <unistd.h>

int getdtablesize(void);

glibc 向けの機能検査マクロの要件 (feature_test_macros(7) 参照):

getdtablesize(): 


    glibc 2.20 以降:
        _DEFAULT_SOURCE || ! (_POSIX_C_SOURCE >= 200112L)
    glibc 2.12 から 2.19:
        _BSD_SOURCE || ! (_POSIX_C_SOURCE >= 200112L)
    glibc 2.12 より前:
        _BSD_SOURCE || _XOPEN_SOURCE >= 500
 

説明

getdtablesize() は 1 つのプロセスのオープンできるファイル数の最大値を返す。 返り値はファイルディスクリプターの取り得る最大値より 1 大きい値である。  

返り値

プロセス毎にオープンできるファイル数の現在の制限値。  

エラー

On Linux, getdtablesize() can return any of the errors described for getrlimit(2); see VERSIONS below.  

属性

この節で使用されている用語の説明については、 attributes(7) を参照。
インターフェース属性値

 getdtablesize() 		Thread safetyMT-Safe
 

バージョン

glibc 版の getdtablesize() は、 getrlimit(2) を呼び出して、現在の RLIMIT_NOFILE を返す。 呼び出しに失敗した場合は OPEN_MAX を返す。

Portable applications should employ sysconf(_SC_OPEN_MAX) instead of this call.  

標準規格

なし。  

歴史

SVr4, 4.4BSD (first appeared in 4.2BSD).  

関連項目

close(2), dup(2), getrlimit(2), open(2)
