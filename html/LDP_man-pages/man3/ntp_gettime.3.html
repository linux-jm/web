ntp_gettime

名前

ntp_gettime、ntp_gettimex - 時間パラメータの取得 (NTP daemon インターフェイス)  

ライブラリ

標準 C ライブラリ (libc, -lc)  

書式

#include <sys/timex.h>

int ntp_gettime(struct ntptimeval *ntv);
int ntp_gettimex(struct ntptimeval *ntv);
 

説明

これらの API は両方とも、 ntv 引き数(以下のタイプの構造体)を介して呼び出し元に情報を返します。 

struct ntptimeval {
    struct timeval time;    /* Current time */
    long maxerror;          /* Maximum error */
    long esterror;          /* Estimated error */
    long tai;               /* TAI offset */

    /* Further padding bytes allowing for future expansion */
};

この構造体のメンバーは以下の通りです:

time
timeval 構造で表される現在の時刻: 
struct timeval {
    time_t      tv_sec;     /* 紀元からの秒 */
    suseconds_t tv_usec;    /* マイクロ秒 */
};
maxerror
最大エラーはマイクロ秒単位です。この値は ntp_adjtime(3) によって初期化され、定期的に(Linux では毎秒)増加しますが、上限はあります (カーネル定数 NTP_PHASE_MAX、値は 16000)。
esterror
マイクロ秒単位の推定エラー。この値には、システムクロックと実際の時刻との差の推定値を含めるように ntp_adjtime(3) を介して設定できます。この値はカーネル内部では使用されません。
tai
TAI (Atomic International Time) オフセット。

ntp_gettime() はntptimeval 構造体を返します。この構造体の time、maxerror、esterror フィールドに値が入っています。

ntp_gettimex() は ntp_gettime()と同じタスクを実行しますが、 tai フィールドの情報も返します。  

返り値

ntp_gettime() と ntp_gettimex() の戻り値は adjtimex(2) と同じです。正しいポインタ引数が与えられれば、これらの関数は常に成功します。
