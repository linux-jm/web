iconv_close

名前

iconv_close - 文字セット変換のためのディスクリプターを解放する  

LIBRARY

標準 C ライブラリ (libc,~-lc)  

書式

#include <iconv.h>

int iconv_close(iconv_t cd);
 

説明

iconv_close() 関数は、 iconv_open(3) を使って以前に割り当てられた 変換ディスクリプター cd を解放する。  

返り値

On success, iconv_close() returns 0; otherwise, it returns -1 and sets errno to indicate the error.
