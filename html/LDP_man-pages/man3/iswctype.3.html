iswctype

名前

iswctype - ワイド文字の分類  

ライブラリ

標準 C ライブラリ (libc,~-lc)  

書式

#include <wctype.h>

int iswctype(wint_t wc, wctype_t desc);
 

説明

If wc is a wide character having the character property designated by desc (or in other words: belongs to the character class designated by desc), then the iswctype() function returns nonzero. Otherwise, it returns zero. If wc is WEOF, zero is returned.

desc は wctype(3) 関数が返す文字属性指示子でなければならない。  

返り値

iswctype() 関数は、wc が指示された属性を持つならば 0 でない 値を返す。そうでなければ 0 を返す。  

属性

この節で使用されている用語の説明については、 attributes(7) を参照。
インターフェース属性値
iswctype() Thread safetyMT-Safe
 

標準規格

C11, POSIX.1-2008.  

歴史

POSIX.1-2001, C99.  

注意

iswctype() の動作は、現在のロケールの LC_CTYPE カテゴリーに依存する。
