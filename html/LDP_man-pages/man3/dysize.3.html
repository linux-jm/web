名前

dysize - 与えた年の日数を返す  

ライブラリ

標準 C ライブラリ (libc, -lc)  

書式

#include <time.h>

int dysize(int year);

glibc 向けの機能検査マクロの要件 (feature_test_macros(7) 参照):

dysize(): 

    glibc 2.19 から:
        _DEFAULT_SOURCE
    glibc 2.19 とそれ以前:
        _BSD_SOURCE || _SVID_SOURCE
 

説明

この関数は通常の年には 365 を返し、うるう年には 366 を返します。うるう年の計算は次の式によります: 

(year) %4 == 0 && ((year) %100 != 0 || (year) %400 == 0)

この式は __isleap(year) マクロで定義されており、 <time.h> にもあります。

この節で使用されている用語の説明については、 attributes(7) を参照してください。

標準

なし。  

履歴

SunOS 4.x.

これは互換用の関数に過ぎません。新しいプログラムでは使わないでください。
