名前

bcmp - バイト列を比較する  

ライブラリ

標準 C ライブラリ (libc,~-lc)  

書式

#include <strings.h>

[[deprecated]] int bcmp(size_t n;
                        const void s1[n], const void s2[n], size_t n);
 

説明

bcmp() is identical to memcmp(3); use the latter instead.  

標準規格

なし。  

歴史

4.3BSD. Marked as LEGACY in POSIX.1-2001; removed in POSIX.1-2008.  

関連項目

memcmp(3)
