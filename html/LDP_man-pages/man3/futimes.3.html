名前

futimes, lutimes - ファイルのタイムスタンプを変更する  

ライブラリ

標準 C ライブラリ (libc, -lc)  

書式

#include <sys/time.h>

int futimes(int fd, const struct timeval tv[2]);
int lutimes(const char *path, const struct timeval tv[2]);

glibc 向けの機能検査マクロの要件 (feature_test_macros(7) 参照):

futimes(), lutimes(): 

    glibc 2.19 よりあと:
        _DEFAULT_SOURCE
    glibc 2.19 以前:
        _BSD_SOURCE
 

説明

futimes() は utimes(2) と同じ方法でファイルのアクセス時刻と修正時刻を変更します。違いは、タイムスタンプを変更するファイルを、パス名ではなく、ファイルディスクリプター fd を用いて指定する点です。

lutimes() は utimes(2) と同じ方法でファイルのアクセス時刻と修正時刻を変更します。違いは、 path がシンボリックリンクを参照している場合に、リンクの展開を行わず、代わりにシンボリックリンクのタイムスタンプを変更する点です。  

返り値

成功すると、 0 が返ります。 エラーの場合、-1 を返し、 errno にエラーを示す値をセットします。  

エラー

エラーは utimes(2) と同じですが、 futimes() では以下のエラーが追加になっています:
EBADF
fd が有効なファイルディスクリプターではありません。
ENOSYS
/proc ファイルシステムにアクセスできません。

lutimes() では以下のエラーが追加になっています:

ENOSYS
カーネルがこの関数をサポートしていません。 Linux 2.6.22 以降が必要です。
