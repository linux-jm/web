名前

fabs, fabsf, fabsl - 浮動小数点実数の絶対値  

ライブラリ

数学ライブラリ (libm,~-lm)  

書式

#include <math.h>

double fabs(double x);
float fabsf(float x);
long double fabsl(long double x);

glibc 向けの機能検査マクロの要件 (feature_test_macros(7) 参照):

fabsf(), fabsl(): 

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || /* Since glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE
 

説明

これらの関数は浮動小数点実数 x の絶対値を返す。  

返り値

これらの関数は x の絶対値を返す。

x が NaN の場合、NaN が返される。

x が -0 の場合、+0 が返される。

x が負の無限大か正の無限大の場合、正の無限大が返される。  

エラー

エラーは発生しない。  

属性

この節で使用されている用語の説明については、 attributes(7) を参照。
インターフェース属性値
fabs(), fabsf(), fabsl() Thread safetyMT-Safe
 

標準規格

C11, POSIX.1-2008.  

歴史

C99, POSIX.1-2001.

double 版の関数は SVr4, 4.3BSD, C89 にも準拠している。  

関連項目

abs(3), cabs(3), ceil(3), floor(3), labs(3), rint(3)
