futimesat

名前

futimesat - ディレクトリファイルディスクリプターに対する相対パスのファイルのタイムスタンプを変更する  

ライブラリ

標準 C ライブラリ (libc,~-lc)  

書式

#include <fcntl.h>            /* AT_* 定数の定義 */
#include <sys/time.h>

[[deprecated]] int futimesat(int dirfd, const char *path,
                             const struct timeval times[2]);

glibc 向けの機能検査マクロの要件 (feature_test_macros(7) 参照):

futimesat(): 

    _GNU_SOURCE
 

説明

このシステムコールは廃止予定です。代わりに utimensat を使用すること。

futimesat() システムコールは utimes() と全く同様に動作するが、このマニュアルページで説明する点が異なります。

path で渡されたパス名が相対パスの場合、 パス名はファイルディスクリプタ dirfd が参照するディレクトリに対する相対パスと解釈されます (相対パスの場合に utimes(2) で行われるように、呼び出したプロセスのカレントワーキングディレクトリに対する相対パスと解釈されるわけではありません)。

path が相対パスで dirfd が特別な値 AT_FDCWD の場合、 path は (utimes(2) 同様) 呼び出したプロセスのカレントワーキングディレクトリに対する相対パスと解釈されます。

path が絶対パスの場合、dirfd は無視されます(dirfd 引数が有用な理由については openat(2) を参照)。  

返り値

成功すると、 futimesat() は 0 を返します。 エラーの場合、-1 を返し、 errno にエラーを示す値をセットします。  

エラー

utimes(2) で発生する可能性があるエラーのいくつかは futimesat() でも起こること可能性があります。また、 以下のエラーも futimesat() では発生することがあります。
EBADF
path が相対パスですが、 dirfd が AT_FDCWD でも有効なファイルディスクリプターでもありません。
ENOTDIR
path が相対パスで、 dirfd がディレクトリ以外のファイルを参照するファイルディスクリプタです。
 

バージョン

 

glibc

path が NULL の場合、 glibc の futimesat() のラッパー関数は dirfd が参照するファイルの時刻情報を更新します。  

標準規格

なし。  

歴史

Linux 2.6.16, glibc 2.4.

これは POSIX.1 に提案された仕様に基づいて実装されましたが、その仕様は utimensat(2) で置き換えれました。

同様のシステムコールが Solaris に存在します。
